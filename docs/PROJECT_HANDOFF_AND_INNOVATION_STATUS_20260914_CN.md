## 5. 研究对象、固定条件与公平对照

任务为**少量正常支持下的工业异常检测与像素定位**，不是用少量缺陷标签训练的普通分类。主要结论使用类别宏平均 pixel AP，不要把 AP 提升改写为“准确率提升”。

- B：DINOv2-B；S：DINOv2-S；C：AnomalyCLIP 的视觉特征。C 的预训练来源包含 VisA，不是从未见过工业异常数据的纯无监督编码器。
- 本轮三分支是 B/S/C 三个视觉编码器。C 不是显式文本分支。本轮不能作为“加入文本是否有效”的验证。
- 正常支持 K=1/2/4/8 按同一序列取前缀；不要重新随机选 K1/K2 来制造独立样本。
- 共同网格以 B 为准，MPDD、BTAD01/02 为 32×32，BTAD03 为 32×42；其他分支按整图坐标关系对齐。后处理与掩码坐标需共同审计。

| 构造 | 权重 | 主要回答的问题 |
|---|---|---|
| A1 | B=1/2，C=1/2 | 双视觉锚点 |
| DUP | B=1/3，Bcopy=1/3，C=1/3 | 无新表征、B 的有效权重变成 2/3，会怎样 |
| TRI | B=1/3，S=1/3，C=1/3 | 相对 DUP，以 S 替换 Bcopy，是否有表征收益 |
| BAL | B=1/4，S=1/4，C=1/2 | 保留 DINO 家族/C 的总权重，考察替换贡献 |

每种构造计算：

```text
J(q) = min_r Σ_b w_b d_b(q,r)       各分支共同选同一参考行
L(q) = Σ_b w_b min_r d_b(q,r)       各分支独立选参考行
G(q) = J(q) - L(q) ≥ 0
```

这里 r 指共同坐标系下的支持图像 patch 行，不只是“选同一张参考图”。J/L 都是冻结的固定融合，不是动态门控网络。

G 非负是基本代数事实，不是论文原创定理；G 大不等于 AP 损失大。增加嵌套参考可以使原始 J、L 各自不增，但不保证 G、AP 或 L−J 的 AP 效应单调。

本轮对 B/S/C 和这些固定权重的结论，不能外推为所有视觉骨干、所有融合层级或所有分支数的最优性结论。TRI−A1 同时改变表征与权重，不能单独用它证明新分支贡献。

## 6. 五个方向目前验证到了哪里

下列“点差”均是原测试集的点估计；AP 使用 0–1 尺度，0.01 等于 1 个百分点。不能将 bootstrap 均值替换原始点差。

### 6.1 核心：共同参考约束有性能代价

来源：`p1_statistics/main_inferences.csv`。对预设 seed、K 等权平均，先在每个共享 bootstrap 复制中聚合，再取分位数。

| 数据 | A1_L−A1_J 原始平均点差，stride8 | 调整后的 97.5% 区间 | stride1 平均点差，无区间 |
|---|---:|---:|---:|
| MPDD | +0.006178，即 +0.618 个百分点 | [0.003100, 0.010518] | +0.006764，即 +0.676 个百分点 |
| BTAD | +0.008298，即 +0.830 个百分点 | [0.006417, 0.011225] | +0.008266，即 +0.827 个百分点 |

20 个条件的 stride8 和 stride1 点差都为正。stride8 条件级探索性 95% 区间，MPDD 10/12、BTAD 8/8 下界大于 0；这只是稳定性描述，不是 20 次独立验证。

允许写：在这套固定表征、权重和正常参考协议中，独立匹配有稳定的平均优势。不能写所有类别均改善、全像素已经统计显著，或匹配规则本身首次被提出。

统计区间主要表达固定类别、固定支持集合下测试图像重采样的不确定性，不覆盖新的类别、训练过程或完整支持抽样总体。BTAD 已在历史研究中被评估过，应称为已知数据集上的冻结复核，不称首次未见数据验证。

### 6.2 权重：复制分支不能代表新增信息

stride8 原始平均 DUP_J−A1_J：MPDD −0.008025，BTAD −0.009588；20 个条件的点差均为负。

含义是把 B 有效权重从 1/2 改到 2/3，在当前组合中造成损失。这支持设置复制对照的必要性；不证明 1/2 是最优权重，更不证明增加任何复制分支都会损失。

## 7. 本次审阅发现的验收缺口
