## 1. 五个方向适合融合，但应成为一条研究问题链

建议中心问题：

> **少量正常参考下，多视觉编码器融合的收益，如何受到有效权重、表征替换与共同参考匹配要求的影响？这些影响是否随参考预算和样本条件变化？**

五个方向在论文中的关系：

```text
观察：增加视觉分支并不总能改善结果
  ↓
先控制权重：是否只是改变了已有分支的比重？
  ↓
公平替换表征：在相同家族权重下，新编码器是否提供额外收益？
  ↓
改变匹配方式：相同表征与权重下，共同选参考有何代价或收益？
  ↓
研究作用条件：参考数量 K、类别和缺陷条件是否改变上述效应？
  ↓
用全像素、完整外部范围和竞争力参照检验结论
```

因此，权重与表示控制是识别问题的基础，共同匹配是重点研究对象，K 和类别条件是影响因素。**不建议写成五个彼此独立的新模块，更不能把五组消融都称为五项原创算法。**

建议工作题目：

**《少样本工业异常检测中固定多编码器融合的收益与局限：权重、参考匹配和支持预算的受控研究》**

英文工作题目：*Understanding Fixed Multi-Encoder Fusion for Few-Shot Industrial Anomaly Detection: Weighting, Reference Matching, and Support Budget*。

题目不预先宣称“共同匹配必然失败”或“参考越多冲突越小”。实验没有显示清晰 K 规律时，应如实报告未发现稳定预算效应，不强行补故事。

## 2. 建议的论文结构与贡献写法

### 2.1 正文结构

| 章节 | 应写的内容 | 对应证据 |
|---|---|---|
| Introduction | 少量正常参考、融合收益不稳定的问题；为什么分支数比较容易混入其他因素 | 已有现象及研究问题 |
| Related Work | 正常记忆库、视觉编码器融合、联合与独立匹配、少样本参考覆盖；明确与最近似工作的差别 | 原论文逐项核查，不能只依据摘要判断没有相同实验 |
| Framework and Controlled Protocol | 冻结编码器、统一支持、权重和 J/L 定义、公平对照、数据角色 | 本文第4–5节及已有协议 |
| Controlled Findings | 先权重，再表征替换，再匹配效应；交互结果作为连接 | 已有两组参考实验及补充矩阵 |
| Support Budget and Conditional Effects | K 曲线、跨 K 差值、类别/缺陷差异、反例 | 新增关键支撑实验 |
| Robustness and Practical Context | 全像素、外部完整类别、强单支和标准方法参照、资源代价 | 新增/复用验证 |
| Discussion and Conclusion | 支持哪些经验条件，哪些假说失败，局限与适用范围 | 正负结果均纳入 |

这是一篇“受控实证分析”路线的论文。方法章节可以介绍统一分析框架，无需编造一个实际上没有训练的新网络。如果后续改成算法改进型论文，要另行冻结可部署规则并验证，不能把测试集最优 λ 包装为新算法。

### 2.2 贡献宜凝练成三项

1. **严谨的对照设计**：区分有效权重变化、新表征替换与参考匹配方式，避免把全部效果归结为分支数量。对照操作中的基本代数并非首创，贡献是否新颖需与文献比较。
2. **可复核的经验发现**：报告匹配方式与融合效果之间的实际关系，以及参考预算、类别条件下的变化和反例。现阶段已有部分发现，完整范围仍须由下述实验支持。
3. **透明的验证与适用范围**：提供正常支持身份、预测、统计、完整类别结果、全像素检查及外部复核，明确哪些结论不能泛化。

其中“新发现”应是论文贡献的中心。大量实现检查只能保证可信，不能独立证明创新；统计不显著也不能自动解释成方法等价。

## 4. 全文统一的变量、方法和对比

B=DINOv2-B，S=DINOv2-S，C=CLIP视觉特征。路径名 `anomalyclip_text` 不表示本轮使用文本评分。冻结目标数据上的编码器，不引入目标缺陷监督训练。

在同一查询、同一正常参考行与固定非负权重下：

```text
J = min_r Σ_b w_b d_b(q,r)
L = Σ_b w_b min_r d_b(q,r)
G = J - L >= 0
```

距离用单位特征的余弦距离；若采用拼接，特征块应乘权重平方根。J/L/G的基础不等式不是创新发现，G也不是“准确率损失”的直接量度。

| 构造 | 距离权重 | 要保存的端点 |
|---|---|---|
| A1 | B=1/2，C=1/2 | A1_J、A1_L |
| DUP | B、Bcopy、C各1/3 | DUP_J、DUP_L；Bcopy共享B数组 |
| TRI | B、S、C各1/3 | TRI_J、TRI_L |
| BAL | B=S=1/4，C=1/2 | BAL_J、BAL_L |

核心预测矩阵为 **11个方法**：B/S/C三个单支，加四种构造各自J/L八个端点。DUP_BAL_J/L、DUP_EXPECTED_J保留为数值等价验收，可复用等价数组，避免无意义重复计算。λ=.25/.50/.75沿用已有次要诊断，**新K扩展不要求默认重扫全部λ**。

主要效应定义（M为固定评价指标）：

| 研究问题 | 预定对比 | 不能混淆的解释 |
|---|---|---|
| 权重影响 | M(DUP_J)−M(A1_J)，并补L端点对应对比 | 没有增加新信息，不能称为测得冗余信息量 |
| 表征替换 | TRI_J−DUP_J、TRI_L−DUP_L；BAL_J−A1_J、BAL_L−A1_L | 这比直接TRI−A1更接近控制家族权重后的比较 |
| 匹配效应 | A1/TRI/BAL/DUP各自的 M(L)−M(J) | 是固定构造内改变匹配要求的性能效应 |
| 表征×匹配交互 | (TRI_J−DUP_J)−(TRI_L−DUP_L)，BAL同理 | AP差值之差不等于patch分数上的J=L+G分解 |
| K调节作用 | Δmatch(K8)−Δmatch(K1)，完整曲线一并报告 | K2/K4两个点不足以证明单调规律 |

**重要数学检查**：固定查询、权重和严格嵌套参考库时，J与L原始最近邻距离各自应随K增加而不增；但是G=J−L和AP均不保证单调。不能因为某个G或AP曲线不单调就判实现失败，也不能预先声称K越大匹配冲突必然越小。

## 8. 统计要求：跨K比较必须重新正确配对

旧统计随机流含 `shot`：`default_rng([bootstrap_seed, shot, replicate])`。它可以支持同K内方法配对，但不同K的相同复制编号不代表抽到了同一批图像。

**因此，不能直接按下标相减旧K2和K4的复制数组，就把结果称为配对的K交互区间。**

对新增K研究另存统计版本：

1. 冻结查询ID顺序。每个数据集/类别/复制编号产生一份图像抽样索引，所有方法、所有K、所有reference seed共用该索引。随机规则不把method/K/reference seed加入该层索引生成；数据集和类别用协议中的固定整数ID，禁止Python不稳定的字符串hash。
2. 一张图像携带全部评价像素、mask、标签与分数。类别内计算pooled AP/AUROC，再取类别宏均值；不使用逐图AP平均代替pooled AP，不把像素当独立样本。
3. 保存每类别×reference seed×K×方法×复制的指标。这样才能正确计算留一类别、K效应和交互，不再只有宏均值而无法回溯。
4. 新分析先完成1000次固定复制；如需要提高区间尾部稳定性，必须在看新效应之前冻结更多次数和预算，不能按显著性增加复制。每次复制有效类别数、NaN原因与实际次数须保存。
5. 分别报告各reference seed及其固定集合上的平均结果。图像bootstrap区间是这些固定支持集条件下的不确定性，不包含支持总体不确定性。三seed可附均值、标准差和范围，但不能据此声称已准确估计所有支持抽样的分布。

建议每个数据集只设两项主推断：A1的平均匹配效应（按预定seed/K等权平均）与A1的K8对K1匹配效应差。两项主推断可使用Bonferroni调整后的97.5% bootstrap区间，并注明其近似性质；其余权重、表示、交互和子组对比统一提供95%探索性区间。不能把复制正负比例直接当成无需解释的p值，也不能把两种方法各自CI上下界相减代替差值CI。

**评价口径分开固定**：性能主表使用全像素P-AP及P-AUROC；机制统计可以继续采用明确标注的stride-8口径，作为条件性证据。全像素未计算区间时，只报告全像素点估计，不宣称全像素统计显著。若论文最终要依靠全像素显著性作主要结论，应单独实测并完成对应全像素配对统计，不能借用stride-8区间。

## 9. P2：把类别差异推进为可解释的适用条件

### 9.1 已有内容不要重复当作新成果

已有R0包含宏类别差值、留一类别点估计、部分G分布和排序翻转汇总。`image_flip.csv`目前可见行以类别聚合，不能凭文件名就声称已有每张图的独立统计。应检查原 `flip_stats.csv` 和 `sample_pairs.npz`，优先恢复/复用逐图结果。

### 9.2 必须补的分析

1. 对P1完整K曲线，分别报告每类权重、表示、匹配效应；补正确的留一类别区间，检查connector/metal_plate等是否决定效应规模。
2. 按图像记录 `L正确/J错误` 与 `L错误/J正确` 的比率及有效pair数；图像为统计单位。不能把同图内成千上万的patch对当独立样本。
3. 缺陷大小分组采用启动前冻结的面积比例规则，例如异常图中GT面积占整图≤0.1%、0.1%–1%、>1%。同时保存每组图像数；少于10张异常图的组只作描述，不作稳定子组结论。阈值是分析约定，不代表自然缺陷类别。
4. 优先在上述分组比较逐图排序变化及原始效应；若计算子组pooled AP，必须明确纳入哪些正常图和异常图，并保证方法之间样本集合相同。子组不得替代原始完整测试集主指标。
5. 有官方缺陷类型标注时可补类型分析；没有时不要凭自动热图随意创造“结构/纹理缺陷”的真值标签。主体边缘/背景条件需要独立主体区域依据，不能将缺陷GT的补集称为背景。
6. 使用现有固定可视化选择规则，实际渲染同一图像的原图、GT、J/L、G和反例。每类至少保留中等效应及正负例；图注给出选择规则、seed/K，解释性图例不作为独立验证样本。

验收：结果能回答哪些已定义条件下改善、无明显变化或恶化；保留原正常区G均值假说的反证；标签仅用于离线诊断，不用于权重、λ、支持或部署路由选择。当前论文无需强行训练一个“失效预测器”。

## 10. P3：补足外部覆盖，验证不是单一数据组合的特例

优先延续BTAD，完整覆盖01/02/03，reference seeds={0,1}，K={1,2,4,8}，第4节11方法，共24单元。第三个seed或第三数据集为后续增强，不作为本轮最小要求。既有01/02、K2/K4的B/C行通过重放后复用，但仍需补S与公平三支。

BTAD03原DINO特征是32×42，而旧载入器只接受32×32。**它不是因性能不好而排除，但当前两类结果也不能冒充完整BTAD。**

需另立支持非方网格的新协议：

- 检查每个编码器实际看到了原图的哪个区域，是否存在中心裁剪、长宽比保持或整图缩放。没有一致视野，不能仅把数组插值到相同shape就宣布空间配对成立。
- 优先以B的原生网格作为共同网格，将其他分支按已核实的整图坐标关系对齐；参考、查询采用同一规则。把H×W参数化，参考行数用K×H×W，不写死1024。
- 诊断、置换、mask映射、分数重建、输出metadata同步适配；对原01/02重放应在原容限内，证明支持03没有悄悄改变已有类别。
- 显式保留所有三类的失败/完成记录。若视野无法一致，应先修正必要导出并记录新协议，而不是在未知配对上产生机制结论。

BTAD已被项目历史流程评估，只能称为已知数据集上的冻结外部复核。新配置应在看其结果前冻结，但这不使整个BTAD重新成为未见数据。若目标期刊需要更强泛化论证，再在不参与本方案选择的数据源上做额外验证，并核对checkpoint训练来源。

外部验收：三类完整、两组参考、完整K与公平矩阵、输入身份通过、全部预定对比与反例齐全。新S没有收益或匹配优势不复现也算实验完成，应收窄论文结论。

## 11. P4：全像素和强基线，避免论文只证明弱对照

### 11.1 全像素

既有MPDD seed0/1 K2/K4八个端点已完成，无需原样重算。对新增seed/K及完整BTAD补全相同端点的全像素点估计；单支用于主性能表时也补同口径。保持原后处理和完整画布，不删裁剪外像素、不换mask口径。

所有关键效应以stride1/8并列，反向或幅度明显变化时如实解释。计时先顺序处理一个类别一个方法，不同时堆叠所有全像素平面。完整像素CI按第8节的论文主张和实测预算单列，不默认对所有次要λ和所有子组做昂贵bootstrap。

### 11.2 竞争力参照与受控对照分表

最低限度保留：

- 同条件B/C/S单支、原A1、独立匹配及公平三支：解释效应来源。
- 原生配置AnomalyDINO与一个标准记忆库基线（优先已有PatchCore复现）：提供实际性能参照。需要比较时优先复用 `experiments/dynamic_fusion/validation_handoff_20260911/E1/` 和 `E3/` 的来源，不重新做全部历史方法。

参照最低范围为MPDD和完整BTAD、K1/K4、seed0/1。核对支持ID、图像坐标、指标、正常样本预算、是否训练/校准；不一致则分开列原生结果和匹配管线结果，不能把它们混成同一因果对照。

目标是说明实际价值和限制，不要求本分析论文每一行都赢。不得只挑被削弱的matched单支来声称优于最强单支；也不应把不同数据预算或使用缺陷训练的模型视为同条件基线。

成本仅作配套小表：选K1/K4/K8的固定类别和批量，区分编码器前向、检索、后处理、评价以及一次性建库开销。复制B共享数组，不应当成真实新增编码器的运行成本。已有评价阶段耗时不能冒充部署延迟。

## 13. 何时可以结束补实验并进入投稿稿件整理？

达到以下条件就可以开始完整稿件整理，不必无限扩方向：

1. MPDD核心K曲线和受控矩阵完成，已有/新增配置清楚分开，至少按计划报告支持抽样差异。
2. 公平表征、匹配和权重效应有完整大小、区间与反例，跨K比较正确配对。
3. 类别条件不是仅凭平均数或精选图片；全像素方向和完整外部范围已核实，剩余局限公开。
4. 强参照和数据角色没有误导；图表可回溯到预测和manifest。
5. 文献差异已经逐项核对，贡献表述与结果相符。

若K效应不稳定，则保留“预算条件下的实证结果”，不宣称单调规律；若新增S没有稳定收益，则将其作为受控负结果；若外部/全像素不复现，则收窄适用范围。**实验完整性与预期假说成立是两个不同验收项。**

接手AI的首要动作是完成P0并给出缓存/改造/耗时清单，然后按P1-A、P1-B、P2推进，按预算穿插P3/P4，最后产出P5。不要先设计新融合网络，也不要将当前五个研究问题改写成五个已经成立的创新模块。
