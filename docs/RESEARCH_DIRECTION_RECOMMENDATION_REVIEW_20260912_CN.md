## 3. 附件中正确且应保留的部分

### 3.1 权重混杂确实需要优先排除

当前 B/S/C 分别是 DINOv2-B、DINOv2-S 和 CLIP 视觉分支。在单位化特征的等权联合距离中，B+C 的两个家族各占 1/2；B+S+C 中 DINO 家族合计占 2/3。

附件的五组控制成立：A1、B+B+C 等权、B+S+C 等权、家族平衡的真实三支、家族平衡的复制三支。它在第 13 节正确要求特征块乘 `sqrt(weight)`，没有把距离权重误当作特征缩放系数。

但要收紧解释：B+B+C 等价于 B/C 的 2:1 加权是基本代数。即便性能改变，也只是证明这个系统受权重影响；它并没有测得一个可量化的“信息量”。B 与 S 同家族也不意味着它们完全重复，家族平衡是预设控制，不是已证明的最优融合。

### 3.2 配对干预的不变量设计合理

共同置换所有参考行不应改变 J/L/单支分数；单独置换一支不应改变各支完整 NN 分数和 L。使用固定行集合、双射置换和精确 NN，可避免把删样本、增加内存或近似检索误差混入解释。

需要补充：分支数≥3 时，若只置换一支，只打破它与其他支的对应，其他支之间的对应仍保留。因此置换 B、S、C 并不是同一干预，必须记录 `permuted_branch`；不能只选最有利的一支置换。探索阶段至少预先指定 C 与新增 S 两个对象，确认阶段固定完整比较集合。

### 3.3 暂缓大量骨干穷举合理

先解释已发现的退化，比立刻运行大量组合更节省资源。若最终要概括为普遍多编码器规律，仍需异质编码器和跨组合复核；阶段性暂缓不能变成用一个 B/S/C 组合代表全部多分支。

## 4. 最关键的缺口：配对敏感性不等于原始系统失效归因

附件第 2、8、10 节的理想叙事有一个尚未闭合的跳跃：

```text
改变人工 reference 配对 → J 改变
```

能够证明对应关系影响联合打分，但不能单凭此推出：

```text
原始三支系统的 AP 下降 → 由有害的共同参考耦合造成
```

打乱参考行会制造在真实图像中未出现过的联合特征，改变空间对应、共现和经验联合密度。一个有效利用真实对应关系的模型同样可能在被打乱后掉分。因此置乱下降可能体现有用的联合结构，而非原始模型的缺陷。

我前一版建议对此已有提醒，但本次应进一步落实为验收要求：**必须在原始、未置乱的真实数据上，显示共同匹配项与实际排序损害之间的关系。** 置换属于补充的干预证据，不是唯一核心证据。

## 5. 建议补入的两组关键诊断

### 5.1 原始分数的增量分解

在共同的距离单位、权重协议和处理位置下，分别计算两支、三支的：

```text
J = 联合最近邻分数
L = 各支独立最近邻分数的固定加权和
G = J - L

ΔJ = J_three - J_two
ΔL = L_three - L_two
ΔG = G_three - G_two
ΔJ = ΔL + ΔG
```

这可区分“独立分支证据本身已经变化”和“要求共同参考额外引入的分数变化”。在家族平衡下，若 m_B/m_S/m_C 为各支独立 NN 距离，则 `ΔL=(m_S-m_B)/4`，有明确解释。

**这是逐 patch 分数的恒等分解，不是 AP 的加法分解，更不是新的理论贡献。** 先在原始 patch 分数上验证；不能直接用于图像 max 分数、逐图非线性归一化后的结果或 AP。若共同线性插值/高斯处理后继续分析，应另验证恒等关系和区域边界影响。

### 5.2 检查共同匹配项是否翻转正常/异常排序

对于预先定义采样规则下的正常 patch n 与缺陷 patch a：

```text
J(a) - J(n) = [L(a) - L(n)] + [G(a) - G(n)]
```

当 L 原本把异常排得更高，而 G 使 J 把正常排得更高时，才能具体展示共同匹配项破坏了这一对的排序。也要报告相反情况：L 错而 J 对，体现共同约束的正贡献。

只报告“正常区域平均 G 高于异常区域”既非充分也非必要：正常的 G 更高仍可能没有改变排序；少量尾部正常 patch 也可能造成重要误报，却不改变整体均值。

建议同时报告：

- 正常图、异常图内正常区域、缺陷区域的 G 分位数与尾部；
- 正确→错误与错误→正确的配对排序变化；同图定位排序与跨图排序分开；
- 同一方法组合下的 P-AP、I-AUROC、AUPRO 及按图像成簇的配对不确定性。

像素配对需预先固定规则与数量，不能把海量相关像素当独立重复样本，也不能把少量可视化成功案例当全局效应。

可选增加预注册的约束松弛诊断：

```text
S_lambda = L + lambda * (J - L)
lambda ∈ {0, 0.25, 0.5, 0.75, 1}
```

端点是既有独立 NN 与联合 NN。中间点可检查保留原始特征与配对、减弱共同约束后是否恢复排序。全部固定取值都报告，不能按测试最优选择 lambda。这是普通固定分数插值，**只作诊断，不称新融合算法**；即使恢复，也不证明共同匹配是唯一原因。

## 6. K 交互与扩展门槛需要修正

### 6.1 经验依赖不等于可预测边界

附件正确提示 K 曲线不必单调，但其“可预测边界条件”措辞仍偏强。增加 K 同时改变样本数、参考行数、覆盖机会与联合密度；即便观察到稳定曲线，也只能先称“经验参考预算依赖”。

若要进一步声称能预测何时融合失败，需要在未参与规则选择的数据上验证一个事先定义的判据，例如正常数据上的诊断量能否预测新类别的融合增量。开发和验证该判据是额外研究任务，目前附件尚未完成设计，更没有结果。

不能通过扫描大量正常候选后挑 K 张、又把实验称为只使用 K 张正常图。候选池、正常校准集和选图过程均计入数据预算。

### 6.2 Phase C 的“任意一项稳定就升级”应分层

建议改为以下决策，不把轻量探索门槛等同于完整论文成立：

1. **实现通过**：A1 重放、复制等价性、共同置换与单支/L 不变量全部通过。
2. **值得小规模复核**：在原始数据上出现有实用意义的排序/指标效应，并与 ΔG 或预定干预相符。只有权重效应时转向权重问题，不自动升级成 coupling 论文。
3. **值得全面扩展**：权重因素已控制；原始性能变化、区域诊断与干预证据能相互支持；至少两个参考 seed 及第二个数据集复核。允许机制只在预先说明的某类区域或域成立。
4. **支持 K 主张**：预注册交互分析和嵌套支持结果支持参考预算依赖；如无稳定交互，删除这一核心主张，而非挑选 K。

“p 值显著”不是唯一门槛；报告效应量、置信区间、类别差异和实际代价。区间跨零是未确定，不能自动判成等价或没有作用。不得因为某组合输给 A1 就从确认矩阵中删掉。

## 7. 与项目现状的对应

现有基础已经足够启动有针对性的试验，但不是这些机制已完成验证。

- MPDD 六类、seed 0、K2/K4 的 B/S/C 单支、双支和一次三支结果及特征基础可复用。三支相对 A1 的均值约下降 1.23 个 P-AP 百分点，是动机证据。
- R1 已有 MAP_mean，即独立 NN 后平均；不能把简单 J/L 比较再列为新贡献。需复用已有端点，并为原始分数/区域诊断新增导出。
- 原 A1 的四数据集 K1/2/4、三个参考 seed 支撑基线稳定性；它们不能自动填补新三支、置换、权重控制和 K8/16 的结果矩阵。
- 新诊断应写入独立实验目录。扩数据集、支持 ID、分支和指标时需改适配层，不能假定现有受控脚本只换参数就完整支持。
- 反复置换主要增加精确近邻计算与数据读取，而非必须反复运行编码器。应按查询分块计算，避免把所有 query×reference 距离矩阵一次放入内存。真实耗时需先用一个类别测量，本审阅不虚报小时数。
- 正常误报率需要声明阈值来源；新增正常校准样本属于额外预算。无阈值协议时，先报告分布、排序和阈值无关指标。
- 完整原图端到端耗时与缓存评分耗时要分开。多分支编码器、CLIP/T、预处理、内存构建和后处理都应按实际参与路径计量。

## 8. 与当前论文和AI 辅助评审要求的关系

当前 [英文稿](<repo-root>/docs/manuscript_revision_20260905/English_content.md:1) 标题与摘要是 DCFnet 双视觉固定融合检测器，核心结果是相对 matched DINO 控制的定位收益。其方法解释了联合距离，但尚未提供本建议要求的机制归因。

[评审会审核定稿清单 P02–P05](<repo-root>/docs/requirements_notes_20260912/DCFnet_需求整理与执行清单_20260912_审核定稿版.md:38) 的实际边界是：

- 大量常规实验不能单独成为方法创新；具有独特问题、设计和发现的实证贡献可以谨慎讨论。
- 当前方法贡献需要解释真实设计的价值、区别和证据；常规拼接/归一化不会自动成为新模块。
- 当前稿的三分支内容属于实验分析，不能让 Overview 暗示已实现统一多分支系统。
- 前景/ROI 是AI 辅助评审登记的候选，尚未实现为有效新模块；本建议不会自动完成或替代那一候选。

因此，**不能说AI 辅助评审已禁止机制型实证论文，也不能说AI 辅助评审已认可把这条线作为唯一主创新。** 若这条研究取得强证据，可以形成研究型论文；那将需要重新组织标题、摘要、相关工作、研究问题、实验方法和结论，而非给现有 DCFnet 贡献段加一句话。

| 结果情况 | 建议论文处理 |
|---|---|
| 只有复制/权重解释，或置乱敏感但没有真实退化证据 | 保留 DCFnet 主线，新增机制诊断/局限分析；不把 coupling failure 当主创新 |
| 原始退化、干预和 K/区域规律有跨域可复核证据 | 可另建机制研究稿，A1 作为受控研究对象与参考系统；保留原稿作为历史版本 |
| 进一步设计出可在正常-only 条件下使用、并有独立验证的修正方法 | 可考虑“发现问题—解释机制—修正方法”的方法型论文；当前并无这样的新方法结果 |

机制研究不必每个配置都超过 A1 才有价值，但须证明其发现超出了已知联合匹配几何，且能解释或指导实际选择。若修正最终就是已有 MAP_mean，也不能把它重新命名为新算法。

## 9. 推荐的下一轮最小验证包

暂定名称 `reference_coupling_pilot_v1`，不改历史协议。此处仅是下一轮执行建议，本轮未创建或运行。

1. 先恢复并核验支持图像与 patch 行身份；MPDD s0/K2/K4 六类重放 A1，完成五组复制/权重控制。
2. 在原始配对下导出两支与三支的 J/L/G、ΔJ/ΔL/ΔG，分析区域尾部、双向排序翻转和原始指标。
3. 对预先指定的分支做共同、图内、跨图置换，固定 10 个置换 seed 仅作探索；所有不变量先通过。
