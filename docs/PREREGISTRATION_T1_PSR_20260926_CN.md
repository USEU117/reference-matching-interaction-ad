## 一、占位与轴去重（先做，几乎零成本）

### 1.1 Mode A — 占位

| 工作 | 覆盖什么 | 留白 |
|---|---|---|
| **PCU**（UAI 2026, PMLR v337） | 施加已知强度的 perturbation ladder，把表示的一阶斜率 / 二阶曲率 / 局部稳定性（响应谱）当作不确定性异常信号 | 原文验证主要在通用/表格 UAD，且**训练了 encoder**；**冻结视觉编码器上的 patch 级扩展未在其检索集内被验证** |

**判定**：`occupied in principle`（"扰动响应谱当异常信号"这一观测量已被占），但**冻结、无训练、patch 级、少样本工业定位**这一组合**未在检索集内发现**。因此本探针**不得**主张"首次提出扰动不确定性用于异常检测"，只能主张"在冻结少样本工业协议下该观测量的受控实测"。

> 注：本会话环境未挂载联网检索工具，上述检索在仓库内既有文献调研归档上执行；投稿前须补一轮在线核验。

### 1.2 Mode B — 轴去重

本探针的轴 = **"冻结相似度场的局部稳定性"**（对查询侧做无标签微扰后，匹配结果自身的不稳定程度）。与已封闭 38 族逐一对照：

- 不在"特征标定/通道选择"轴：那里改的是特征尺度，此处改的是**对微扰的响应**；
- 不在"重构/流形/测试期适配打分"轴：那里在测试期改动**参考或打分函数**，此处两者都不改，只测其**局部条件数**；
- 与"跨图一致性""匹配深度/度规""位置先验""图内自归一""形态/区域后处理""分数级集成"均不同族。

**判定**：**轴开放**（最近邻为 PCU 式不确定性，已在 1.1 说明留白）。

### 1.3 剪枝检查

- 非单调剪枝：观察量不是冻结距离的类内单调变换 → **不因单调性剪枝而恒为零**；
- 零拷贝等价：两个 patch 可以有几乎相同的 top-1 距离而在相似度场中处于完全不同的局部几何（尖峰 vs 平台）→ 响应谱不同 → **不是同一个探针**，不予剪枝。

## 二、探针规格

### 1. 要回答的问题（可证伪）

在冻结 A1 协议下（DINOv2-B/14 + AnomalyCLIP 文本描述子，0.5/0.5 concat，faiss top-1，1−cos，六类宏 Pixel-AP，MPDD，seed0，k2/k4）：

- **Q**：以"查询侧无标签微扰下匹配结果的**不稳定程度**"作为异常分数，是否比冻结距离本身更能分离异常？

**反证条件**：若 lead 变体在任一 cell 的宏 ΔAP < +0.01，则"不稳定度是有效异常观测量"这一假说在该 cell 被否。

### 2. 观测量定义（写死，不可事后改）

- 基线：`d0(q) = 1 − cos(q, r_top1)`，即冻结控制（必须复现 k2 `0.343706` / k4 `0.388328`）。
- 扰动集（**全部无标签**，随机流固定）：
  - `G(σ)`：`q ↦ unit(q + σ·ε)`，`ε ~ N(0, I)`，`σ ∈ {0.01, 0.03}`，每个 patch 8 次抽取；
  - `D(p)`：查询特征坐标按固定随机流以概率 `p = 0.1` 置零（token dropout），每个 patch 8 次抽取。
- 响应统计（每个 patch 一个标量，越大越异常）：
  - `S_std(·)` = 各次扰动下 `1 − cos(q̃, r_top1(q̃))` 的**标准差** → 变体 `PSR_std_{σ}`；
  - `S_arg(·)` = 各次扰动下 top-1 支持行索引与基线不同的**比例** → 变体 `PSR_arg_{σ}`。

### 3. 预注册变体全集（全部报告，含失败者）

`PSR_std_0.01`、`PSR_std_0.03`、`PSR_arg_0.01`、`PSR_arg_0.03`（`D(p)` 关闭，不扫描；若 `PSR_*` 族全负则记为整族负）。

family lead 由**预注册规则**（宏 ΔAP 最优且过门约束）确定，**不**由事后挑选。

### 4. 门（与全部 breadth 轮次一致）

lead 变体在 **k2 与 k4 两个 cell 均**满足：宏 ΔAP ≥ +0.01 **且** worst 类 ΔAP ≥ −0.03 **且** ΔAUROC ≥ −0.005。

### 5. Control parity（先决）

必须精确复现冻结控制：k2 `0.343706`、k4 `0.388328`（容差 3e-4，与既有 harness 一致）。未通过则本探针作废。

### 6. 报告口径

必须报告逐类 ΔAP 方向、worst 类、副指标 ΔAUROC；**不**把区间跨零写成零效应，写"区间跨零，方向未定"。

### 7. 泄漏审计

检索探针代码，确认：ground-truth 字段不进入扰动抽取、超参选择、变体选择或路由路径；扰动是**无标签**的；**不做按类启用**。审计结果写入产物 payload。

### 8. 杀 criterion

- parity 不通过 → 作废重写；
- 两 cell 宏 ΔAP < +0.01 → **记为负结果并归档该轴**，不改口径、不缩数据集、不升格为"注意到的趋势"；
- 出现单元级 OOM / 单 cell > 30 min（CPU）→ 停止该 cell 并记录。

### 9. 成本与产物

- 成本：纯 CPU；冻结特征在盘（`outputs/dynamic_fusion/v3_direction_a/features_vitb14_s0_k{2,4}` 与 `features_s0_k{2,4}`），估 **分钟级**。
- 产物目录：`experiments/dynamic_fusion/innovation_t1_psr_20260926/`（新目录，前缀待作者确认）。
- 内容：预注册 payload（含 `preregistered` 字段）、逐 cell JSON、逐类 CSV、control parity 断言日志、泄漏审计记录、单一可复现命令说明。

## 三、先验与预期（写在前，防事后解释）

- **先验偏低**：isotropic 小扰动下 top-1 选择通常稳定，`S_arg` 可能大面积为零；`S_std` 亦可能只是 `d0` 的弱重排。

- 若全负，本探针的产出 = 该轴的**边界刻画**（作为 limitation / future work 证据），与项目"负结果同样是结果"的档案纪律一致。
