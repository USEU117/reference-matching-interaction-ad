## 1. 本轮要回答的问题与不变条件

本轮只研究冻结视觉编码器在正常参考库匹配中的表现。B=DINOv2-B，S=DINOv2-S，C=当前 AnomalyCLIP 的 CLIP 视觉分支。A1 为 B+C 的等权联合特征最近邻方法。

四个试探方向：

1. **权重控制**：三支退化是否受 DINO 家族重复加权影响。
2. **原始匹配诊断**：新增分支的距离变化来自独立证据，还是共同参考要求；是否造成正常/缺陷排序翻转。
3. **配对干预**：各支参考特征集合完全不变时，改变跨支对应关系如何影响结果。
4. **约束松弛**：固定减弱共同匹配项，是否改变原始数据上的排序和性能。

本轮优先复用 MPDD 六类、reference seed=0、K=2/4 的 B/S/C 缓存。这是探索性完整小矩阵，**不是跨 seed、跨域的确认性研究**。不能在完成后直接写“发现普适失效机制”“准确率上限”或“可预测边界”。

冻结条件：同一查询顺序、同一支持图像与顺序、相同参考行集合、32×32 对齐网格、各支单位化、精确 1-NN、448 双线性插值后 Gaussian σ=4、图像分数取最大值、历史像素评价 stride=8。标签只用于离线评价和诊断，不用于选权重、选支持或选择置换。

## 4. P2：五组控制与原始分数诊断

权重均指**有效距离权重**。若使用拼接实现，特征块乘其平方根；本轮引擎直接平均各支的 `1-cos` 距离，与单位化加权拼接的共同 NN 等价，须先通过旧路径验收。

| 方法键 | 分支距离权重 | 验证目标 |
|---|---|---|
| A1_J | B=1/2，C=1/2 | 冻结联合基线 |
| DUP_J | B=1/3，Bcopy=1/3，C=1/3 | 原样复制 B，只改变权重；复用同一数组 |
| TRI_J | B=S=C=1/3 | 真实三支 |
| BAL_J | B=S=1/4，C=1/2 | 家族总权重平衡 |
| DUP_BAL_J | B=Bcopy=1/4，C=1/2 | 必须与 A1_J 距离等价 |
| DUP_EXPECTED_J | B=2/3，C=1/3 | 必须与 DUP_J 距离等价 |

同时保存 B/S/C 单支，及 A1/TRI/BAL 三种设置的：

```text
J(q) = min_r Σ w_j d_j(q,r)
L(q) = Σ w_j min_r d_j(q,r)
G(q) = J(q)-L(q)
ΔJ = J_three-J_two = ΔL+ΔG
```

验收：G≥−1e-6；复制等价性、共同置换、分数恒等分解最大差≤1e-6。保留原始浮点残差，不为了“非负”强行截断 G。

这些是数学与实现验收，不是创新证据。ΔJ 分解只适用于指定分数层，不能把 AP 差值拆成几项相加。

## 5. P3：配对干预的精确定义

所有干预只改变参考行排列，不改变查询、各支参考多重集合、K、行数、特征尺度和权重。

1. **共同置换**：A1/TRI/BAL 各自所有参与分支采用同一参考行置换。只换行号，J 必须不变。
2. **图内置换 within**：每张正常参考图内部的 1024 个空间位置独立双射重排，只作用指定的一支。这里是完整空间置换，不冒充局部块扰动。
3. **跨图置换 cross**：交换正常参考图像的身份，保持每图同一 patch 位置；从非恒等图像排列中不放回取样。K1 无该条件，本轮也不推断 K1。

干预对象预先固定：A1 中置换 C；TRI 与 BAL 中分别置换 C 和新增 S。不能只报告最有利的目标分支。B/S 之间仍保留对应的条件与打乱 S 的条件意义不同。

随机规则由脚本和实际 `reference_permutations.npz` 双重保存。每个用到的置换都检查双射；C、S 的对应单支最近邻分数实际重算并检查不变，L 因此不变。不能仅凭理论上应不变就省略实现验证。

输出每个置换的指标与对原始相同方法的差值，给出种子/不同置换的分布。**置换数量不是独立训练次数、独立参考种子或独立数据集数量。**

科学解释：打乱后变化只证明评分依赖经验对应关系。它可能破坏有用结构，也可能制造虚假的近邻；不能直接证明原始系统已经失败。

## 6. P2/P4：区域、排序与固定松弛诊断

原始 448 mask 按面积汇总到 32×32 网格，保存 patch 的缺陷覆盖率。区域至少区分：正常图、异常图内完全正常 patch、含缺陷 patch；额外报告缺陷覆盖率≥0.5 的 patch 与混合边界数量。**这是 patch 机制诊断，不当作全像素定位结论。**

对 A1/TRI/BAL 的 G 报告每图的均值、分位数和尾部。对每张含正常/缺陷区域的异常图，用固定随机种子从两类 patch 各最多取 64 个，保存实际抽样位置，统计：

- L 正确、J 错误的排序翻转。
- L 错误、J 正确的修复。
- 并列、未变化和有效配对数量。

正常 G 的均值更高不是失败的充分条件，尾部变化也可能比均值更有意义。先检查真实排序，再结合 P-AP/AUPRO 和图像指标。

固定松弛诊断：对 A1/TRI/BAL，使用 `Sλ=L+λG`，λ=0/0.25/0.5/0.75/1；端点复用 L/J，所有中间值一并报告。它是普通固定分数插值，只作机制诊断；不得选测试集最优 λ 后改称新方法。

指标：历史 stride-8 P-AP、P-AUROC、历史 AUPRO@0.3 实现、I-AUROC/I-AP；逐异常图像内 P-AP 与 image max。关键小缺陷或区域结论需后续全像素复核，当前 stride-8 结果必须标识。

本轮不使用测试标签拟合部署阈值，所以不把 best-F1 的最优阈值用于“部署正常误报率”。如后续需要固定阈值 FPR，必须另建正常校准协议并计入额外正常数据预算。

## 9. 科学验收与后续交接决策

**运行验收**：计划单元均有 DONE；每项不变量通过；没有混用协议；数据、预测、置换和日志可追溯。没有效应也可以完成这一验收。

**探索结果验收**：对所有预定方法给出宏均值、逐类方向、K2/K4 各自结果和配对差值；不把两个 K 当作独立 seed。配对 bootstrap 以图像为重采样单位，像素仅作为同图内观测；说明当前区间不包含参考 seed 不确定性。置换种子变异另列，不能拼进 bootstrap 假装扩大样本。

实用效应参考为宏 P-AP 的 0.005，作为预定解释尺度，而非必须超过 A1 的筛选门槛。效应量小或区间跨零写“不确定”，不能自动写“等价”。只出现 p 值显著也不代表有实际价值。

最终按证据分流：

1. **权重控制有影响**：报告 DUP/家族平衡改变了多少，继续做第二 seed 复核；不能直接认定所有退化均由冗余造成。
2. **原始排序与共同匹配项有关，且干预证据相符**：进入第二 seed、第二数据集的预定小规模复核，再冻结完整确认方案。
3. **只有置换敏感，原始损害不清楚**：保留为对应关系诊断，主机制证据不足。
4. **各方向都无实质信号**：完整保存负结果，停止扩大 permutation/backbone 数量，评估是否回到现有稿的局限分析。
