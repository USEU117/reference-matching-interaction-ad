二、本轮 6 项优化：改前 → 改后

#目标改前（v1）改后（v2）
1更像「收敛图」 三个面板各画原始曲线，无渐近线、无稳定点标注；读者要自己判断「平了没有」。 每个面板都画一条水平参考线＝该序列在 N = 1000 的取值（(a) 为 0、(b) 为 1），并直接标注实测稳定点：竖虚线 settled from N = 200（点估计，±2.3e−04 pixel AP 灰带）与 settled from N = 500（区间宽度，±5% 灰带），另加 recommended N = 1000 (used throughout) 点线。
2面板数与信息密度 3 面板 × 5 数据集：(a)(b) 各 5 条「水平 ± 区间带」，点估计的「是否变平」在 |值| 尺度上不易读（如 VisA 的 0.0081–0.0096）。 选 (a) 方案：2 面板。左＝全部数据集（10 条序列）点估计相对 N = 1000 的变化，右＝区间宽度相对变化（KSDD2 仍灰虚线单列）。理由见下方「三、为什么选 2 面板」。
3单位与标签 y 轴写 I_TRI (10^-3 pixel AP)；I_TRI / I_BAL 在图上首次出现处无释义；「10^-3」相对「百分点」未点明。 y 轴写清量纲：estimate(N) - estimate(1000) (10^-3 pixel AP) 与 95% interval width / width at N = 1000；面板标题注明「pixel AP, original metric scale」「ratio」；标题下新增一句图内释义：I_TRI and I_BAL are the two interaction contrasts, both in macro pixel AP: I_TRI = (TRI − DUP)_L − (TRI − DUP)_J and I_BAL = (BAL − A1)_L − (BAL − A1)_J, with L, J = local, joint matching rule.
4配色 自选四色（#2E6F9E 蓝 / #B27C20 赭 / #3F7D4F 绿 / #9E3B57 玫红）＋ KSDD2 灰；面板 (c) 只靠颜色区分数据集，灰度打印时蓝/绿/玫红难以区分。 换成色盲友好 Okabe–Ito 子集：MPDD #0072B2○、BTAD #D55E00□、MVTec #009E73△、VisA #CC79A7▽、KSDD2 #808080◇。同时线型承载对比量（实线 = I_TRI，虚线 = I_BAL）、标记形状承载数据集，灰度打印也能逐条辨认（不再只靠颜色）。
5KSDD2 的语义 灰色虚线，仅靠图例标签 KSDD2 与图注一句话区分。 保持确认集语义并强化：灰色 + 更细线（1.0 vs 1.25）+ 置于底层，图例写作 KSDD2 (confirmation)，面板 (b) 标题直接写「KSDD2 (grey, dashed) = confirmation set, not a family member」，图注再声明「outside the four-dataset family」。
6图注 图内 8 行多行说明块；无固定词数的「可入稿图注」，无中文对照。 图内说明块精简为 6 行（含「无 loss 曲线」「只用前缀、未新采样」「稳定阈值来自实测」）；另在 JSON 与绑定表给出 66 词英文图注 + 中文对照（见下方「四」），可直接入稿。

三、为什么选 2 面板（方案 a）而不是保留 3 面板（方案 b）

  • 一屏一问：导师 10 秒内要回答两个问题——「点估计稳了吗」「区间稳了吗」。v2 把这两个问题各给一个面板，面板标题即是结论句；v1 的 (a)(b) 是同一个问题的两种对比构造，需要读者跨面板比较。
  • 「变平」在变化量尺度上唯一可读：v1 画的是水平值（VisA≈0.0093、MVTec≈0.0043、BTAD≈−0.0002），四组数值量级差 40 倍，共用一个 y 轴时 BTAD 的「平」与「不平」肉眼无法分辨。v2 左面板改为「与 N = 1000 的差」，全部序列收敛到同一条 0 参考线，平不平一眼可判。
  • 密度用编码解决，而不是用第三个面板：方案 b 的 3 面板会把 10 条序列挤在 1.6 in 高的面板里；v2 面板高 2.25 in，且用「线型 = 对比量、颜色 + 标记 = 数据集」把 10 条序列编码清楚，仍不需要在每个面板放图例框。
  • 版面收益：面板从 3 降到 2，图高从 24.4 cm 降到 23.9 cm，字号下限不变（11.50 pt），体积反而略增（801 KB）——增量来自曲线与标记本身，仍在 900 KB 门限内。

四、可入稿图注（≤ 70 词）

Figure S4. Bootstrap convergence of the interaction (macro pixel AP). Only prefixes of the frozen replicate arrays are used; no new sampling. The horizontal reference line marks each series' N = 1000 value. Point estimates settle by N = 200 and interval widths by N = 500 (within 6.8%); the paper reports N = 1000. KSDD2 (grey, dashed) is the confirmation set, outside the four-dataset family.
图 S4. 交互量的自助收敛（宏观 pixel AP 原值）。仅使用已冻结 replicate 数组的前缀，未新增采样；横轴为自助重复次数 N。水平参考线为该序列在 N = 1000 的取值；点估计自 N = 200 起稳定，区间宽度自 N = 500 起收敛到 6.8% 以内；全文报告 N = 1000。KSDD2（灰色虚线）为确认集，不属四数据集家族。
