### 三条战略判断

**(a) 你的"问题"没有被占。** 未在检索集内发现任何工作做"**匹配方式（共同参考 vs 各自最近） × 表征替换**"的**因子化受控交互研究**。别人在做**更强的机制**，你在做**机制为什么有效的受控分解**——这两件事不冲突，后者仍是你真正的护城河。**这是最该守住的资产。**

**(b) 你的"工程代际"落后于前线。** 现在是"单层冻结 + 等权 concat"对"多层 + 增强 + 结构先验 + 超图 + 注意力重加权"。审稿人很可能问两件事：**"为什么不用多层？"**、**"为什么不比 HyperFSAD / VisionAD / DuoAD？"**。这两问不需要你改结论，但需要你**主动写进 limitation 或补一组受控对照**。

**(c) 你判定的真缺口，正好是全领域公认难题。** bracket_brown（上下文/错位、异常区视觉正常）是"表示缺口"，而 2026 年的主流解法（超图、结构先验、部件一致性、组件重建）都在打这块。**机会**：如果你能用现有受控框架证明"这类机制在受控下救的是什么、毁的是什么"，比再报一个 SOTA 更有价值。**风险**：别人可能先发。

## 4. 本次 CPU 侦察结果（R13）

**口径**：沿用全部 breadth 轮次的冻结 harness —— seed0、k2/k4、六类宏 Pixel-AP；门 = lead 宏 ΔAP ≥ +0.01 **且** worst ≥ −0.03 **且** ΔAUROC ≥ −0.005；control parity 必须精确复现（k2 `0.343706` / k4 `0.388328`）；只用冻结特征与支持集，零 test 标签拟合，不做门后调参。

**预注册**（写在脚本 docstring 与输出 JSON 的 `preregistered` 字段里，运行前固定）：
- SHM（sparsemax 超边）τ ∈ {0.02, 0.05, 0.10}
- SOM（softmax 稠密对照）τ ∈ {0.05, 0.10}
- 诊断项 HCEN（均匀质心超边，**不设门**）
- PAIT 迭代扩库：q = 0.40 固定不扫；轮次 1/2/3；轮 1 必须复现 R6 的 PA_q40（k2 宏 ΔAP = `+0.004354`）作为交叉校验

三条可写入限制的结论：

1. **特征空间聚合继承了"均值崩塌"**。把"最近支持行"换成"支持行的加权组合"，就等于把 min 型统计换成 mean 型统计；R4 的 CEN（质心）与 R12 的 RGN（连通域均值池化）已经两次证伪 mean 型统计，本次是**第三次、且发生在特征空间**。**新轴闭合为负**。
2. **损害集中在强类，不是"救硬类伤强类"**。SHM 的损失几乎全部落在 tubes / connector / metal_plate（tubes 单项 −0.16 ~ −0.71），而两个硬类（bracket_black / bracket_brown）几乎没动。这与 35 族里反复出现的"救硬类伤强类"规律**方向相反**——它不是权衡，而是**纯损失**。这反而说明：聚合机制连"用强类换硬类"都换不到。
3. **稀疏度不是解药，且最优在内部**。τ 越小（越稀疏）越差，τ=0.10 最好，但 τ→∞（均匀，即 HCEN）又回落到 −0.2195。峰值在 τ≈0.10 内部，两侧都更差 ⇒ 即使加密 τ 网格（**预注册规则不允许门后加网格**），也没有从 −0.0574 跳到 +0.01 的空间。

三条结论：

1. **迭代只带来小幅增益，补不上缺口**。轮 3（+0.005685）相对轮 1（+0.004354）仅 +0.0013，距预注册门 +0.01 仍差 **0.0043**。ReMem 式"多轮再评估"在**本协议、本特征、本支持预算**下不足以把 benign 亚门推成方法贡献。
2. **迭代立即到达不动点**。`pa_bank_rows` 显示轮 2 与轮 3 的扩库行数完全相同（例如 tubes 21173 → 41370 → 41370、metal_plate 18411 → 39731 → 39731）。因为轮 2 之后 `aug = {d ≤ 分位数(0.40)}` 恰好取到 40% 的行数，集合规模被构造固定；**再多的轮次不再改变规模**，这也解释了为什么 r2 与 r3 量级接近。**"迭代"这条设计自由度实际上只有一轮**。
3. **PA 的良性来自"广谱小增益 + 处处无损"，而非"救硬类"**。增益落在 tubes / connector / metal_plate（中强类），两个硬类几乎不动，worst ≈ 0。这与 §2 中"35 族普遍救硬类伤强类"形成鲜明对照——**PA 是目前唯一不产生权衡的族**，但它的增益幅度天生小（需要 +0.01，实际 ~+0.006）。
