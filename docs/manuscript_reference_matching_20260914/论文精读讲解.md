# 0. 先看结论：三句话

1. **"加一个编码器有没有用"和"这份用处依不依赖匹配规则"，是两件不同的事。** 不能用一个数字（三分支比双分支好多少）同时回答。

2. **这两个量在不同数据集上的表现可以完全相反。**
   - MPDD 上，加 DINOv2-S 的**用处本身不确定**（区间跨零），但**依赖关系很确定**（+0.77 个点，校正后仍排除零）。
   - BTAD 上，加 S **非常有用**（两种规则下都涨约 +1.5 个点），但**几乎不依赖规则**（≈ 0）。

3. **换一个完全"不同出身"的编码器（WideResNet50-2）后，两个数据集上都是正交互（+0.50 ~ +0.97）。** 所以"正交互"不是某一个编码器的特例；但这也**不能**推广成"分支越多越好"或"独立匹配普遍更好"。

# 1. 这项研究到底在问什么

## 1.1 现实里的场景

工厂要检测新产品的外观缺陷。困难在于：

- 投产前你手上只有**少量合格（正常）照片**；
- 缺陷**长什么样事先不知道**——划痕、污染、缺件、结构变形，种类太多，没法预先收集样本。

所以学界用的标准做法是：**不训练缺陷分类器**，而是拿这少量正常图当作"参照物"，然后看待检图像哪些地方**不像**这些参照物。这种方法叫 **few-shot 正常参考（few-shot normal-reference）**。

本文用的两个数据集（MPDD、BTAD）就是按这个结构组织的：训练/支持部分只放正常图，测试部分才放正常图加各种缺陷，并附带像素级真值掩膜。

## 1.2 为什么"加个编码器效果更好"这句话不能直接说

假设你原本用两个编码器（记作 **B** 和 **C**），各自权重一半。现在想加第三个，看性能涨没涨。

问题在于，这一个动作会**同时**改变三样东西：

| 变了什么 | 说明 |
|---|---|
| ① 表征 | 真的多了一份信息 |
| ② 有效权重 | 原来的 B 和 C 各自权重从 1/2 变成 1/3 |
| ③ 选中的参考 | 加了分支之后，可能选中了另一张正常图当参照 |

**② 最容易被人忽略。** 举个具体例子：你不加新编码器，而是**把 B 复制一份**，变成「B + B + C」，权重各 1/3。这时：

- **信息完全没增加**（两份 B 的数值一模一样）；
- 但 B 的总权重从 1/2 变成了 **2/3**，C 从 1/2 变成了 1/3。

换句话说，**"分支数从 2 变成 3"这个动作本身就能改变性能，哪怕什么新信息都没加**。

所以论文的结论很直接：**不能拿"三分支减双分支"当作新编码器的贡献**。必须先把"权重变化"这一半剥掉。

## 1.3 本文要问的问题

剥掉权重的干扰之后，论文问的是这一句：

> **把副本换成一个真正不同的编码器之后，这份好处会不会因为"你允许每个分支各找各的正常参考"而变大？**

- 如果**会变大** → 说明这个表征的用处**依赖**匹配规则（本文叫"存在交互"）。
- 如果**不会** → 说明它有用，但用处跟规则无关。

这两个答案在工程上的含义完全不同：前者意味着"换规则时要重新评估该不该加这个分支"，后者意味着"加不加跟规则无关，可以分开决策"。

# 2. 四个构造：实验的骨架

论文设计了四个构造（构造 = 固定的分支组合与权重），用它们把三种变化一层层剥开。

| 构造 | 组成（括号内是距离权重） | 它相对上一个构造做了什么 |
|---|---|---|
| **A1** | B (1/2) + C (1/2) | 原始双分支锚点（就是之前项目里的 DCFnet） |
| **DUP** | B (1/3) + B (1/3) + C (1/3) | 复制 B 一份：**信息不变，只改有效权重** |
| **TRI** | B (1/3) + S (1/3) + C (1/3) | 把那份副本换成真正的 S：**权重不变，只改表征** |
| **BAL** | B (1/4) + S (1/4) + C (1/2) | 另一种分配：**C 保持 1/2 不动**，只把非 C 的那一半拆给 B 和 S |

**这张表是全文的钥匙，四行要记牢。** 关键就在两两相减：

| 对比 | 剩下的是什么 |
|---|---|
| **TRI − DUP** | 槽位和权重都一样，只剩"换了表征" → **纯表征效应** |
| **BAL − A1** | 另一种分配方式下的表征效应（互补检验） |
| **DUP − A1** | 只剩"权重重排" → **重新加权的效应**，没有新信息 |
| **TRI − A1** | 上面两者混在一起 → **所以不能用它论证新编码器的贡献** |

两个补充说明：

**① DUP 在数值上等价于「B 2/3 + C 1/3」的双分支构造。** 也就是说它根本不是"第三个分支"，只是权重重排。这一点让"权重的变化有多要紧"变得可以量化。

**② BAL 的叫法有讲究。** 在 S 实验里，BAL 保持的是"DINOv2 家族合计 1/2、C 保持 1/2"；但在 D 实验里（S 换成 WideResNet50-2），**不能**再叫"DINO 家族权重保持"，因为 D 是卷积网络、不是 DINOv2 家族，只能叫"保持非 C 的权重不变"。

**③ 论文还做了 D 版本**：`TRI_D`（B + D + C）和 `BAL_D`（B 1/4 + D 1/4 + C 1/2），用来验证结论是不是只对 DINOv2 家族成立。

# 3. 两种匹配规则 J 和 L

## 3.1 白话版：三位专家的比喻

把每个编码器想成**一位专家**。待检图像上的某个位置，要让专家们判断"它像哪一张正常样品"。

**J（联合匹配，Joint）**
> 三位专家**必须指着同一张正常样品**发言。先对"某一张样品"把三人的意见合起来，再挑出最像的那张。

**L（独立匹配，Independent）**
> 三位专家**各自挑自己觉得最像的那一张**（可以是三张不同的样品），然后再把意见合起来。

两者用的是**同一批正常样品、同一批描述子、同一套权重**。唯一的差别是：

> **"先合并，再挑最好" 还是 "先各自挑最好，再合并"。**

论文原话是"组合的分支合并与候选最小化这两步的先后顺序相反"。就这一件事。

## 3.2 精确版

设 $F_b$ 是分支 $b$ 的特征张量，先做空间对齐和分支内归一化，得到单位描述子 $g_{b,p}$（$p$ 是查询位置）。分支距离记作 $d_b(p,r)$（查询位置 $p$ 与正常位置 $r$ 之间）。

**J：**
$$d^{J}(p)=\min_{r\in\mathcal{R}_c}\ \sum_b w_b\, d_b(p,r)$$

**L：**
$$d^{L}(p)=\sum_b w_b\,\min_{r\in\mathcal{R}_c} d_b(p,r)$$

**两者的一个重要数学性质**：J 等价于把各分支的归一化描述子按 $\sqrt{w_b}$ 拼成一个联合描述子，其平方欧氏距离的一半等于加权余弦距离。这说明——

> **权重是"距离权重"，不等于特征拼接系数。** 距离各占三分之一，对应的是特征系数各取 $\sqrt{1/3}$，然后还要做联合归一化。这两个概念很容易混，论文在 §3.3 专门澄清了。

## 3.3 那个不等式，以及为什么不能直接推出"L 定位更好"

这是全文最需要小心的一个推理，也是审稿人最容易抓的地方。

**先看不等式**：对任何一张候选样品 $r$，每个分支的距离 $d_b(p,r)$ 都 ≥ 这个分支自己的最小值 $\min_r d_b(p,r)$。加权求和不会破坏这个不等式，再取最小值也不会反转。所以：

$$d^{L}(p) \le d^{J}(p) \qquad\Longrightarrow\qquad G = d^{J} - d^{L} \ \ge\ 0$$

**白话意思**：J 强行要求三位专家看同一张样品，这个额外约束让分数**只会更大（更差）**，不会更小。所以 J 是"受约束版"，L 是"自由版"。

**但是——** 这个不等式**不能**推出"L 定位更准"。原因在于两个概念不是一回事：

| | 说的是什么 | 怎么算 |
|---|---|---|
| 距离不等式 $G \ge 0$ | **分数高低** | 具体的数值 |
| 定位性能（AP） | **像素排序** | 异常像素是否排在正常像素前面 |

**打个比方**：两个学生的总成绩都降了 5 分，但不代表排名没变——原来 90/80 分，现在 85/75 分，排名还是那样。反过来，如果原来 90/85、现在 85/75，虽然都降了，**差距反而拉大了**。

**所以**：分数变化和排序变化没有必然联系。论文因此反复强调——**这个性能后果必须实测，不能从不等式推**。

论文还在原处标注：这个不等式是**标准代数性质，不是本文新提出的定理**。这一句是主动防审稿意见。

# 4. 五个量，各回答一个问题

论文用了五个量（其中"交互"有两个，所以一共六个符号）。分开记，别混。

## 4.1 定义表：每个量在问什么

先记住一个记号：$P$ = "类别宏平均的像素 AP"（第 8 章有解释），下标 $t$ 取 **J** 或 **L**（两种匹配规则）。

| 符号 | 白话 | 公式 | 它把什么**控制住**了 | 回答什么问题 | 最容易和谁混 |
|---|---|---|---|---|---|
| $M$ | **匹配效应** | $P(L)-P(J)$ | 分支组成完全不动，只换规则 | 单看 J→L，规则本身值不值？ | 与"加分支"无关，**不能**用它论证新表征的收益 |
| $E_{TRI,t}$ | **表征效应** | $P(TRI_t)-P(DUP_t)$ | 槽位分配锁死在 **1/3–1/3–1/3**；只把槽位 2 的 B 副本换成真的 S | 在规则 $t$ 下，换入新表征**有没有用**？ | 和 $E_{BAL,t}$ 不是一回事（分配不同） |
| $E_{BAL,t}$ | **表征效应（换一种分配再问一次）** | $P(BAL_t)-P(A1_t)$ | 槽位分配锁死在 **1/4–1/4–1/2**（C 保一半）；同样只换槽位 2 的内容 | 同上，换一组分配做**互补检验** | $A1$ 就是 BAL 的同型对照（因 $B_{copy}\equiv B$，写成两分支的样子） |
| $I_{TRI}$ | **交互** | $[P(TRI_L)-P(DUP_L)]-[P(TRI_J)-P(DUP_J)]$ | 对照和分配都不动；只把**规则**从 J 换成 L | 这份用处**依不依赖规则**？ | 别看漏下标：$I_{TRI}$ 默认指 **S 分支**，与 $I_{TRI\_D}$ 是两个量 |
| $I_{BAL}$ | **交互（另一组分配）** | $[P(BAL_L)-P(A1_L)]-[P(BAL_J)-P(A1_J)]$ | 同上 | 同上，分配换一种 | 同上 |
| $D_q$ | **编码器差值** | $I_q^{(D)}-I_q^{(S)}$ | 两个编码器跑在**同一 scope**（同 seed/K/类别），逐重采样副本配对 | D 的交互比 S 的**大多少**？ | 不是"D 比 S 好多少"——那是绝对效应，不是交互 |

**这张表的关键读法**：$M$、$E$、$I$ 是三层完全不同的提问——
**"规则本身值不值"（$M$） → "加这个表征值不值"（$E$） → "这份价值看不看规则脸色"（$I$）**。
论文的全部主张都建立在这三层必须分开报这一点上。

**两个 $I$ 为什么要都报**：$I_{TRI}$ 和 $I_{BAL}$ 是**同一件事在两种权重分配下的重复**。两者结论一致，才能说"交互"这个现象不取决于具体的分配方案（这就是"互补检验"的意思）。

## 4.2 判读表：一个数字该怎么读

| 情形 | 可以这样说 | **不能**这样说 |
|---|---|---|
| 95% 区间排除零（探索性口径） | 方向上有一致性 | ✗ "已经确立" |
| **98.75% 校正区间排除零**（主结论用这个） | 在 4 项一族的 Bonferroni 校正下仍成立 | — |
| 区间跨零 | 当前数据**分辨不出** | ✗ "两者等价"、✗ "不存在依赖"、✗ "没有收益" |
| 点估计超过 0.5 个 AP 百分点，但**区间下界没超过** | 点估计超过该**描述性尺度** | ✗ "效应一致高于这个量级" |

> 上面最后一行就是 MPDD 的 TRI 交互：点估计 $+0.772$，但 98.75% 区间下界只有 $+0.346$。所以摘要里选的是"区间不含零"这个更稳的说法，而不是"超过 0.5 个点"。

## 4.3 三条硬规矩（§3.5 末尾明确写的，也是评审最爱挑的）

| 规矩 | 为什么必须守 |
|---|---|
| 所有差值都在**同一条件内部**、**同一次重采样副本内部**先算好，再聚合 | 两次独立重采样之间没有配对关系，直接相减得到的区间没有覆盖率 |
| **禁止**用"一边显著、另一边不显著"来推交互 | 那是两个彼此独立的显著性判断，不是差值的检验。正确做法是把 $E_L-E_J$ 在**每个副本内**先算出来，再取分位数 |
| **禁止**用"上界减下界"这类区间端点相减来推交互 | 端点相减会造出一个**没有覆盖率**的假区间，看起来更宽或更窄都是假象 |

**一句必须记住的话**：交互为正，**只**说明"L 规则让这次替换更有利"。它**不代表**这个表征在 L 下本身就好。所以论文永远把"绝对效应"和"交互"放在一起报。

# 5. 实验是怎么做的

## 5.1 用了什么数据

| 数据集 | 类别数 | 在本文里的角色 | 说明 |
|---|---|---|---|
| **MPDD**（金属零件缺陷检测） | 6 类 | **开发集**（development） | 主分析的两个数据集之一；参与过本项目的开发过程 |
| **BTAD**（beanTech 异常检测） | 3 类 | **冻结验证**（holdout → external frozen validation） | 主分析的另一半；类别 03 用了修正后的几何（见 5.7） |
| **MVTec AD** | 15 类 | **外部冻结验证**（external frozen validation） | **本轮新增**：检验"结论是不是只在 MPDD/BTAD 上成立" |
| **VisA** | 12 类 | **域内冻结验证**（in-domain frozen validation） | **本轮新增**：注意 AnomalyCLIP 的权重在 VisA 上训练过，所以它**不是**完全外部的检验 |

**四个数据集的分工必须讲清楚**，否则会读错 MVTec/VisA 的分量：

- MPDD 与 BTAD 承担**主分析**——有 98.75% 校正区间、进入成文结论；
- MVTec 与 VisA 承担**泛化检验**——用同一套构造、同一套匹配规则、同样三条评价网格再跑一遍，回答"换个数据集还成立吗"。它们**不是"未被碰过的确认集"**：两套数据都参与过旧项目，而且 VisA 的 CLIP 分支权重就在 VisA 上训练过。

论文明确写了几件"泼冷水"的话：

1. 旧项目的 **MVTec AD 和 VisA 实验不复用**，因为它们评的不是这套新设计；本轮是在它们上**重新跑**这套新设计，属于新实验，不是复用旧结果；
2. 因为四个数据集都参与过项目探索，所以**不宣称**这是"全新未见数据集的确认"——真正的未碰过确认集**仍然缺失**（见第 7 章①）；
3. BTAD 用了修正后的几何版本（见 5.7）。

## 5.2 种子和支持预算

**种子（seed）**指的是"随机抽哪几张正常图当参考"，换个种子就是换一批参考图。
**预算 K**指的是"用几张正常图"，本文取 1、2、4、8。

| 研究 | 数据集 | 种子 | K | 单位数 |
|---|---|---|---|---|
| **S 研究**（主分析） | MPDD、BTAD | MPDD 用 0/1/2；BTAD 用 0/1 | 1, 2, 4, 8 | MPDD 72 个、BTAD 24 个 |
| **D 扩展**（**预指定**） | MPDD、BTAD | 0/1 | 1, 4 | 36 个 |
| **E 扩展**（事后探索性） | MPDD、BTAD | 0/1 | 1, 4 | 每个编码器 36 个（E1、E2 各一组） |
| **种子扩展**（本轮新增） | MPDD、BTAD | **3, 4, 5, 6, 7** | 1, 2, 4, 8 | 把种子池从 3 个扩到 8 个（矩阵已跑完，方差分析待跑） |
| **泛化检验**（本轮新增） | MVTec、VisA | 0/1/2 | 1, 2, 4, 8 | MVTec 180、VisA 144 个单元（矩阵已跑完，统计区间待跑） |

四个关键设计：

- **同一类别同一种子下，支持序列是固定的，小预算是大预算的前缀**。也就是说 K=1 用的那张图，一定也在 K=8 的八张图里面。这样"预算曲线"才是可比的一条线。
- **D 扩展是"预指定"的**（prespecified）：规格在看到结果之前就冻结了。这是防"试了很多编码器挑一个好看的"。为了让比较公平，S→D 的差值比较也被限制到和 D 相同的种子与预算范围内。
- **E 扩展（E1/E2）不是预指定的，而是"事后探索性"的**：它们的规格是**在 D 的结果已知之后**才冻结的。所以它们只能当**支持性证据**，不能享有和 D 同等的地位。这一点在正文里必须分开写。
- **种子 3..7 共享同一份查询编码**：新增的 5 个种子用的 query 特征块与 seed 0 **完全相同**（导出时用 `--reuse-query-from`）。所以种子之间的差异**只来自支持集**，不掺入编码漂移——这正是种子方差分析想要的纯净比较。这个做法的合理性有实测支撑：把同一批 query 图像重新编码一遍，特征的最大逐元素差异约 **1.7e-03**，听起来不小，但它对**最近邻余弦距离**的影响只有 **1.2e-07 ~ 4.1e-07**，而换一批支持集对同一距离的影响是 **7.5e-03 ~ 6.8e-02**——两者相差约 **4~5 个数量级**（最坏比值 1.5e-05）。所以编码漂移不可能伪造出种子间的差异。

论文自己提醒了一句："**这是对共享数据的重复评价，不是 96 个独立数据集**"——因为很多单位共用同一批图和同一个种子。

## 5.3 三种评价网格（不能混着排名）

| 网格 | 做法 | 有置信区间吗 | 用途 |
|---|---|---|---|
| **步长 8** | 在输出画布上每隔 8 个像素取一个 | ✅（主分析） | 控制 bootstrap 的计算量 |
| **全像素** | 每个像素都用 | ❌ | 分辨率敏感性检查（只给点估计） |
| **跨方法** | 把每种方法的预测映射回原图坐标，只评**它们共同有效区域的交集** | — | 和现有方法比较 |

为什么步长 8 当主分析：1000 次重采样如果每个像素都算，成本太高。但代价是——**小缺陷可能只落到很少几个采样点上**，所以必须再用全像素做一次方向核对。

**注意**：全像素只有点估计、**没有区间**。所以"全像素方向一致"是一个有力的**交叉验证**，但**不能**升级成"全像素也显著"。

**四数据集上的进度不一样**（写作时不能含糊）：

| 网格 | MPDD / BTAD | MVTec / VisA |
|---|---|---|
| 步长 8（主分析，有区间） | 完成 | 矩阵已跑完 **324/324** 单元，**统计区间阶段尚未跑出** |
| 全像素（点估计） | 完成 | 部分产出，**尚未全域完成** |
| 共同有效区域交集（和现有方法比） | 完成 | **尚未做** |

所以现阶段只能写"泛化矩阵已完整产出"，**不能**写"MVTec/VisA 上的交互区间是多少"。这一点在正文里必须如实区分，否则会变成"报告了不存在的数字"。

## 5.4 不确定性怎么算：bootstrap 白话版

论文做了 **1000 次配对图像级 bootstrap**。白话解释：

1. 从每个类别的测试图里，**有放回地**抽同样多的图（有的图被抽到两次，有的没抽到）——这叫一次"重采样副本"。
2. 在这一个副本里，把全部指标重算一遍，包括要比较的各种差值。
3. 重复 1000 次，得到 1000 个结果。
4. 把这 1000 个结果从小到大排，切掉两端，中间那段就是**置信区间**。

几个刻意的设计：

- **"配对"的意思**：同一个副本流**跨方法、跨种子、跨预算共享**。也就是说，比较 A 和 B 时，用的是同一批抽样副本。这样两边共有的波动会被抵消。
- **差值在副本内部先算**：不是先算 1000 个 A 的均值、1000 个 B 的均值再相减，而是在每个副本里先算 A−B。
- **不额外分层**：没有按正常/异常图再分层抽样；一张被抽中的图，它的像素是**整块**进入计算的。
- **基础随机种子是 20260913**，随机流里还混入了数据集标识、类别标识和副本序号，保证可复现。

**这个区间到底在说什么？** 论文写得很克制：它刻画的是"**换一批测试图，结论会不会变**"。它**不**重采样"可能的支持集"，所以**不能**回答"换一批正常参考图，结论会不会变"，更不能外推到别的数据集。

## 5.5 多重比较校正：为什么要"校正"，98.75% 是什么

**问题**：一次比较用 95% 区间，单次误判概率约 5%。但本文同时做 **4 个主要比较**（2 种构造 × 2 个数据集），4 次里"至少错一次"的概率明显高于 5%。

**最粗糙的解决办法（Bonferroni）**：把每次的标准收紧到

$$1 - \frac{0.05}{4} = 98.75\%$$

**代价**：区间变宽，更难排除零。

**所以摘要那句话的分量在于**：它说的不是"95% 下不含零"（这个比较容易达成），而是"**连放宽到 98.75% 都还不含零**"——这是最强的那一档表述。

**"族"（family）是什么意思**：校正只在一个"族"内部有效。本文有三族，各用同样的 98.75%：

1. 四个主要 S 交互；
2. 四个 D 交互；
3. 四个配对的编码器差值。

**不继承这个保证的**：逐类别、逐预算这些后续分析。它们只是"探索性"的，作用是"指出值得在新数据上检验的条件"，不是结论。

**本轮新增的比较怎么归类**（这批是 D 之后才做的，位置要写清楚）：

| 新增比较 | 项数 | 性质 | 98.75% 口径怎么处理 |
|---|---|---|---|
| E1 / E2 的交互（对 S 的扩展） | 每数据集 4 项 | **事后探索性**（规格在看到 D 的结果**之后**才冻结） | 沿用同一个 98.75% 常数算区间，但必须在正文里声明它**不是预指定族** |
| E1 / E2 相对 S 的配对差值 | 每数据集 4 项 | 同上 | 同上 |
| MVTec / VisA 的交互 | 每数据集 4 项 | **泛化检验**（独立数据集上的重复，不是新假设） | 单独报告，不与主族混合 |

一句话纪律：**新增比较借用的是"98.75% 这个计算常数"，不是"预指定族"的身份。** 把两者混起来写，就等于把事后探索伪装成预指定。

## 5.6 "0.5 个点"是什么地位

论文用 **0.5 个 AP 百分点**作为判断交互大小的**描述性尺度**。但明确声明了三件事：

1. 它**不是**工业实用阈值，也**不是**独立于本项目选出来的验收标准；
2. 点估计超过 0.5 **不代表**它的区间都在 0.5 以上；
3. **区间跨零 = 方向证据不足，不等于两种做法等价。**

这三点在论文里反复出现，是全文的口径纪律。

## 5.7 BTAD 几何修正：改了什么

BTAD 类别 03 的**真值掩膜和特征网格变换**之前有几何不一致的问题（缩放后是 448×597，但保留画布是 448×588，两者没对齐）。修正后：

- 受影响的点估计和 bootstrap 比较**全部重算**；
- **原始点估计按原样报告**，bootstrap 均值单独放一列，**不用它替换点估计**（因为两者不是一回事）；
- 逐预算的聚合是"所有可用种子的平均"，不是"最后一个处理完的种子"。

这是本文一个容易被忽略但很关键的处理——它说明作者知道几何错误会同时污染像素坐标和评价口径。

### 修正后又补了两步（本轮完成）

**① 细网格区间现在覆盖全部三个类别，而且结论没变。**

修正刚做完时有个范围限制：归档的细网格结果只覆盖类别 01/02，类别 03 只有点估计。本轮把 03 也纳入（用一致的几何真值 + 修正后的 patch 分数），补出完整区间：

| 网格 | 对比 | 点估计 | 98.75% 区间 | 排除零？ |
|---|---|---|---|---|
| 步长 8 | I_TRI | −0.00021 | [−0.00235, +0.00244] | 否 |
| 步长 8 | I_BAL | −0.00089 | [−0.00306, +0.00167] | 否 |
| 步长 4 | I_TRI | −0.00011 | [−0.00224, +0.00251] | 否 |
| 步长 4 | I_BAL | −0.00085 | [−0.00296, +0.00177] | 否 |

**关键点**：先前"排除类别 03"的结论**在纳入 03 之后依然成立**（区间照样跨零），所以那个范围限制**不再是缺陷**，可以放心写进正文。同时回归检查通过：与 S 研究已发布的修正口径一致（4 项比较最大差 6.98e-08），且"嵌套性"检查 16 项零违反。

**② 同一类几何错误在 VisA 上被再次发现并修掉。**

导出 VisA 的 B 分支缓存时触发了新加的**画布守卫**：缓存的掩膜是 **448×448（正方形压缩）**，而正确画布是 **448×490**（candle 原图 1168×1284，短边 448、长边裁到 14 的倍数 490）。

- 受影响的 **36 个单元**全部从数据集原始掩膜按同一规则重建，并逐个记录在导出报告里（`masks_rebuilt_on_canvas`）；
- **MVTec 不受影响，因为它本身是正方形图像**——正方形恰好把这个 bug 掩盖住了。

> 这件事值得单独记一笔：**BTAD 的几何错误和 VisA 的几何错误是同一类**（"缩放时把长宽比弄丢了"），一个出在真值掩膜、一个出在缓存掩膜。说明这类缺陷不是偶然，而是需要**自动守卫**而不是靠人眼检查。

# 6. 结果：一条故事线（十四步）

这一章是重点。论文的结果部分看着零散，其实是一条链。我按"逻辑顺序"重讲一遍，而不是按表格编号。

## 第 1 步：先打两个地基

任何结论都要先确认两件基本功（§4.2.1）。

**地基一：融合比单个编码器好。**
MPDD 上各配置的像素 AP：

| | B 单独 | S 单独 | C 单独 | A1 融合（J） | A1 融合（L） |
|---|---|---|---|---|---|
| 像素 AP | 0.348 | 0.326 | 0.283 | **0.3729** | **0.3791** |

三个单分支**都低于**融合锚点。所以研究保留融合锚点是有道理的，不需要先争论"一个编码器够不够"。

（BTAD 上的锚点是 0.6408（J）/ 0.6498（L），但它没有与上面这些单分支同几何版本的对照数据。）

> 注意：BTAD 的单分支诊断**故意不报**。因为 BTAD 的几何重算只覆盖了那 8 个交互构造，把两批不同几何的结果放一起比，会把"几何差异"当成"编码器差异"。

**地基二：L 规则本身确实更好。**
这就是**匹配效应 $M = P(L) - P(J)$**。因为支持图、描述子、权重全都没变，**只有选择规则变了**，所以这个量干净地反映"规则本身值多少"。

| | A1 的 $M$ | 其他构造 |
|---|---|---|
| MPDD | **+0.618**（区间排除零） | 同向，从 +0.321（DUP）到 +1.213（BAL） |
| BTAD（修正后） | **+0.900**（区间排除零） | 同向 |

**但这里要停一下**：规则让**所有**构造都变好了，**不能**因此说"新加的表征也从这个规则受益"。那是第 3、4 步的问题。

## 第 2 步：证明"复制一个分支"也能改性能

这是全文方法论的支点（§4.2.2）。

**结果**：DUP（就是 B+B+C，信息没多）在**两个数据集、两种规则**下，**全都低于** A1。MPDD 上大约是 **−0.80（J）** 和 **−1.10（L）**。

**所以呢**：
> **把分支数从 2 变成 3，可以在不引入任何新信息的情况下改变性能。**

这一个结果直接判了"三分支减双分支"这种比法的死刑。也解释了为什么全文都用 TRI−DUP 而不是 TRI−A1——**TRI−A1 里面混了一半的权重重排，不是新编码器的贡献**。

## 第 3 步：MPDD 上，S 的效应本身不确定，但交互很确定

这是最容易读错的一步，要分两层看。

**第一层：绝对表征效应（表 6）**

| 对比 | J 下 | L 下 | L 的 95% 区间 |
|---|---|---|---|
| TRI − DUP | −0.224 | **+0.548** | [−0.092, +1.160] ← **跨零** |
| BAL − A1 | −0.510 | +0.085 | 跨零 |

**白话解读**：
- J 规则下，把副本换成 S，性能**掉了** 0.224 个点；
- L 规则下，同一次替换，性能**涨了** 0.548 个点；
- **但**这个 +0.548 的区间从 −0.092 到 +1.160，**包含了零** → 所以"加 S 在 MPDD 上带来了绝对提升"这句话**还不能说**。

论文原话就是这个意思："独立匹配让观察到的替换变得更有利，但**不应该改写成**在 MPDD 上加 S 确立了绝对提升"。

**第二层：交互（表 7）**

| 对比 | 交互 | 98.75% 校正区间 |
|---|---|---|
| TRI | **+0.772** | [+0.346, +1.211] ← **排除零** |
| BAL | **+0.595** | [+0.189, +1.030] ← **排除零** |

**白话解读（这是全文最微妙的一点）**：
> **"效应本身不确定"和"效应依赖规则"可以同时成立。**

翻译成话就是：我们**说不准** S 在 MPDD 上到底有没有用（可能有用，也可能是零），但我们**能确定**它的作用**随规则剧烈变化**——在 J 下是负的，在 L 下是正的，这个"翻转"本身是稳的。

**还要注意一个细节**：交互的点估计（+0.772）超过了 0.5 那个描述性尺度，但**区间的下界（+0.346）没有**。所以论文的写法是"点估计超过该尺度，但区间下界没有，因此数据不足以确立效应一致高于该量级"。摘要里选的是"区间不含零"这个更稳的说法。

## 第 4 步：BTAD 上完全反过来——S 很有用，但不依赖规则

同样两层（表 6 / 表 7）：

**第一层：绝对效应**

| 对比 | J 下 | L 下 |
|---|---|---|
| TRI − DUP | **+1.553** | **+1.503** |
| BAL − A1 | 正 | 正 |

两个规则的 95% 区间**都在零以上** → 这次是**真的有用**，而且很有用（涨 1.5 个点）。

**第二层：交互**

| 对比 | 交互 | 98.75% 校正区间 |
|---|---|---|
| TRI | −0.050 | [−0.235, +0.244] ← **跨零** |
| BAL | −0.119 | [−0.306, +0.167] ← **跨零** |

**白话解读**：
> 把 S 换进去，两个规则下都涨 1.5 个点，两次几乎一样 → **很有用，但完全不在乎你用哪种规则**。

**这就是论文最重要的一个对照**（第 3 步和第 4 步放在一起看）：

| | S 有没有用？（效应 $E$） | 用不用在乎规则？（交互 $I$） |
|---|---|---|
| MPDD | ❓ 不确定 | ✅ 很依赖（+0.77） |
| BTAD | ✅ 很有用（+1.5） | ❌ 不依赖（≈ 0） |

**这两个问题给出的答案完全交叉**，所以论文说：**它们是两件不同的事，不能用一个数字回答。**

**一条纪律**：BTAD 那两个小的负数（−0.050、−0.119）**不是**"J 规则普遍更好的证据"；区间跨零只能说"**方向证据不足**"，**不能**说"两种规则等价"。

## 第 5 步：换一个异构编码器 D，两个数据集都变成正交互

前面所有结论都是用 **DINOv2-S** 得到的。这里有个天然质疑：**S 和 B 都是 DINOv2 家族的**，会不会"正交互"只是"同门小模型的产物"？

所以论文换上了 **WideResNet50-2（记作 D）**：卷积网络、ImageNet 有监督预训练，跟前面三个（DINOv2-B、DINOv2-S、CLIP）**都不是一族**。而且规格是**预指定**的（看到结果之前就冻结）。

**先看绝对效应（表 8，全像素）：**

| | TRI_D_L | DUP_L |
|---|---|---|
| MPDD | 0.4107 | 0.3554 |
| BTAD | 0.6591 | 0.6335 |

对应的全像素表征效应约 **+5.53** 和 **+2.57** 个点。

> **这里要特别注意**：+5.53 是**绝对效应**，不是那个小得多的**交互**。两个量差了一个数量级，千万别混。
> 另外，**D 单独使用时的像素 AP 比这些融合构造更低**——所以融合结果不能用"挑 D 自己的分数"来解释。

**再看交互（表 9）：**

| | TRI | BAL |
|---|---|---|
| MPDD | **+0.974** | **+0.628** |
| BTAD | **+0.622** | **+0.501** |

**四个全为正，四个校正区间全部排除零。** 全像素点估计保持同样的方向。

**所以呢**：
> "正交互"**不是**"只有加同家族的小 DINOv2 才会出现"的现象。

**但边界也要说清**：这只证明了**在这两个数据集上、对这个特定的卷积编码器**成立，**不能**推广到"任意卷积骨干"或"任意数据集"。

### 第 5 步的补充：再加两个编码器，把"任意卷积骨干"这句话顶回去

D 只是**一个**卷积编码器，"孤证"正是审稿最容易攻击的地方。所以本轮补了**两个不同家族的冻结编码器**（规格在看到任何结果前就冻结；但因为是在 D 之后做的，只能算**事后探索性**）：

| 编码器 | 是什么 | patch / 步长 | 维度 | **单分支 AUROC**（48 单元） |
|---|---|---|---|---|
| **S** | DINOv2-S（ViT-S/14） | 14 | 384 | 基线 |
| **D** | WideResNet50-2（ImageNet 有监督） | 8 / 16 | 1536 | 约 0.94（参照） |
| **E1** | **DINO `deiT-small/8`**（原始自蒸馏 DINO） | **8** | 384 | min 0.9163 / 均值 0.9668 / max 0.9917 |
| **E2** | **ConvNeXt-Tiny**（ImageNet 有监督） | 8 / 16 | 576 | min 0.8871 / 均值 0.9529 / max 0.9844 |

**为什么这两个选得有价值**：E1 是**小 patch 的 ViT**，E2 是**现代分层卷积**——连同 D 的老式卷积，一共跨了三个家族。三者的 AUROC 最低也有 0.887（远高于 0.5），说明对齐、归一化、打分链路都是对的，读数可信。（校验方式：用新代码路径去驱动**已发布的 D 编码器**，20 项比较最大差 **0.0**，逐位复现。）

**四编码器交互并列表**（步长 8、像素 AP；BTAD 用修正口径）：

| 数据集 | 交互 | S | D | E1 | E2 |
|---|---|---|---|---|---|

- 原来的说法是"**不是只有 DINOv2 家族才有正交互**"，现在可以更进一步：**在 BTAD 上，三个额外编码器里有两个（D、E1）显著大于 S，且方向一致**；
- 但**不能**说"所有编码器都这样"：MPDD 上 **E2（ConvNeXt-Tiny）的交互显著为负**，它相对 S 的差值也**显著为负**——也就是说在 MPDD 上换成 ConvNeXt，会让"匹配依赖"**消失甚至反向**；
- 所以正确的结论是：**交互依赖编码器**（被三个额外分支重复确认），**而不是"正交互是普遍现象"**。这恰好和"交互随数据条件而变"拼成一张完整的图。

**一条纪律**：E1/E2 属**事后探索性**，正文必须写明它们的规格冻结在 D 的结果**之后**，作用是**支持性证据**，不是独立的预指定检验。

## 第 6 步：D 的交互比 S 大多少？

**一个错误做法**：直接拿第 5 步的 D 表格和第 3/4 步的 S 表格对比。为什么不行？因为两批实验用的**种子和预算范围不一样**（D 只用 seed 0/1 和 K=1/4），直接比会把"支持条件覆盖不同"当成"编码器差异"。

**正确做法（表 10）**：把 S 也限制到 D 用的那些种子和预算，然后直接估计差值 $D_q = I_q^{(D)} - I_q^{(S)}$。

| | 观测差值 | 98.75% 校正区间 | 结论 |
|---|---|---|---|
| BTAD · TRI | +0.623 | [+0.255, +0.945] | 排除零 → **D 的交互确实更大** |
| BTAD · BAL | +0.585 | [+0.204, +1.060] | 排除零 → 同上 |
| MPDD · TRI | +0.207 | 跨零 | **未能分辨** |
| MPDD · BAL | +0.081 | 跨零 | **未能分辨** |

**白话解读**：
- BTAD 上：**能确定** D 的交互比 S 大。
- MPDD 上：**说不准**谁大谁小 → 论文写的是"不确定性不足以分辨差异"，而**不是**"两个编码器等价"。

（另外，表 10 里"观测差值"和"bootstrap 均值"是**两列**，因为两者不相等——尤其 MPDD 上差得比较明显。论文刻意不把 bootstrap 均值冒充点估计。）

**一个必须并列读的反例**：BTAD 四条件下，`BAL D L` 的**全像素 AP 更高**，但它的**图像级 AP 是 0.9372，低于 `A1 L` 的 0.9468**。

> **所以"交互更大"完全不等于"每个指标都更好"。** 图像级打分和像素级排序回答的是两个不同的评价问题。

## 第 7 步：结论会随条件变（预算与类别）

**预算曲线（图 5a）**——看 K 从 1 增加到 8 时交互怎么变：

| K | 1 | 2 | 4 | 8 |
|---|---|---|---|---|
| **MPDD** · TRI | +0.41 | +0.75 | +0.88 | **+1.01** |
| **MPDD** · BAL | +0.37 | — | — | +0.83 |
| **BTAD**（修正后）· TRI | +0.20 | +0.09 | −0.14 | **−0.23** |

**白话解读**：
- MPDD：**正常参考越多，交互越强**（单调上升）。
- BTAD：**反过来，而且变号**，到 K=8 时已经是 −0.23，而且区间**不再包含零**。

> **所以论文说的是"预算依赖的描述"，而不是"更多正常参考总会放大独立匹配的好处"这种单调律。** 两个数据集方向相反，就不可能有普遍规律。

**为什么不能从数学上推出单调性**：当参考库是嵌套的（大预算包含小预算的全部参考），**最小原始距离**确实只会变小不会变大。但 ① AP 看的是排序，② 交互是**四个性能值的差**。所以距离的单调性**不能**传递到 AP，更不能传递到交互。

**逐类别（图 5b）**：
- MPDD **六类全部为正**，connector（连接器）和 tubes（管件）领先；
- BTAD **三类都接近零**，类别 02 还略负。

**留一类别检验（每次去掉一个类别再算）**：
- MPDD：去掉**任何**一类，TRI 的聚合交互仍然为正 → 结论不靠某一类撑着；
- BTAD：去掉类别 02，聚合交互的**方向会翻转** → 只有 3 个类别时，平均值对组成极其敏感。

**纪律**：逐类别、逐预算的区间**不继承**主族的校正保证，它们只是"探索性后续分析"，用来指出"值得在新数据上验证的条件"，**不是**"类别身份或缺陷尺寸有因果作用"的证明。

## 第 8 步：定性案例——AP 好不等于边界画得准

图 6 和图 7 展示了 MPDD 的 **5 个案例**（seed 0、K=4）：其中 **3 个是 A1 L 相对 A1 J 改善，2 个是退化**。

**案例是怎么挑的**：按**存储的逐图像 AP 变化极值**挑（改善最大的几个、退化最大的几个）。**不是**按"原始分数平均下降多少"挑——因为那个和定位好坏不是一回事。

**图是怎么画的**（这套规则很值得记，答辩可能被问）：
- 同一个案例的 J 图和 L 图**共用同一个最小/最大值**做归一化，否则两张图颜色没法比；
- L 图量化成 256 个箱，用 **Otsu 法**（最大化类间方差）选一个可视化阈值，如果并列就取最小的那个；
- 青色轮廓**完全来自模型分数**，是真值掩膜之外的独立输出；
- 裁剪框：以**真值掩膜包围盒**为中心，扩大 1.8 倍，边长限制在 **96 到 260 像素**之间；同一列所有面板用同一个裁剪框。

**论文在这里的克制**：AP 改善**不等于**任意阈值下边界都画得准。图里的小轮廓可能只覆盖了划痕最强的那一段，其余位置的次级响应还在别处。所以论文把三件事**明确分开**：

1. 连续的定位证据（分数图）
2. 阈值化的可视化（Otsu 轮廓）
3. 部署用的分割精度

**并且绝不用真值轮廓冒充模型的预测输出。**

## 第 11 步：几何"对应"本身不需要是对的（本轮新增）

这一步回答一个很尖锐的质疑：**把 B 的 patch 和 C 的 patch 当成"同一块地方"，这个假设站得住吗？**

**先审计、不假设**（MPDD 全部单元 + BTAD 12 个单元）：

| 指标 | MPDD | BTAD | 白话 |
|---|---|---|---|
| `exact`（B 与 C 选中的参考**完全同一行**） | 5.9% | 13.3% | 很低 |
| `within_1`（位置差 ≤ 1） | 29.1% | 37.0% | 也不高 |
| **置换基线**（把对应关系打乱后） | **0.058%** | **0.050%** | 几乎为零 |
| `cycle`（往返一圈能否回到原处） | 11.4% | 26.0% | 低 |
| **位置信息量**（exact − 置换基线） | **5.87%** | **13.24%** | 有信息，但很弱 |

**怎么读**：绝对对应率很低（5.9% ~ 13.3%），说明"同一个网格位置 = 同一个物体部位"**基本不成立**；但它**显著高于随机置换基线**（约 0.05%），所以也不是完全没有位置信息。

**然后是关键实验**——既然对应这么弱，把对应**换掉**会怎样？（**MPDD 与 BTAD 都已跑**；下表先列 MPDD 的前三种）

| 变体 | 做了什么 | I_TRI | I_BAL |
|---|---|---|---|
| `identity`（现状） | 什么都不改 | +0.77 ✅ | +0.55 ✅ |
| `procrustes`（学习式对应） | 用支持集参考**拟合一个线性变换 W**，把 C 的空间映射到 B | +0.77 ✅ | +0.55 ✅ |
| `shuffled`（故意破坏对应） | 打乱 C 的位置索引 | +0.80 ✅ | +0.81 ✅ |

**这三个变体都排除零，而且数字几乎一样。**（MPDD 另跑了第 4 种 OT 软对应：点估计仍为正，其 98.75% 区间同样排除零；MPDD 上四种对应方式与 ε 网格共 14 条区间**全部排除零**，其中最弱的格是 ε=0.05 的 `I_BAL`，下界仅 +0.006 点。BTAD 上四个变体与 ε 网格共 14 条区间全部跨零。）

- 那个 Procrustes 解的 $\|W-I\|_F \approx 39.2$（离单位阵很远），说明它**确实学到了一个"很不一样"的对齐**——但**交互完全没变**；
- 就算**故意打乱**对应关系，交互照样在，甚至略大。

> **所以：这个交互既不依赖"画布对应是对的"，也不依赖"两个分支的特征空间是对齐的"。** 本文的结论**不建立在那个可疑的假设上**——这比"我们假设对应是对的"强得多。

**边界**：早期这三种变体只覆盖 MPDD，现两个数据集都已补齐四个变体与 ε 网格。MPDD 上 14 条区间**全部排除零**，所以「方向不随对应方式改变」与「区间排除零」两句话都成立（最弱的格是 ε=0.05 的 `I_BAL`，下界仅 +0.006 点）；BTAD 上 14 条区间全部跨零，其判定本来就是「方向证据不足」。而 `identity` 与 `procrustes` 完全相同这件事本身也说明："学一个线性对齐"在这套流水线里没有带来可见变化。

→ "一个样本点"不足以支撑"所有卷积骨干都这样"。
→ **状态：已补强，正文必须改写。** 现在有 **D、E1、E2 三个额外编码器**（跨老式卷积、小 patch ViT、现代分层卷积三族）。但结论要写得比原来更精确：**"交互依赖编码器"被重复确认，而"正交互"不是普遍现象**——MPDD 上 ConvNeXt-Tiny 的交互**显著为负**。而且 E1/E2 是**事后探索性**的，不能和预指定的 D 平起平坐。

**④ 全像素没有区间；完整的部署资源测量也拿不到。**
→ "方向一致"不能被升级成"全像素也显著"。也不会有"哪种方案更快"的结论。
→ **状态：仍然缺失。** 补充：VisA 批次是混合设备的，所以它上面的计时/显存**不能**直接进资源图。

**⑤ 定性案例是挑出来的极端，Otsu 轮廓是显示选择而不是标定的缺陷掩膜。**
→ 5 个案例说明不了普遍规律；轮廓也说明不了分割精度。
→ **状态：未变。**

**⑥ 所有构造共享的操作（空间映射、分支归一化、从拼接描述子打分）是固定的、没有做消融的。**
→ 这是最容易被忽略的一条。意思是：本文**不量化**这三个共享步骤各自贡献多少，也**不把它们当作已验证的模块**。想做消融得单独设计实验。
→ **状态：仍然缺失。** 这是本轮**没有**触及的一个空档（本轮做的是"几何对应的审计与替换"，那是评测口径，不是那三个共享操作本身）。

**⑦ 几何对齐是"确定性的画布对应"，不是"感受野描述同一物体部位"的学习保证。**
→ 把两层特征图缩放到同一尺寸，只保证**坐标**对得上，不保证**语义**对得上。
→ **状态：已转化为正面证据，正文要改写。** 现在有了两条实测：① 审计显示绝对对应率只有 5.9%（MPDD）/ 13.3%（BTAD），**远高于**随机置换（0.05%）但绝对水平很低；② **把对应换成 Procrustes 学习式对齐、甚至故意打乱，交互都不变**。所以正确的写法是：**这个限制不构成对结论的威胁**——结论不依赖那个假设。（覆盖范围限 MPDD。）

### 本轮新暴露出来的边界（手稿里还没有，动笔要加）

| 新边界 | 说明 |
|---|---|
| **E1/E2 是事后探索性** | 规格冻结在 D 的结果**之后**，不能声称预指定。必须在正文明确标注。 |
| **B2 的对应替换只在 MPDD 上做过** | BTAD 没跑。所以"交互不依赖对应"这条证据**限于 MPDD**。 |
| **MVTec/VisA 的统计区间尚未产出** | 只能说"矩阵已完整跑完 324/324"，**不能**报任何交互数字。 |

**最后一段的态度很重要**，值得原样记住：

> 这些局限**不会**把一个"负结果或不确定结果"变成失败的实验。BTAD 配 S 恰好把"正的表征价值"和"不确定的匹配依赖"分开了；D 的比较则在匹配条件下给出了编码器特异性差异。**一篇受控的、有界的研究，其贡献就是这个。**

# 8. 术语小词典

按"读论文时会卡住"的顺序排。

| 术语 | 白话解释 |
|---|---|
| **AP（平均精度）** | 衡量"异常像素的分数是否排在正常像素前面"的指标。本文的首要指标。 |
| **AUROC** | 另一个排序指标，本文只当辅助诊断，**不用它替换 AP** 来解读主要交互。 |
| **像素 AP vs 图像 AP** | 像素 AP 评"每个像素排得对不对"；图像 AP 评"整张图的分对不对"。**两者可以结论相反**（本文就有这样的例子）。 |
| **类别宏平均** | 先把每个类别内部的像素汇总算一个 AP，再把各类别的 AP **等权平均**。这**不同于**把所有类别汇成一个 AP，也**不同于**先算每张图的 AP 再平均。 |
| **冻结编码器** | 骨干网络的参数不动、不做目标域微调，只当成特征提取器。所以本文没有学习率、训练轮数、损失曲线这类东西。 |
| **patch / 描述子** | `patch` 是图像上的一个小方块；`描述子`是编码器给这个方块输出的向量。逐个 patch 比较就是逐个向量比距离。 |
| **支持集 / 支持预算 K** | 支持集 = 当作参照物的那几张正常图；K = 用几张。 |
| **种子（seed）** | 决定"从各类别的所有正常图里抽哪几张"。换种子 = 换一批参照物。 |
| **记忆库 / 参考库** | 把所有正常图的 patch 描述子收集起来的集合，查询时从中找"最像的"。 |
| **联合匹配 J** | 所有分支必须指向**同一张**正常 patch，再合并。 |
| **独立匹配 L** | 每个分支各挑各的最像的 patch，再合并。 |
| **有效权重** | 某分支在最终距离里的总占比。复制一份分支会改变它，但这与"新信息"无关。 |
| **约束差 $G$** | $d^J - d^L \ge 0$。度量"强行要求共用参考"带来的分数代价。**它衡量的是距离，不是定位性能。** |
| **表征效应 $E$** | 换入新表征（相对匹配对照）带来的性能变化。 |
| **交互 $I$** | 同一个表征效应在 L 和 J 下的差。回答"这份用处依不依赖规则"。 |
| **配对（paired）** | 比较双方在完全相同的条件下计算（同一批图、同一种子、同一次重采样副本），先把共有的波动消掉。 |
| **bootstrap（自助重采样）** | 从观测数据里有放回地反复抽样，用重复的波动来估计不确定性。本文做 1000 次。 |
| **重采样副本（replicate）** | 上述 1000 次中的**一次**抽样结果。本文的差值都在副本内部先算。 |
| **95% / 98.75% 区间** | 95% 是单次比较的常用标准；98.75% 是做了 4 次比较后的校正标准（0.05/4）。校正后区间更宽。 |
| **Bonferroni 校正** | 一种最简单的多重比较校正：把显著性水平除以比较次数。粗暴但通用。 |
| **族（family）** | 校正的作用范围。本文有三族，各族内部用 98.75%；**族外不继承**。 |
| **区间跨零** | 区间同时包含正数和负数 → 无法判断方向 → **只能说"证据不足"，不能说"等价"。** |
| **步长 8（stride-eight）** | 每 8 个像素取一个采样点。有区间；全像素没有。 |
| **共同有效区域交集** | 两种方法都能给出预测的那部分像素，只在它上面比较，避免在裁掉的边缘凭空编造预测。 |
| **Otsu 阈值** | 一种自动找分割阈值的经典方法：选那个让"类间方差最大"的阈值。本文只用于**画示意图**，不是部署阈值。 |
| **预指定（prespecified）** | 规格在看到结果前就冻结，防止"试了很多选项挑一个最好看的"。 |
| **点估计 / 自助均值 / 区间** | **三个不同的东西**，不是"同一东西的粗细两档"。点估计 = 用原始数据一次算出的单个数（不挂概率）；自助均值 = 1000 次重采样结果的平均；区间 = 那 1000 个值切出来的分位段。论文把它们分列，**不拿自助均值冒充点估计**。 |
| **编码器差值 $\Delta I_q$** | 同一个交互、同一个对照 $q$，在两个编码器上的差（如 D 相对 S）。$q \in \{\text{TRI}, \text{BAL}\}$。**只能同一个 q 内部相减**，跨 q 会把"编码器差异"和"权重分配差异"混在一起。 |
| **位置信息量（positional information）** | 实际对应率减去随机置换基线。用来判断"网格位置对应"里到底有没有真信息：5.87%（MPDD）/ 13.24%（BTAD）——有，但很弱。 |
| **置换基线（permutation baseline）** | 把对应关系随机打乱后的对应率，约 **0.05%**。任何"对应有效"的说法都必须先超过它。 |
| **循环一致性（cycle consistency）** | 从 B 对应到 C、再从 C 对应回 B，看能不能回到原处。本文 11.4%（MPDD）/ 26.0%（BTAD）。 |
| **Procrustes 对齐** | 用支持集参考拟合一个**线性变换**，把一个分支的特征空间映射到另一个分支。本文的 $\|W-I\|_F \approx 39.2$（离单位阵很远），但**对交互没有任何可见影响**。 |
| **画布守卫（canvas guard）** | 一个自动检查：缓存掩膜的形状必须等于"画布网格 × 步长"，不符就按同一规则从原始数据集重建并记录。**VisA 的正方形压缩缺陷就是它抓出来的**（MVTec 因为是正方形图，侥幸没暴露）。 |
| **只增不改守卫** | 新实验启动前对已有缓存做快照，跑完逐一比对 size + mtime，确保**旧产物一个都没被改动**。种子扩展这次是 78 个文件零改动。 |
| **支持集方差** | 把交互的波动拆成"换支持集引起的"和"其他来源"。这是 bootstrap 区间**回答不了**的那一半——bootstrap 只重采样测试图。 |
| **泛化数据集 vs 确认集** | **泛化数据集**（MVTec/VisA）：跑同一套设计看结论是否重现，但数据参与过旧项目，所以不构成"确认"。**确认集**：事先冻结规格、只打开一次、未被碰过 —— 本文**仍然没有**。 |
| **事后探索性（post hoc）** | 规格是在看到别的结果**之后**才冻结的。这类结果只能当支持性证据，不能声称预指定。本文的 E1/E2 就属于这一类。 |
| **设备偏离（device deviation）** | 同一批实验中途换了运行设备/框架版本。本文 VisA 批次前 55 个单元跑 CPU、其余跑 GPU，数值等价（最大差 6.5e-07），但**计时口径不干净**。 |

# 9. 最容易误解的地方

| 你可能读成 | 论文实际的口径 |
|---|---|
| "TRI − A1 说明加 S 没用" | TRI − A1 混入了权重重排，**必须看 TRI − DUP** |
| "$d^L \le d^J$，所以 L 定位更准" | 那个不等式约束的是**距离**；AP 看的是**排序**。必须实测，不能推。 |
| "J 显著、L 也显著 → 说明有交互" | 交互是**差值的检验**，不能用两个独立的显著性判断拼出来 |
| "BTAD 交互跨零 → 两种规则一样好" | 区间跨零 = **方向证据不足**，**不等于**等价 |
| "D 的 +0.97 比 S 的 +0.77 大，所以 D 更好" | 那只在 **BTAD** 上成立；MPDD 的 S→D 差值跨零。而且"交互大"≠"每个指标都好"（`BAL D L` 的图像 AP 就更低） |

**再加几条最隐蔽的**（第 1 条是原有的，后 7 条由本轮新增证据带出来）：

| 你可能读成 | 论文实际的口径 |
|---|---|
| "为了加第三个编码器才把分支数从 2 变 3，性能变了就是新编码器的功劳" | **复制一个分支**（不加任何信息）也能改变性能（DUP 在两个数据集两种规则下都低于 A1）。所以功劳不能直接归给新编码器。 |
| "MVTec/VisA 的 324 个单元都跑完了 → 泛化已经验证了" | **矩阵跑完 ≠ 结论已出**。逐单元分数有了，但聚合成交互区间的那一步**还没跑**。现在**不能**报任何 MVTec/VisA 的交互数字。 |
| "E1/E2 和 D 一样，都是预指定的" | D 是**预指定**；E1/E2 的规格冻结在 D 的结果**之后**，属**事后探索性**。两者证据等级不同，正文必须分开写。 |
| "B 和 C 的对应率只有 5.9% → 这套方法的前提站不住" | 对应率确实低，但**把对应换成学习式对齐、甚至故意打乱，交互都不变**。结论不依赖那个假设——低对应率反而是这条正面证据的背景。 |
| "MPDD 上 ConvNeXt 的交互是负的 → 说明'正交互'这个结论错了" | 它说明的是**交互依赖编码器**（本来就是本文的论点之一），**不是**"正交互不存在"。BTAD 上三个额外编码器里有两个显著为正。 |
| "E2 在 MPDD 的 I_BAL 差值 95% 下排除零 → 算显著" | 主口径是 **98.75%**。它在 98.75% 下跨零，所以记为"未能分辨"。换口径取结果属于选择性报告。 |
| "点估计 +0.772 超过 0.5，所以重要性确立了" | **区间下界只有 +0.346**，落在 0.5 以下。只能说"点估计超过该尺度"，不能说"效应一致高于这个量级"。 |
| "BTAD 的细网格以前只覆盖两个类别，结果不完整" | 这个范围限制**本轮已解除**：细网格区间现在覆盖全部三类，区间照样跨零，结论不变。 |

# 10. 如果被追问，怎么答

**Q1：MVTec AD 和 VisA 到底用不用？**
A：分两层，别混。① **旧项目的那两批实验不能复用**——它们评的不是这套"表征 × 匹配规则"的设计，直接拿来就是"用旧数据撑新结论"。② 本轮已经在这两套数据上**重新跑**了这套新设计，矩阵完整产出 **324/324** 个单元（MVTec 180 + VisA 144）。但它们的定位是**泛化数据集**，不是确认集：两套数据都参与过旧项目，VisA 的 CLIP 分支权重还在 VisA 上训练过（所以只是"域内"验证）。而且**统计区间尚未跑出**，现在还不能报数字。

**Q2：为什么主要指标是像素 AP，不用 AUROC？**
A：缺陷像素很稀疏，AP 同时强调精度和召回；AUROC 只当辅助诊断，而且**不用它替换 AP** 来解读主要交互。

**Q3：为什么都只用步长 8 出区间？**
A：1000 次重采样若每像素都算，成本过高。代价是小缺陷可能只落到少数采样点，所以必须再用全像素做一次方向核对——而全像素只有点估计，**不能**声称显著。

**Q4：为什么 MPDD 上"效应不确定但交互确定"不矛盾？**
A：这是两个不同的问题。效应问"换 S 有没有用"，可能有用也可能是零；交互问"它的作用随规则变多少"。前者说不准，后者可以说得准——因为在 J 下是负的、L 下是正的，这个**翻转方向**本身很稳定。

**Q5：为什么说 BTAD 的三类结果不能当普遍规律？**
A：只有 3 个类别，去掉类别 02 聚合交互的**方向就会翻转**。所以论文把逐类别分析定位成"探索性、值得在新数据上验证"，不继承主族的校正保证。**补一句本轮的进展**：BTAD-03 细网格区间过去只覆盖 01/02，现在已补齐全部三类，结论不变（区间照样跨零）——所以"范围限制"这条**已解除**；但"只有 3 类 ⇒ 逐类别结论脆弱"这条**没变**。

**Q6：为什么不做运行速度对比？**
A：A1 缺可比的逐单位计时，PatchCore 缺逐进程显存峰值，两者不可拆。**把这些缺口填上的图会是误导性的**，所以只报有记录的分阶段耗时。补充一条本轮的新理由：**VisA 批次是混合设备的**（前 55 个单元 CPU、其余 GPU），所以它上面的计时/显存**不能**进资源图，除非单独重测。

**Q7：这篇的创新点到底在哪？**
A：**不**在新算子（联合/独立匹配是已有的）。创新在：① 把"参考选择"在固定融合里做成了可以干净比较的形式；② 用"复制分支"和"权重保持"两个对照，把"重新加权"从"新表征"里剥出来；③ 用交叉设计直接估计"表征 × 匹配规则"的交互，并给出"交互依赖编码器和数据条件、不能仅由分支数量解释"的证据。

**Q8：如果我要接着做，最该补什么？**
A：先分清"已经在补"和"还缺"两类。

**已经在补（数据备齐、等分析）**：

- **换支持集的稳定性** —— 种子 3..7 的矩阵已跑完、清单独立复现通过、"只增不改"守卫通过，只差**方差分解**；
- **换数据集的稳定性** —— MVTec/VisA 的 **324/324** 个单元已跑完，只差**统计区间**。

**仍然缺的（按优先级）**：

1. **未被碰过的确认集** —— 唯一**无法事后补**的一条，必须事先冻结规格、只打开一次，而且**负结果也要如实报**；
2. **共享操作的消融** —— 空间映射、分支归一化、拼接打分这三步所有构造共用，至今**没有**量化各自贡献；
3. **全像素区间** 与 **完整的部署成本测量** —— 前者成本高，后者受"PatchCore 缺逐进程显存、A1 缺逐单位计时"限制。

**Q9：E1/E2 和 D 有什么本质区别？**
A：**证据等级。** D 是**预指定**的（规格冻结在看到任何结果之前）；E1/E2 的规格冻结在 **D 的结果已知之后**，属**事后探索性**。它们能当支持性证据（"交互依赖编码器"被重复确认），但不能声称是独立的预指定检验。正文里必须分开写，否则就是"把事后探索伪装成预指定"。

**Q10：B/C 的几何对应率只有 5.9%，这不是致命问题吗？**
A：不是——而且这一条已经从弱点**变成了正面证据**。审计确认对应率确实低（MPDD 5.9%、BTAD 13.3%），但远高于随机置换基线（0.05%）；更关键的是，**把对应换成 Procrustes 学习式对齐、甚至故意打乱位置，交互都不变**（三个变体都排除零、数字几乎一样）。所以结论**不依赖**"画布对应是对的"这个假设。（覆盖面限 MPDD。）

**Q11：MVTec/VisA 的结果出来了吗？**
A：**矩阵出来了，结论没出来。** 324/324 个单元全部跑完，但把逐单元分数聚合成交互区间的那一步尚未完成。所以现在**不能**写任何 MVTec/VisA 的交互数字——写了就是编造。另外两点必须记住：VisA 是**域内**验证（CLIP 权重在它上面训练过）；它那批还是**混合设备**跑出来的（数值等价，但计时口径不干净）。

**Q12：为什么用 98.75% 而不是常见的 95%？**
A：因为主分析同时做 4 个比较（2 种构造 × 2 个数据集），不校正的话"至少错一次"的概率明显高于 5%。Bonferroni 给出 1 − 0.05/4 = **98.75%**。切得更宽 → 更**难**排除零 → 所以"98.75% 下排除零"是比 95% **更强**的陈述。注意 95% 和 98.75% 是**同一套 1000 次重采样**切不同分位点，**不是**两次实验。

**Q13：点估计、自助均值、区间，是"同一东西的粗细两档"吗？**
A：**不是，是三个不同的量。** 点估计 = 用原始数据一次算出的单个数（**不挂任何概率**）；自助均值 = 1000 次重采样结果的平均；区间 = 那 1000 个值切出的分位段。而"95% vs 98.75%"是**区间内部**的粗细区别，和"点估计 vs 区间"这条轴**无关**。论文把点估计与自助均值**分两列报**，就是不许混称。

**Q14：这一轮新增证据最需要防的写作事故是什么？**
A：**把"正在补"写成"已经补上"。** 具体是两种：① 说"MVTec/VisA 已泛化验证"，但统计区间还没跑；② 说"种子稳健性已确立"，但方差分解还没跑。这两处目前都只能写"数据已备齐、验证通过、分析待跑"。另外三种是：把 E1/E2 说成预指定、把 95% 排除零说成显著、把点估计超 0.5 说成重要性确立。
