## 摘要（Abstract）

少样本工业异常定位（few-shot industrial anomaly localization）使用少量正常图像来找出未见查询图中的异常区域。组合预训练视觉编码器（pretrained visual encoders）可以丰富可用的描述子，但增加一个分支同时也会改变有效权重（effective weights）以及被选作参考的正常 patch。本文研究：**新增一个表征所带来的收益，是否取决于这一「参考选择」约束**。在编码器冻结（frozen encoders）、共享支持图像（shared support images）、距离权重固定（fixed distance weights）的条件下，我们比较两种规则：**联合匹配**（joint matching，在所有分支中选出同一个参考 patch）与**独立匹配**（independent matching，每个分支各自选一个参考）。复制分支对照与保持权重的对照把「新增表征」与「重新加权」区分开；表征效应之间的配对差值则量化它们与匹配规则之间的**交互**（interaction）。加入 DINOv2-S 后，在 MPDD 上得到 +0.77 与 +0.60 个像素平均精度百分点（percentage points）的正交互，经多重比较校正后的区间不含零；而在 BTAD 上，证据不足以支持存在交互。一个预先指定的 WideResNet50-2 分支在两个数据集上都给出 +0.50～+0.97 个百分点的正交互。以上估计基于步长 8（stride-eight）的像素评价；全像素（full-pixel）点估计保持了方向一致。结果表明：**「新增分支的价值」与「该价值对匹配规则的依赖」是两件不同的事**，后者随编码器与数据条件而变，并不能仅由分支数量解释。一个在任何特征被编码之前就已冻结预期的确认集**满足**该预期：两支编码器、两种对比的交互都为正；同一组对比在四个数据集上分别表现为 MPDD、MVTec AD 与 VisA 为正、BTAD 点估计接近零且区间跨零（当前数据不足以确定交互方向），且在 MPDD 上，交互的**符号**与**零排除判定**都不随画布对应方式改变，包括一个会额外平滑 C 支的最优传输变体在内。

**〔注 1〕少样本（few-shot）与正常参考协议**
「少样本」在这里指每一类只用 K 张正常图（K = 1、2、4、8）建立参考，不用缺陷样本。所谓「正常参考协议」是指：推理时只拿这 K 张正常图当参照物，判断查询图哪些像素与正常外观偏离，而不是去训练一个「缺陷分类器」。这正是工业场景的痛点——新产品投产前往往只有少量合格样本，典型缺陷根本还没出现。

**〔注 2〕有效权重（effective weight）**
三个分支等权平均时，每个分支权重是 1/3；两个分支时是 1/2。若把已有的 B 分支**复制一份**凑成三支，B 的总权重从 1/2 变成 2/3，C 从 1/2 降到 1/3。这个「1/2→2/3」就是有效权重变化，它会在完全没有引入新信息的情况下改变结果。本文把它单列为需要排除的混淆因素。

**〔注 3〕交互（interaction）在本篇中的确切含义**
交互不是「两个因素都有效」，而是一个特定的差值：**同一表征替换在不同匹配规则下带来的收益之差**。写成 $I = E_L - E_J$，其中 $E$ 是「替换新表征相对匹配对照的像素 AP 变化」。$I>0$ 表示「独立匹配让这次替换更有利（或损失更小）」。注意：**正交互并不等于该表征在独立匹配下一定带来正收益**，两件事必须分开报告——这是全文反复强调的一条纪律。

**关键词**：少样本异常定位；冻结视觉编码器；正常参考匹配；固定特征融合；表征交互。

## 1 引言（Introduction）

工业视觉检测必须定位那些在部署前难以穷举其外观的缺陷。一个新产品可能只提供少量已验证的正常图像，而划痕、污染、缺件、结构缺陷的代表性样本仍然缺失。工业异常基准（industrial anomaly benchmarks）通过提供正常训练图像与种类各异的测试异常，使这一区分具体化 [1, 2, 3, 4]。在少样本正常参考协议下，目标是识别「与现有正常外观的偏离」，而不是学习一个目标任务上的缺陷分类器。

冻结的预训练编码器（frozen pretrained encoders）提供了一个实用起点。它们的局部描述子（local descriptors）让查询 patch 可以与一个「正常支持 patch 的记忆库」比较，从而避免在目标域上做梯度优化。AnomalyDINO 用 DINOv2 特征展示了这一简单做法的价值 [5, 6]。多个编码器可以给出同一图像的不同描述，近期方法已经把视觉与视觉语言预训练表征组合起来 [7, 8]。然而，**整个融合系统分数变高，并不能说明「加入一个编码器」中究竟是哪一部分带来了改变**。

在「两支 vs 三支等权」的直接比较中，有三个因素纠缠在一起：新增编码器改变了可用的表征、改变了分配给既有信息的总权重，并且可能改变在共享匹配规则下被选中的支持 patch。举例来说，复制一个已有分支不增加任何信息，但当三个分支距离被平均时，它把该分支的有效权重从 1/2 变成了 2/3；而把这个副本换成一个不同的编码器，则是另一项独立的干预。若把这两种变化都算作「第三个分支的贡献」，就会既可能高估、也可能掩盖新表征的真实价值。

**〔注 4〕为什么这里必须做「对照分解」**
这就是本文的方法论核心：把「三支比两支好」这一个笼统结论，拆成三个可分别估计的量——(a) 只改有效权重（B 复制一份）；(b) 在固定槽位权重下换成真编码器；(c) 在 (b) 的基础上再换匹配规则。只有这样才能回答「新表征本身有没有用」以及「它的用处是否依赖匹配规则」。

正常参考的选择还引入另一层区分。**联合匹配**要求所有分支对同一个正常支持 patch 打分，然后才选出最佳候选；**独立匹配**允许每个分支各自选最近的正常 patch，然后再把距离平均。在两种固定规则下，加入特征都可能改变被选中的参考；但「加入一个分支」本身并不改变规则。在第 3.3 节的假设下，独立匹配不可能给出比联合匹配更大的原始最小距离。然而，**异常分数更小并不必然意味着缺陷像素与正常像素的排序更好**——性能后果必须实测，而不能从距离不等式推出。

**〔注 5〕这里的关键陷阱**
直觉会说「允许每个分支各挑最近的正常 patch，约束更松，分数应该更好」。代数上确实有 $J(p)\ge L(p)$（联合匹配的最小距离不小于独立匹配）。但论文用的是 AP（平均精度），它衡量的是**排序质量**，而不是分数绝对值。约束放松后所有像素的分数都可能被压低，排序反而可能变差。所以「约束差 $G$ 更大」不能被当成「定位性能变差」——这也是论文把二者分开的原因（第 3.3 节末段）。

这个问题把多模态融合（multimodal fusion）的既有研究与多视图异常检测（multi-view anomaly detection）中「一致的邻域」研究连接起来 [9, 10, 11, 12]。我们**不**提出最近邻匹配、早/晚融合或共享邻域这些想法。本文的关注点更窄：在编码器冻结、权重固定、少样本支持集完全相同的条件下，**替换一个既有表征所带来的定位收益，是否取决于正常参考是否在各分支间共享**？我们同时考察表征的绝对效应，以及该效应在两种匹配规则之间的直接差值。

本文的贡献如下。

1. **固定视觉融合中参考选择的一个统一表述。** 我们在同一个对齐后的正常 patch 库上、用相同的分支距离与权重，写出联合匹配与独立匹配。这把「被组合的描述子」与「哪一个支持 patch 有权解释当前查询」这一约束分离开来，使参考选择的差异显式化，并把「原始分数的约束」与「定位性能的主张」区分开。它的贡献是给出了该设定下一个精确的分析基础，而不是提出新的匹配算子或原创的距离不等式。

2. **一个受控的表征替换设计，用来隔离「匹配交互」。** 从一个双视觉锚点出发，我们用一个精确复制分支暴露有效权重变化，在固定槽位权重下把该副本换成真正不同的编码器，并补充一个保持原表征组权重的对照。把每种构造与两种匹配规则交叉，就得到一个直接的「表征 × 匹配」交互。这一设计回答的是「换一个参考约束后，某表征是否变得更有用」，而不是把任何两到三支的差异都归因于新信息。

3. **交互取决于编码器与数据条件的证据。** DINOv2-S 替换在 MPDD 上有正的匹配交互，而在 BTAD 上虽表现出正的表征效应，却没有清晰的总体交互。预先指定的 WideResNet50-2 替换在两个数据集上都得到正交互；直接比较在 BTAD 上检出比 DINOv2-S 更大的交互，但在 MPDD 上其差异仍不确定。这些发现区分了「新增表征是否有用」与「它是否依赖匹配」。参考预算、类别、定性、基线与资源分析只是界定了观察范围，并不构成一项独立的方法论贡献。

本研究是对受控融合选择的分析，并不是声称某个三分支网络普遍更优。原始的**双编码器配置（在下文中称为 A1）**作为锚点。它早期的项目名 DCFnet 不会被用来给所有变体改名，也不暗示一个刚被验证过的新网络架构。

**〔注 6〕A1 与常见误解**
A1 = DINOv2-B（记作 B）+ AnomalyCLIP 的视觉路径（记作 C）两支等权。本文不主张自己发明了新网络，而是把 A1 当作「锚点」，在其上做受控改造。这句话是回应老师此前「不要把它写成已实现的新架构」的要求。

## 2 相关工作（Related Work）

工业异常定位方法在三个方面不同：如何表示「正常」、需要多少目标域适配、以及如何组合证据。我们围绕四类工作组织文献：正常模型学习、局部参考记忆、基础模型融合、多视图邻域。最后一类是必需的，因为「共享邻域 vs 独立邻域」的结构取舍**早于**本文的工业设定就已存在。

**〔注 7〕为什么相关工作要专门写第 2.4 节**
这是「新颖性自查」的要求：老师要求任何「首创」主张必须先查文献。第 2.4 节的作用是明确承认——「共享参考 vs 独立参考」这个操作本身在多视图异常检测里已经是研究对象，因此本文不能声称操作首创。本文的增量在于**问题设定、分离方式与估计形式**，而不是操作本身。

### 2.1 重建与正常模型学习（Reconstruction and Normal Model Learning）

重建方法通过「与估计出的正常外观的偏离」来识别异常。SLSG 结合生成式预训练、模拟异常与对正常嵌入的图建模 [13]。RealNet 使用基于扩散（diffusion）的异常合成，以及特征与残差选择，来提升对异常敏感的重建证据 [14]。这些方法说明拟合出的正常模型或异常判别器如何改善分离度，同时引入了训练目标与适配决策。它们处理的是一个**不同的权衡**：本文的系统不做任何目标域优化。

**〔注 8〕重建法 vs 本文的检索法**
重建法要学一个「能重建正常图」的模型，重建误差大的地方就是异常；它需要训练/适配。本文是**检索法**：把正常 patch 的特征存起来，查询 patch 去和它们比距离。二者对「正常」的定义不同，因此不能直接对比优劣。

分布式的 patch 模型提供了另一种对正常性的描述。PaDiM 用多元高斯（multivariate Gaussians）建模预训练 patch 嵌入的分布 [15]。这避免了重建图像，但估计出的正常分布依赖可用样本数量与特征维度。本文保留**观测到的**支持描述子，只改变它们的表征组成与参考选择规则。本文并不证明在正常训练集更大的场景下，固定检索优于拟合模型。

**〔注 9〕PaDiM**
PaDiM 的直觉是：每个空间位置上的 patch 特征在正常样本中大致服从一个高斯分布，于是「离这个分布多远」就是异常分。它的优点是快、无需训练；代价是高斯参数要从少量样本估出来，K 很小时估计不稳。

### 2.2 特征记忆与少样本正常参考（Feature Memories and Few Shot Normal References）

PatchCore 使用正常局部描述子的代表性记忆库并做最近邻打分 [16]。它的核心集（coreset）与图像预处理同时影响正常覆盖度与计算开销。AnomalyDINO 表明冻结的 DINOv2 patch 为少样本检测提供了很强的基础 [5]。这些方法促使我们在解释一次融合比较时，必须明确交代记忆候选、所选特征层与空间覆盖范围。

**〔注 10〕核心集（coreset）**
记忆库若把所有正常 patch 都存下来会很大。PatchCore 用贪心采样挑一个「有代表性」的子集（coreset），在保持覆盖度的同时降低存储与检索成本。这个选择会影响结果，所以论文强调比较融合时要交代清楚。

近期若干研究修改的是表征或正常参考本身，而不只是增加编码器数量。FEAD 通过条件特征变换与多频建模来丰富稀疏的正常模式 [17]。K-NG 通过不断演化的 Neural Gas 表示研究少样本在线检测 [18]。PGAD 把全局不变性与多尺度局部证据结合，并做分数校准 [19]；FastRef 在测试时精炼正常原型（prototypes）[20]。SubspaceAD 用主成分子空间（principal subspace）建模冻结视觉描述子 [21]；DCP-SFR 则关注深层表征中浅层缺陷信息的保留 [22]。这些工作表明，参考覆盖、线索保留与适配都可能实质性地改变异常分数。本文的**固定记忆**设定刻意排除了「按查询更新记忆」这类机制，以免它们混淆两种匹配规则之间的比较。

**〔注 11〕为什么本文要「排除查询相关的更新」**
如果允许记忆库随查询变化，那么 J 与 L 之间的差异就不再只来自「参考选择规则」，还可能来自「更新策略」。为了做干净的因果式比较，本文把记忆库固定住，只动规则。这也是论文中「training-free」「fixed bank」的用意。

### 2.3 基础模型与多分支融合（Foundation Models and Multi Branch Fusion）

视觉语言预训练提供了可迁移的视觉与文本表征 [23]。WinCLIP 结合提示集成（prompt ensembles）与局部视觉特征，用于零样本/少样本异常检测 [24]。AnomalyCLIP 学习「与物体无关」的正常/异常提示 [8]，PromptAD 只从正常目标样本学习 [25]，InCTRL 使用带样本提示的上下文残差学习 [26]。AA-CLIP 引入异常感知对齐 [27]，FAPrompt 发展细粒度异常提示 [28]。UniVAD 把免训练的参考式异常检测扩展到不同领域 [29]。这些方法在训练数据、提示使用、适配方式与推理路径上各不相同，**不应被笼统描述为都需要目标缺陷监督**。

**〔注 12〕零样本 vs 少样本**
「零样本」指完全没有目标类别的样本可用；「少样本」指有少量正常样本；「目标正常样本适配」指只拿正常样本做适应（如 PromptAD），仍不需要缺陷样本。三者不能混在一张主表里比较，这点在老师的要求里被明确点出。

本文的 C 分支只保留 AnomalyCLIP 的**视觉描述子路径**。它使用视觉语言预训练骨干，并不意味着我们的推理是一个文图融合系统：没有任何文本编码器分数或学习到的提示输出进入异常分数。把受控视觉分支与完整的已发表视觉语言系统相比时，这一区分很重要。

Sea-CLIP 与本工作尤其接近，因为它把 CLIP 与 DINOv2 表征用于少样本异常检测 [7]。它的匹配与解码组件已经同时涉及「类共享参考」操作与「独立最近邻」证据。它的完整架构与我们的对称加权距离比较并不相同，但这已经**排除了「把这两个编码器组合起来」或「把它们的参考耦合起来」是首创**的可能。M3DM 用多个记忆库结合 RGB 与点云信息 [30]；CIF 用超图结构共性来引导少样本多模态参考记忆 [31]。3D-ADNAS 背后的架构分析考察了融合模块的条件收益与不同融合阶段 [9]。因此，无论是「多模态融合」还是「新增模块的条件价值」，都不是本文的新一般命题。

本文贡献的不同之处在于受控的问题本身：我们固定正常支持集身份与距离权重，只替换一个视觉表征，然后估计**当共同的参考约束被解除时，这一替换效应如何变化**。我们不从不同端到端架构的总分去反推这一交互，也不声称与上述所有系统做了全面比较。

### 2.4 多视图邻域一致性（Multi View Neighborhood Consistency）

多视图异常检测明确研究跨表征的不一致与一致。MUVAD 用邻域信息区分「跨视图不一致」与「在多个视图中都异常」两类 [11]。Neighborhood Consensus Networks 对齐不同视图的邻域结构 [12]，ECMOD 则用带邻域一致性信息的对比表征学习 [32]。SCoNE 直接处理跨视图一致的局部邻域，并讨论了「从各自独立表示的邻域中恢复一致邻域」的局限 [10]。这些研究确立了：**「分离邻域还是保持一致邻域」是一个既有研究问题**。

**〔注 13〕本节的限定作用**
SCoNE、MUVAD、NC-Nets、ECMOD 合起来说明：共享/独立邻域这个「操作」不是首创。本文与之的差别在于任务与输入（冻结预训练编码器、每类少量正常参考、像素级工业定位，而不是无标注多视图数据上的离群检测）、分析对象（把有效权重与新增表征分离，并显式区分「匹配规则」与「规则下选中的参考」），以及证据形式（对「匹配方式 × 新增分支」给出带重复种子、配对重采样区间与家族校正的直接交互估计）。

本文任务与「通用多视图实例上的无监督离群检测」不同。我们使用已验证的正常图像支持集、稠密的冻结视觉特征，以及像素级工业定位。分支集合通过显式的复制与表征替换对照来改变，我们关心的量是一个**配对性能交互**。这一范围构成了我们「提供补充证据」这一主张的基础；它**不**赋予共享参考选择本身以新颖性。

综合起来，这四类工作提供了定义正常性与组合信息的不同方式：学习型模型适配正常或异常结构，记忆库保留观测到的局部证据，基础模型系统扩展可用描述子，多视图方法组织它们的邻域关系。本文在一个固定记忆的工业协议下，把后两个问题连接起来。最接近的先前工作促成了一个克制的科研主张：**在显式权重控制与有边界的经验结论下，隔离出「正常参考匹配」在新增视觉表征收益中所扮演的角色**。

## 3 框架与方法（Framework and Methods）

### 3.1 问题定义（Problem Statement）

对于类别 $c$，输入由 $K$ 张已验证的正常支持图像与一张查询图像 $x$ 组成。支持集为

> **公式 (1)**：$\mathcal{X}_c = \{x_i^c : i = 1,\dots,K\}$

这里 $x_i^c$ 是类别 $c$ 的第 $i$ 张支持图像，查询图可以是正常的也可以是异常的。类别标签用于指定相关的支持库；**不预测目标缺陷类别**。我们用 $p$ 表示查询 patch，$r$ 表示一个对齐后的支持 patch 索引（它同时包含支持图像身份与空间位置），$b$ 表示一个视觉分支。同一个索引 $r$ 在空间对齐之后指代各分支中**对应的**那个支持位置；它并不要求查询 patch 匹配其支持图中同一空间坐标。

原生输出是一张连续的像素异常图 $A_t$ 和一个图像级分数 $s_{\mathrm{img},t}$，其中匹配规则标签 $t$ 取 J 或 L。图上显示的缺陷轮廓是由同一张图、通过另一个单独指定的可视化阈值导出的；它**不是**额外的学习输出、不是缺陷类别标签、也不是为部署校准过的阈值。测试标签与掩膜只用于离线评价与示例选取，**不用于在查询推理时选择参考**。由于这些数据集此前已参与过项目分析，我们把这一「推理限制」与「完全未见过的评测」区分开表述。

**〔注 14〕"不用于选择参考" 这句话为什么重要**
它是在排除一种常见的质疑：如果用了测试集标签去挑参考 patch，那结果就不可信了。本文明确：标签只在事后算指标和挑展示案例时用到，推理链路里没有标签。

老师明确要求同时给出**热图**与**对应轮廓图**，且必须来自同一个查询样本。图 1 右下正是这样做的：同一张分数图 → 一张热图 + 一张叠加轮廓。注意轮廓必须声明为「可视化后处理」，不能说成「已校准的分割系统」，图注里已经写了。

### 3.3 正常参考匹配（Normal Reference Matching）

设 $F_b$ 为一个分支的特征张量，$R_b$ 是它到共同空间格点的确定性映射。在位置 $p$，逐分支归一化产生单位描述子 $g_{b,p}$。查询描述子与支持描述子之间的分支距离为

> **公式 (2)**：$d_b(p,r) = 1 - g_{b,p}^{\mathsf{T}} g_{b,r}$

所有报告的构造都使用非负、和为 1 的距离权重 $w_b$。公式 (2) 中的描述子非零；数值上的范数处理遵循归档实现。在每个分支都使用同一对齐候选集 $\mathcal{R}_c$ 时，联合匹配为

> **公式 (3)**：$J(p) = \min_{r \in \mathcal{R}_c} \sum_b w_b\, d_b(p,r)$

联合匹配先对每一个候选 $r$ 求各分支距离的加权和，再选加权距离最小的候选。等价地，把归一化后的各分支描述子按「距离权重的平方根」作为系数拼接起来，就得到一个单位联合描述子；其平方欧氏距离的一半等于加权余弦距离。因此，**特征系数与距离权重不能混淆**：距离上的等三分需要相等的平方根系数，并随后做相应的联合归一化。

**〔注 17〕距离权重 vs 特征系数**
这是很容易写错的一处。若想让三个分支在**距离平均**中占 1/3，拼接特征时的系数应是 $\sqrt{1/3}$ 而不是 $1/3$，同时还要保证拼接后的向量是单位向量。论文专门点明，是因为旧版插图里曾把 0.5 之类的系数直接当作距离权重。

独立匹配把「分支组合」与「候选最小化」的顺序反过来：

> **公式 (4)**：$L(p) = \sum_b w_b \min_{r \in \mathcal{R}_c} d_b(p,r)$

此时每个分支可以选中不同的支持 patch。讨论被选中的邻居时，我们用 $r_J$ 与 $r_{b,L}$ 表示相应的参考索引。并列（ties）可能选出不同索引但分数相同，因此参考身份应当与距离一起解读，而不是当成对每个查询的唯一解释。

图 2 在同一个对齐库上展示两种规则：面板 (a) 固定一个查询 patch 与候选参考行，面板 (b) 对比 $J$ 要求的「单一共享行」与 $L$ 允许的「分支各自的行」。两个面板使用相同的候选集、描述子与权重，因此它们只在「组合与候选最小化的顺序」上不同。

> **图 2（fig2_matching.png）** 同一固定库上的联合匹配与独立匹配。(a) 一个查询 patch 与候选参考行 r = 1, …, 8；每个分支行中被着色的格子标记该分支认为最近的候选。这些格子只是**顺序指示**，不承载任何测量值。(b) J 要求所有分支使用同一个共享参考行，然后对候选求加权距离和的最小值；L 则允许每个分支先取自己的最近行，再形成加权和。两个面板使用相同的对齐候选集、相同的分支描述子和相同的非负权重（和为 1），因此二者只在组合与候选最小化的顺序上不同。

两种原始 patch 分数的差为

> **公式 (5)**：$G(p) = J(p) - L(p) \ge 0$

对每个候选而言，每个分支的距离都不小于它自己的最小值；加权求和保持该不等式，而对加权和取最小值也不会使其反转。这是一个**标准的代数性质，不是新定理**。当各分支的最小值存在共同最小化点时（以及其他退化情形）取等号。正的 $G$ 衡量的是「强制共用参考」在距离上的代价；它**不**衡量缺陷定位的改善，因为平均精度取决于正常与异常像素的排序。在做共同的线性缩放与平滑之后，这一区分依然成立。

**〔注 18〕这就是「不要把代数事实包装成定理」那条要求**
$G \ge 0$ 是显然的代数结论，老师明确要求不能写成「本文提出的定理」。论文因此把它当作解释工具，并反复强调 $G$ 大 ≠ 定位差。

### 3.4 表征构造与权重控制（Representation Constructions and Weight Controls）

我们用正体分支标签：B 表示 DINOv2-B，S 表示 DINOv2-S，C 表示 AnomalyCLIP 视觉描述子，D 表示 WideResNet50-2。这些标识与斜体数学索引不同。表 1 定义了各构造；它们的标签在正文、表格与图中保持一致。

**表 1 固定表征构造与每个对照的用途（Table 1. Fixed representation constructions and the purpose of each control.）**

| 构造 | 距离权重 | 受控比较 |
|---|---|---|
| **A1** | B 1/2；C 1/2 | 双视觉锚点 |
| DUP | B 1/3；B 副本 1/3；C 1/3 | 对既有信息重新加权；不引入新编码器 |
| TRI | B 1/3；S 或 D 1/3；C 1/3 | 在固定槽位权重下替换副本 |
| BAL | B 1/4；S 或 D 1/4；C 1/2 | 保持 C 与非 C 总权重不变 |

> **表注**：每种构造都在 J 与 L 下评价。粗体标识研究锚点，不表示性能最佳。对 S 而言，BAL 同时保持了 DINO 家族的总权重。

**〔注 19〕读这张表的方法**
- **A1→DUP**：只把 B 的权重从 1/2 抬到 2/3，其余不变 → 测「纯重新加权」的影响。
- **DUP→TRI**：槽位权重完全不变，只把「B 的副本」换成「真 S/D」 → 这才是**新表征的净效应**。
- **A1→BAL**：C 保持 1/2，非 C 总权重也保持 1/2，只是把它在 B 与 S/D 之间分配 → 另一种分配方式的对照。
- **TRI − A1** 同时改了权重和表征，所以**不能**单独归因给 S。

图 3 用槽位图展示同样的四种构造，并说明每一步隔离了什么。把构造与表 1 一起读，就足以把「有效权重变化」与「描述子变化」区分开。

> **图 3（fig3_constructions.png）** 固定表征构造及由它们构建的对比。(a) A1、DUP、TRI、BAL 及其距离权重；同一槽位在四个面板中保持同色。(b) A1→DUP 只改变 B 的有效权重，因此是「权重混淆」对照；DUP→TRI 在权重不变的前提下把真编码器放入槽位；A1→BAL 保持非 C 家族总权重与 C 权重相等。(c) 本文估计的四个对比。TRI 到 A1 的差异同时改变两个因素，绝不被单独归因于 S。额外槽位由**五个冻结编码器**实例化：S 与 D 是预先指定的，E1、E2 与 E3 是在 S 与 D 结果已知之后才加入的探索性迁移检验。这些是同一冻结管线中的分析配置，不是训练出来的网络。

把 DUP 与 A1 比较，改变的是 B 的有效权重，没有新增表征。DUP 在数值上也等价于一个权重为 2/3 与 1/3 的两支 B/C 构造。把 DUP 中被复制的 B 描述子换成 S，就在**相同槽位权重**下得到 TRI。因此 TRI 减 DUP 衡量的是「这次表征替换」的效应，而不是「两支与三支之间」的全部差异。

**〔注 20〕为什么还要一个"数值等价"检查**
DUP 应当与「两支 B/C、权重 2:1」给出完全一样的结果。这是一个实现正确性的自检：如果不等，说明代码里槽位权重的处理有问题。论文把它写成「两项额外的构造用于检查数值等价」，不作为额外算法计数。

BAL 提供互补的比较。在 S 实验中，DINO 家族的总权重仍为 1/2，而 C 保持 1/2，从而允许把 B 的配额在 B 与 S 之间拆分。在 D 实验中，BAL 保持非 C 总权重不变，但**不应被称为「保持 DINO 家族」的构造**，因为 D 是卷积型的 ImageNet 编码器。两种对照都不能证明其权重选择最优。副本是被精确复用的，而不是通过另一次随机特征提取得到的，因此它不可能通过数值随机性引入信息。

**〔注 21〕"精确复用"的意义**
如果副本是重新跑一遍特征提取得到的，浮点误差会带来微小差异，理论上可能「碰巧」带来信息。这里直接复制同一份张量，就彻底排除了这条路。

### 3.5 表征效应及其与匹配的交互（Representation Effects and Their Matching Interaction）

设 $P$ 表示「类别宏平均像素平均精度」（category-macro pixel AP），它先针对某个指定的支持条件与评价网格计算。在匹配规则 $t$ 下，两个表征效应为

> **公式 (6)**：$E_{TRI,t} = P(TRI_t) - P(DUP_t)$
> **公式 (7)**：$E_{BAL,t} = P(BAL_t) - P(A1_t)$

直接交互就是同一表征效应在 L 与 J 下的差：

> **公式 (8)**：$I_{TRI} = E_{TRI,L} - E_{TRI,J}$
> **公式 (9)**：$I_{BAL} = E_{BAL,L} - E_{BAL,J}$

**〔注 22〕"类别宏平均"（category-macro）到底怎么算**
先在每个类别内部把所有测试图的像素分数与标签**汇总**（pooling）算一个 AP，再对类别等权平均；支持条件（seed × K）在数据集层面等权平均。这样做的后果是：大类别不会因为像素多而主导结果。它与「把所有类别像素倒进一起算一个 AP」以及「先算每图 AP 再平均」都不一样，论文特意区分。

**〔注 23〕为什么交互要这样定义**
$I$ 衡量的是「同一个替换，在 L 下比在 J 下多做/少做了多少」。它**不等于**「L 比 J 好」——那是匹配效应 $M$（表 5）。这两者容易混：$M$ 说「换规则本身有用吗」，$I$ 说「换规则会不会改变新表征的价值」。论文把两者分别报告，正是这条区分。

正交互意味着独立匹配使该表征变化更有利（或更少有害）。它**不**能证明在 L 下的表征效应本身为正。因此我们把绝对效应与交互一起报告。反过来，一个为正的表征效应加上一个跨零的交互区间，支持「该表征在观察条件下有用」，但并未清晰地确立它依赖匹配。

**〔注 24〕"区间跨零" 不等于 "没有差异"**
这是统计表述的纪律。置信区间跨零只能说**证据不足以判定方向**，不能说「统计上等价」「证明无影响」。论文在多处（BTAD 的 S 交互、MPDD 的 S→D 差异）都按这个口径写，避免把不显著读成无效应。

D 比较使用相同定义，只是用 D 替换 S。为了比较二者的交互，两者都被限制在相同的 seed 与支持预算内。对于 TRI 或 BAL 中任一构造标签 $q$，编码器比较为

> **公式 (10)**：$\Delta I_q = I_{q,D} - I_{q,S},\quad q \in \{\text{TRI}, \text{BAL}\}$

所有差值都在**匹配的条件下**、并在每个重采样副本**内部**先形成，然后再聚合。我们从不通过对比两个独立的显著性判断、也不通过相减两个置信区间端点来推断交互。这些是既有的对比估计量（contrast estimators），用于回答本文的表征问题，而不是本文提出的统计方法。

**〔注 25〕两种常见错误做法**
(a) 看「J 下显著、L 下不显著」就断言两组不同 → 错，因为没有对二者之差做检验；
(b) 用「L 区间上端 − J 区间下端」当差值的置信区间 → 错，这样得到的区间过宽且没有概率含义。
本文的做法是：在同一次 bootstrap 副本里直接算完整差值，再取分位数。这点也是老师「不能相减端点」要求的落实。

### 3.6 异常输出与计算代价（Anomaly Outputs and Computational Cost）

patch 分数在共同格点上构成矩阵 $a_t$，被双线性缩放到 $H \times W$ 的输出画布，并用标准差为 4 像素的高斯平滑；$u$ 索引输出像素。图像分数是图上的最大响应：

> **公式 (11)**：$A_t = \mathrm{Gauss}_{\sigma=4}(\mathrm{Resize}_{H\times W}(a_t)),\quad s_{\mathrm{img},t} = \max_u A_{t,u}$

受控评价把 patch 分数恢复到保留的图像画布上，尺寸为 $H \times W$；方形图像是 448 × 448，BTAD 03 类是 448 × 588。真值遵循同样的缩放与裁剪范围。这一记账与「在原图坐标下做跨方法评价」不同，后者见第 4.1.3 节。像素指标使用连续分数。仅为了示意轮廓，阈值化产生

> **公式 (12)**：$M_{\mathrm{vis},t}(u) = \mathbf{1}[A_{t,u} \ge \tau_{\mathrm{vis}}]$

这里 $\tau_{\mathrm{vis}}$ 是一个**可视化规则**，不是通用的固定工作阈值。定性图使用其图注中写明的确切归一化与 Otsu 规则。真值边界另行显示。无论该图还是公式 (12)，都不构成一个已校准的缺陷分割系统。

**〔注 26〕Otsu 阈值**
Otsu 法在分数直方图上找一个阈值，使「类间方差」最大（即把像素分成前景/背景两类时分得最开）。它是一个**自动但不含语义校准**的阈值：不同图会得到不同阈值，因此适合「展示轮廓」，不适合宣称「分割精度」。论文要求把「连续定位证据」「阈值化可视化」「部署分割精度」三件事分开陈述。

如果库里含 $N_c$ 个正常 patch，查询含 $n$ 个 patch，合并描述子维度为 $d$，那么穷举匹配需要 $nN_cd$ 量级的距离运算与 $N_cd$ 量级的特征存储。联合匹配可以使用一个加权拼接索引，而独立匹配需要相应的逐分支检索。即使运算量级相同，不同实现的额外开销也可能不同。更大的支持预算会增加参考存储；真正新增一个编码器会带来特征提取成本，而复用一个副本不会产生该编码器成本。「免训练（training-free）」指的是没有目标域优化，**不是**零准备成本或可忽略的推理成本。

**〔注 28〕"预先指定"（prespecified）为什么反复强调**
它是在防「p-hacking / 挑结果」的质疑：D 分支是在看到结果之前就定好的，不是试了很多编码器后挑了一个好看的。文中多处（摘要、引言、4.1.1、4.1.4）都保留这句话，属于证据纪律。

## 4 实验评估（Experimental Evaluations）

### 4.1 实验设计（Experimental Design）

#### 4.1.1 数据集与参考协议

本主题实验使用金属零件缺陷检测数据集 MPDD（Metal Parts Defect Detection）与 beanTech 异常检测数据集 BTAD [2, 3]。它们分别包含 6 类与 3 类，提供不同的正常外观与缺陷分布。旧项目的 MVTec AD 与 VisA 实验**不被复用**来评价新的「表征 × 匹配」设计。后续扩展确实在 MVTec AD 与 VisA 上（作为冻结验证集）、并在 KolektorSDD2 上（作为「在任何特征被编码之前就已冻结预期」的确认集）运行了同一组受控对比；这些是**新运行**的实验，单独在第 4.2.9—4.2.13 节报告，不是旧项目的实验。MPDD 曾参与开发，BTAD 也已在项目中检查过；因此，本文的交互分析与编码器扩展都**不**被描述为「在全新未见数据集上的确认」。

表 3 记录两项研究的评价范围，包括各自使用的 seed 与支持预算，以及编码器比较复用了其中哪一部分。

**表 3 本主题的评价范围与数据角色（Table 3. Current-theme evaluation scope and data roles.）**

| 数据集 | 类别数 / 测试图数 | S 研究 | D 与编码器比较 |
|---|---|---|---|
| MPDD | 6 / 458 | seed 0、1、2；K = 1, 2, 4, 8 | seed 0、1；K = 1, 4 |
| BTAD | 3 / 741 | seed 0、1；K = 1, 2, 4, 8 | seed 0、1；K = 1, 4 |

> **表注**：支持集在每个类别与 seed 内是嵌套的，且在成对比较的方法之间完全一致。两个测试数据集都已在项目分析中使用过。D 的规格在 D 结果之前固定，但这不构成「未见数据集确认」。

**〔注 29〕seed 与 K 的含义**
- **seed**：支持图像的抽样随机种子（第 0、1、2 号抽法）。固定随机种子保证可复现。
- **K**：每类使用的正常支持图数量。
- **嵌套（nested）**：K = 2 的支持集包含 K = 1 的那一张，K = 4 再包含 K = 2 的，依此类推。好处是不同 K 之间的差异只来自「多了哪些图」，而不是「换了一批完全不同的图」。代价是四个 K 之间不独立，所以文中不给「单调规律」这种强结论。

对每个类别与 seed，支持序列是固定的，较小的预算就是同一序列的前缀。成对比较中的所有方法使用**完全相同**的支持图像与查询图像。S 研究在 MPDD 上使用 seed 0、1、2，在 BTAD 上使用 0、1，$K$ 取 1、2、4、8。这分别得到 72 与 24 个「类别 × seed × 预算」单元，也就是 12 与 8 个数据集级支持条件。这些是在共享数据上的重复评价，**不是 96 个独立数据集**。

**〔注 30〕"不是 96 个独立数据集" 这句话防的是什么**
防把「重复测量」当成「独立样本」来夸大统计功效。72 + 24 = 96 个单元来自同一个 MPDD 与 BTAD，只是 seed 和 K 不同。论文特意用这句限定语，避免被质疑「把重复算成独立重复」。

预先指定的 D 扩展在两个数据集上都使用 seed 0 与 1、$K$ 取 1 与 4，得到 36 个类别级单元。A1 与 DUP 对照在该范围内重新打分。S 与 D 的交互比较也使用这一受限范围，从而避免由支持条件覆盖度不等造成的差异。在比较了多个候选扩展结果之后，**没有**再挑选额外的编码器或数据集。

#### 4.1.2 基线与对照范围

主受控矩阵由单分支 B、S、C 以及 A1、DUP、TRI、BAL 的 J/L 形式组成。这些是**十一个分析配置，而不是十一个被独立提出的算法**。另有两个构造用于检查「复制表征」与其「有效权重表述」的数值等价性。D 扩展加入 D 单独路径及其 TRI/BAL 组合。单分支去除是一个配对对照，**不应**被当作「存在一个独立新颖网络模块」的证据。

**〔注 31〕为什么单分支不叫"消融"**
老师明确说过「DINO-only 不能算消融」。本研究的单支 B/S/C 是**受控诊断**（用来看融合相对单支是否有增益），不是「去掉某个自研模块」的消融。真正需要的消融是：去空间映射、去分支归一化、去 DPAM、拼接检索 vs 分数层融合——这些本文**没有运行**，因此只在局限中如实说明，不出图（见 4.2.8）。

为了提供实际背景，我们还评价了 AnomalyDINO 与 PatchCore 的原生方法配置 [5, 16]。AnomalyDINO 在原生图像画布上运行，分别开启与关闭参考旋转选项。PatchCore 包含一个官方分辨率的 224 像素配置（1024 维投影特征）以及更早的本地 128 像素 / 256 维配置；后者被保留是为了暴露配置敏感性，而不是被当作 PatchCore 的唯一代表。在这一比较中，骨干、特征维度、预处理、参考增强与检索管线仍是各方法特有的；因此它**不能**隔离匹配，也**不构成**通用的 SOTA 排名。

#### 4.1.3 评价指标与不确定性

像素 AP 是主要指标，因为它在稀疏缺陷像素条件下同时强调精度与召回，并评价异常排序。在每个类别内部，像素分数与标签跨该类的测试图**汇总**；然后对类别 AP 等权平均。支持条件在数据集层面等权平均。这与「把所有类别汇总成一个 AP」以及「对每图 AP 再平均」都不同。像素 AUROC（受试者工作特征曲线下面积）是次要诊断指标；解释主交互时**不用它替代** AP。

**〔注 32〕AP 与 AUROC 的分工**
- **AP（平均精度）**：对「正类（缺陷像素）」敏感的排序指标，缺陷很稀疏时比 AUROC 更能暴露差异，所以当主指标。
- **AUROC**：衡量整体可分性，对类别极不平衡不敏感（因为用了真阳率/假阳率），所以缺陷占比很小时容易「看起来很好」。因此它只作辅助诊断，不拿来解释主结论。

我们区分三种评价网格。主重采样分析使用保留输出画布上的固定**步长 8**子集，以限制图像级重采样的计算量。全像素评价使用每一个输出像素，提供分辨率敏感性检查的点估计。跨方法比较把每个方法的预测映射到它在原图坐标中的实际覆盖范围，并只在它们的**共同有效交集**上评价。表格与图注都明确标注所用的网格；它们的 AP 值不会被放进同一个可互换的排名里。

**〔注 33〕步长 8 与全像素**
- **步长 8**：每隔 8 个像素取一个参与重采样统计。这样 1000 次 bootstrap 才算得动；区间也只有这个口径才有。
- **全像素（stride 1）**：用全部像素，数值更精确，但**没有算区间**，只能作点估计的方向核对。
- 所以文中凡是「显著性/区间」的表述都只属于步长 8；全像素只能说「方向一致」。

不确定性由 **1000 次配对图像级 bootstrap 重采样**估计：在每个固定类别内**有放回**抽样，不做额外的正常/异常分层。被抽中的图像以整块形式贡献它的全部像素；同一条副本流在各方法、各 seed、各预算之间共享。条件与类别在汇总某个副本的对比之前先被聚合。基础随机种子为 20260913；确定性数据流还并入数据集身份、类别身份与副本索引。这些区间刻画的是**在给定类别、编码器与有限支持清单条件下的测试图像抽样不确定性**；它们并不重采样「可能的支持集总体」，也不给出对任意未来数据集的不确定性。

**〔注 34〕bootstrap 在这里做了什么、没做什么**
它回答的是：「如果我换一批测试图（同一批类别、同样的支持集），结论会不会变？」它**不**回答：「如果换一批支持图，结论会不会变？」——后者需要重采样支持集，本文没做。这一区分在讨论与局限里被明确写出，属于「不要过度外推」。

对于四个主要 S 交互（两种构造 × 两个数据集），我们报告 95% 探索性区间，以及与「四次比较 Bonferroni 校正」对应的 98.75% 分位数区间。四个 D 交互与四个配对编码器差值各自是独立的探索性家族，使用同样的校正。第 4.2.9—4.2.12 节的扩展使用各自随文写明的档位：确认集只用 **95%** 区间且不套家族校正；八格四数据集家族使用 **95%、98.75% 与 99.375%** 三档。这些是建立在 bootstrap 区间上的近似家族校正；1000 次副本限制了极端尾部的精度。它们**不是**对后续所有子组图与次要指标的一次性同时保证。交互分析相对于项目早期的探索是**事后（post hoc）**的，尽管 D 的规格在 D 结果之前就已冻结。

**〔注 35〕Bonferroni 校正在做什么**
一次比较用 95% 区间，犯「假阳性」的概率约 5%；一次做 4 个比较，至少错一个的概率会明显高于 5%。Bonferroni 的粗糙做法是把每个区间放宽到 $1-0.05/4 = 98.75\%$，以把整族出错率压回大约 5%。代价是区间更宽、更难排除零。本文报告两套区间并说明适用范围，就是既给出「每个比较各自的读数」，也给出「家族层面的读数」。

我们用 0.5 个 AP 百分点作为判断交互量级的**描述性尺度**，而不是既定的工业效用阈值，也不是独立于本项目选定的接受标准。点估计高于该尺度**不**意味着它的区间也整体高于该尺度。跨零的区间被当作「方向证据不足」，而不是统计等价。全像素结果目前没有 bootstrap 区间，因而不能支持全像素统计显著性的主张。

**〔注 36〕为什么要专门声明 0.5 个百分点**
因为项目以前用过这个数字做门槛，容易被误读成行业标准。论文明确它是「本项目的描述性参考尺度」，并且强调「点估计超过它 ≠ 区间也超过它」，避免把描述性数字伪装成判定标准。

#### 4.1.4 实现与计算环境

归档运行使用 NVIDIA GeForce RTX 3060 Laptop GPU（6 GB 显存）、Intel Core i9-12900H 处理器与 16 GB 系统内存。编码器以评估模式运行，不做梯度更新。查询特征被缓存，以避免为每个受控分数变体重复做特征提取；打分与评价仍对每个适用的支持条件运行。精确检索实现了第 3 节的距离定义，并在合适处使用 FAISS [33]。**没有任何目标损失被优化。**

**〔注 37〕为什么这段话里要出现"没有损失被优化"**
因为老师问过「所有对比方法的 loss-epoch 曲线」。冻结检索方法没有目标域训练，就没有 loss 曲线；这里如实写「无损失被优化」，并在第 3.7 节写「训练轮数不适用」，是用 K 曲线（图 5）与资源图（图 8）替代的依据。

稿件使用最终几何一致的 BTAD 版本。此前 BTAD 03 类的真值与特征网格变换经过审计，随后受影响的点估计与 bootstrap 比较被重算。**原始点估计按其原样报告**；bootstrap 均值保留在源表中，但不会被替换为点估计。这一区分同样适用于逐预算聚合：它平均所有可用 seed，而不是只显示最后处理的那个 seed。

**〔注 38〕BTAD 03 的几何修正到底修了什么**
BTAD 03 的原图是 600 × 800；之前掩膜被直接缩放到 448 × 448 画布，与「按比例缩放再裁剪」的特征变换不一致，导致掩膜与预测错位。修正后：图缩放到 448 × 597，再从左上裁剪到 448 × 588，真值走同一变换。审计结果显示：单个方法条件的绝对像素 AP 变化最大约 0.0136，而**交互量本身只变化约 2×10⁻⁵**——因为交互是「同方向的差分之差」，共模误差被抵消。这就是为什么论文能用修正版重算，而主要结论不变。

资源测量按阶段与配置报告。历史上的受控运行没有记录所有逐单元的特征与打分时间，因此后来的部分计时**不会**被拼装成一个端到端时延。PatchCore 的「建库 + 打分」合并阶段无法事后拆分。在当前插桩下，PatchCore 的逐进程 GPU 显存不可得，也不使用整卡占用作为替代。这些限制影响实际比较，但**不改变已存的异常预测**。

#### 4.2.1 总体受控结果

单支诊断从一侧界定了这一比较。在 MPDD 上（这些运行与主几何版本一致），每个单支都低于融合锚点：B 为 0.348、S 为 0.326、C 为 0.283，而 A1 在两种规则下为 0.373 与 0.379。因此，**组合描述子相对每个单支都有帮助**，这也是本研究把「融合锚点」作为出发点、而不是去问「一个编码器够不够」的原因。相应的 BTAD 诊断在此不报告：修正后的 BTAD 03 几何重算只覆盖八个交互配置，把两个版本放进同一个比较会把几何差异与编码器差异混在一起。

#### 4.2.2 把重新加权与新信息分开

在两个数据集、两种匹配规则下，DUP 相对 A1 都降低了平均 AP（表 4）。在 MPDD 上，观测差在 J 下约为 −0.80 个 AP 百分点，在 L 下约为 −1.10。因此，把表面上看起来的分支数从二增到三，可以在**没有引入新信息**的情况下改变性能：被复制的 B 描述子只是抬高了 B 的有效权重，同时降低了 C 的权重。

**〔注 41〕本节的逻辑为什么关键**
如果直接比较「三支 TRI」与「两支 A1」，得到的是「权重变化 + 新表征」的混合结果。DUP 这一行给出「纯权重变化」的基准，于是「新表征的净效应」= TRI − DUP。这就是「不要把常规操作/堆叠当成创新贡献」在实验设计层面的落实。

这一结果解释了为什么「TRI 与 A1 的直接比较」无法识别 S 的贡献：TRI 相对 A1 同时含有有效权重变化，相对 DUP 才含有新描述子。TRI→DUP 这一对比固定了分支槽位及其距离权重；BAL→A1 处理的是另一种分配方式——其中 C 与「非 C 的合起来权重」保持不变。这些对照**并不**证明「两支等权普遍更优」，它们证明的是：在当前配置下权重移动是有实质影响的，因此必须与表征价值分开处理。

**〔注 43〕"像素 AP 更高但图像 AP 更低" 如何理解**
图像级分数是「整张图的最大响应」，像素级 AP 看的是「每个像素排序」。前者关心「图有没有缺陷」，后者关心「缺陷在哪」。一个配置可能把缺陷区域排得更好（像素 AP↑），却让某些正常图的最大响应意外偏高（图像 AP↓）。二者不可互相替代，所以论文两处都写、不混说。

#### 4.2.5 支持预算与类别条件

图 5(a) 显示按 seed 平均后的 S 交互随嵌套支持预算的变化。在 MPDD 上两种对比都随 K 增强：TRI 交互从 1 张支持时的 +0.41 个百分点升到 2、4、8 张时的 +0.75、+0.88、+1.01，BAL 从 +0.37 升到 +0.83。在修正后的 BTAD 上，同一对比减弱并改变符号：从 1 张支持时的 +0.20 点，变为 2 张时的 +0.09、4 张时的 −0.14、8 张时的 −0.23，其中 8 张时区间已不含零。因此曲线支持的是「随预算而变」的描述，而**不是**「更多正常参考会一致放大独立匹配收益」的单调律。

> **图 5（fig5_budget_category.png）** 交互随嵌套支持预算、类别与支持种子的变化。(a) $I_{TRI}$ 与 $I_{BAL}$ 随 K 的按 seed 平均步长 8 点估计。K = 2、4、8 是同一支持序列的嵌套前缀，因此四个预算**不是独立样本**；连线只是连接已评估的预算，不表示拟合趋势。(b) MPDD（study 版本）与 BTAD（修正版本）上按类别的 $I_{TRI}$。Bracket_white 与 connector 的区间最宽，因此 MPDD 的平均值不是由某一个狭窄估计造成的。(c) 同样两个交互按 seed 展开（seed 0—7）：seed 0—2 使用各自独立的 query 编码块，seed 3—7 共享同一个重采样块，因此后者只反映支持集变化。八 seed 批次**只作描述性展示**，其回归门已在数据集宏平均层面通过（见第 4.2.11 节），因此面板 (c) 可与汇总表并读。这些逐预算、逐类别与逐 seed 数值是探索性后续分析，**不继承**主要家族的多重比较校正。

**〔注 44〕为什么"嵌套支持"会带来这种不对称**
嵌套意味着加更多参考图**不可能**让「最小原始距离」变大（候选集变大，最小值只会更小或不变）。所以约束差 $G$ 有单调性保证。但 AP 与交互都依赖**排序**，而排序并不继承这个单调性——这正是 MPDD 上升、BTAD 下降这类不对称可以出现的原因。论文用这段把「数值约束」与「缺陷定位性能」彻底分开。

当库是嵌套的、描述子固定时，增加正常候选**不可能**增大精确的最小原始距离。然而 AP 取决于分数排序，而交互是四个性能值的差。AP 与交互都**不**从「最小距离运算」继承单调性保证。这一区分也解释了为什么「数值上的约束差」不应被当作「缺陷性能度量」。

类别分析进一步限制了总体解释。图 5(b) 按类别分解 TRI 交互：六个 MPDD 类别全部为正，其中 connector 与 tubes 领先；而三个 BTAD 类别都接近零，类别 02 略为负。在留一类别分析中，去掉任何一个 MPDD 类别，TRI 总体交互都保持为正；而在修正 BTAD 上，去掉类别 02 会改变 TRI 总体的方向。由于 BTAD 只有三个类别，平均值对类别构成较为敏感。逐类别与逐预算区间属于探索性后续分析，不继承主要家族的多重比较保证；它们指出的是**值得在新数据上检验的条件**，而不是证明类别身份或缺陷大小具有因果作用。

**〔注 45〕留一类别分析（leave-one-category-out）**
做法是每次去掉一个类别，看总体结论是否反转。若反转，说明结论被该类别主导。这里 MPDD 稳健、BTAD 会被类别 02 反转，所以论文只写「对类别构成敏感」，不写「稳健」。

步长 8 与全像素的总体交互方向在 S 与 D 的汇总上一致。这是一项有用的数值敏感性检查，因为稀疏像素采样会改变小缺陷的贡献。它**没有**消除该顾虑，点估计一致也**不能**推出全像素显著性。特别是，所选定性案例包含极小缺陷，当只有少数采样像素为正时，其逐图 AP 可能显著变化。

AP 改善**不**意味着在任意工作阈值下都有准确的缺陷边界。示例中的小轮廓可能只覆盖划痕或错配最强的部分，而次要激活可能仍留在图中的其他位置。图 7 的退化案例同样表明：即使其原始 patch 距离并未变大，独立匹配也可能不利地改变相对响应。这些观察促使我们把「连续定位证据」「阈值化可视化」与「部署分割精度」**保持为三个分开的主张**。任何真值轮廓都不会被用来替代预测输出。

**〔注 46〕这里为什么反复强调"真值只用于裁剪"**
因为把真值轮廓画得像预测轮廓，会给人「算法分割得很准」的假象。老师明确说过不能用真实标注轮廓冒充预测结果。论文因此把真值的用途限定为：算指标 + 决定放大窗口的显示区域。

#### 4.2.8 讨论与局限

实际启示是：在扩大编码器集合之前，先检查「融合增益来自哪里」。复制对照检验的是有效权重是否已经改变了结果；固定权重下的表征替换检验的是新描述子是否有帮助；把该替换与匹配规则交叉，检验的是另一个问题——参考选择是否改变了它的价值。MPDD 与 BTAD 的结果说明，为什么这些问题**不能**被压缩成一个笼统的「三支比两支」比较。

解读仍有多方面限制。第一，主交互是在项目早期探索**之后**才形成的，数据集也不是未被触碰过的确认集。第二，bootstrap 以观测到的类别与固定支持清单为条件；它的区间不刻画任意未来的支持选择。第三，只加入了一个预先指定的异构编码器，且其 seed 与预算范围比 S 研究更小。第四，全像素区间与完整部署资源测量仍然缺失。第五，定性案例是选出的极端，其 Otsu 轮廓是展示选择而非校准过的缺陷掩膜。第六，每种构造**共用**的那些操作——空间映射、分支归一化、以及从拼接描述子打分——在主要口径下是**固定而非消融**的，因此本研究不量化它们各自的贡献，也不把它们呈现为已验证的模块；第 4.2.13 节报告了一次单条件范围的共用操作消融，出于同样的原因也属探索性。最后，几何对齐是确定性的画布对应关系，而不是「感受野精确描述同一物体部位」的学习式保证。

这些局限**不会**把一个为负或不确定的交互变成失败的实验。BTAD 上的 S 把「正的表征价值」与「不确定的匹配依赖」分离开来，而 D 比较在配对条件下给出了编码器特有的差异。本研究的贡献就是这份受控且有保留的说明。未来若引入学习式选择器、前景过滤器或动态融合模块，都需要它们各自的实现与证据；本文结果**不**暗示其中任何一个已经成立。

**〔注 49〕第六条局限是回应老师 E03 的**
老师要求「去掉一个模块/分支」的真消融，并且明确「没跑的实验不能画进图里」。这条把主要口径下的共享操作标注为「固定而非消融」，把缺口写在明处，而不是含糊带过；第 4.2.13 节与图 S2 另外给出唯一完成的那次单条件消融，并明确它同样不能当作「已验证」。

家族校正（把区间放宽到 98.75% 之类）是**探索阶段**的内部口径，用来把一族比较的整体出错率压回约 5%。把它套到确认集上，等于在看到结果之后自己把门槛放宽，可能把「没通过」说成「通过」。所以冻结规格只写 95%：KSDD2 的判据就是「95% 区间是否排除零」。同理，确认集不并入四数据集家族表，因为并入会改变已发布表的家族基数与语义。

#### 4.2.12 结论是否取决于「对应方式」

本研究的几何对齐是**确定性的画布对应**，不是经过学习或验证的部件级对应。因此我们在 MPDD 上（6 类、seed 0 与 1、$K$ = 1 与 4、4 个条件、共享同一套 bootstrap 流）用四种方式替换 B 行与 C 行之间的对应：画布规则本身；在支持行上闭式拟合正交 Procrustes 映射并同时作用到 query 与 reference 行；对 C 行做位置置换（query 与 reference 使用同一置换）；以及一个 Sinkhorn 最优传输对应，其代价矩阵为支持描述子的跨分支余弦距离、熵正则系数按**先验**固定为该矩阵四分位距的 0.1 倍——它会把这些 C 行混合到多个画布位置上，而不是对它们重标号。我们还报告同一代价矩阵在正则系数趋于 0 时的**精确指派**。

**两个层面的判定都稳健。** 在七个设置（画布规则、Procrustes、位置置换，以及包括精确指派在内的四个正则系数取值）下，全部十四个点估计都为正，且全部十四个区间在 98.75% 家族档位上都排除零。精确指派是其中最强者；唯一下界贴近零的格是正则系数取中间值 0.05 时的 $I_{BAL}$，为 +0.006 点。

关于传输规则有两点性质需要与本表一并记录。软混合**还改变了 C 描述子的多重集**——每行变成约 15 至 40 个画布位置的加权组合（行最大权重中位数 0.044），而画布规则、Procrustes、位置置换都保持该多重集不变；精确指派同样保持多重集、并与软规则共享同一代价矩阵。因此本表仍把整张扫描完整给出、而不是只用先验正则系数那一档概括：读者可以据此看到，交互的**符号**与**区间分离**都不取决于该常数。

这些传输计划本身几乎不携带「画布位置对应」信息：对角线质量中位数为 0.000949，而随机基线是 0.000977；拟合出的 Procrustes 映射与恒等映射的 Frobenius 距离约为 39，所以两者都没有解出位置级对应。我们也记录新变体的验证：它在合成用例上精确复原已知指派；把计划强制为恒等时能复现已存储的 patch 分数（最大绝对差 6.4e-07）；在新的代码路径存在下，先前三个变体的复现偏差不超过 1.8e-06。本表区间取**图像级自助序列**的分位数（差值先在副本内形成，再跨类别与条件聚合后取分位），即正文主表所用的口径。在这一口径下，画布行在 MPDD 上复现了表 15 的 S 支交互：副本均值 +0.695 对 +0.695，区间同为 [+0.193, +1.160]，两端一致到 2.4e-07；因此表 17 点估计列与表 15 的 S 行相差 0.07 点，是「条件平均差值」与「副本均值」两个估计量之别，而非两条评分链之别。在 BTAD 上本 harness 仍走自己的评分路径，其 BTAD 数字**不可**与 D、E1 或 E2 的数字混用。

在 BTAD 上四种对应方式全部跑齐，并同样扫了四个正则系数取值。没有任何区间排除零：画布规则 $I_{TRI}$ +0.001 点 [−0.183, +0.299]、$I_{BAL}$ −0.080 [−0.270, +0.226]；Procrustes +0.001 [−0.183, +0.299]、−0.080 [−0.270, +0.226]；位置置换 +0.234 [−0.058, +0.715]、+0.217 [−0.112, +0.773]；按先验正则系数的软混合 +0.115 [−0.109, +0.465]、+0.103 [−0.156, +0.561]。正则系数扫描给出：精确指派 +0.220 [−0.044, +0.660]、+0.148 [−0.181, +0.699]；中间取值 0.05 为 +0.162 [−0.080, +0.554]、+0.156 [−0.151, +0.653]；混合最宽的 0.5 为 +0.061 [−0.124, +0.363]、+0.025 [−0.170, +0.353]。十四个区间全部跨零，因此在 BTAD 上，**替换对应方式或改变传输规则的平滑程度，都不改变该判定**——而该判定本来就是「方向证据不足」。

**〔注 54〕「软混合」与「重标号」的区别**
如果「替换对应」只是把 C 支的位置索引整体换一下（重标号、置换），C 支描述子的**多重集不变**、信息内容不变；而熵正则 OT 在中等 ε 下会把每个 C 行做成 15—40 个位置的加权平均，**同时平滑了 C 支**，信息内容被改变。两者不是同一类操作；本节把 ε→0 硬指派单列出来，是因为它与位置置换同类（保持 C 描述子多重集），却又与软混合共享同一代价矩阵——把两者并列才能看出「对应方式」与「是否平滑 C 支」是两件不同的事。

## 5 结论（Conclusion）

我们研究了在少样本工业异常定位中，正常参考匹配如何改变「新增一个视觉表征」所带来的收益。一个共同的固定记忆表述、一个精确复制对照，以及两个表征替换对比，把有效权重、新描述子与参考选择约束分开。联合与独立匹配都是既有操作；本文关心的结果是它们与表征变化之间**直接估计出的交互**。

使用 DINOv2-S 时，MPDD 呈现正的匹配交互，而独立匹配下的绝对增益仍不确定；BTAD 呈现正的表征效应，但没有清晰的总体匹配交互。预先指定的 WideResNet50-2 扩展在两个数据集上都给出正交互。配对比较支持「BTAD 上 D 的交互更大」，同时让 MPDD 上 S 与 D 的差异保持不确定。全像素点估计保持了这些总体方向，但全像素区间尚未计算。

这些发现支持在扩大冻结编码器集合时，**同时检查有效权重与正常参考选择**。它们**不**确立「独立匹配或更多编码器普遍最优」。有限的数据集、以条件为前提的 bootstrap 推断、共同区域基线比较，以及不完整的资源覆盖，共同界定了结论的边界。后续工作应在未被触碰过的数据集上检验同一个受控问题，并量化完整的部署成本，然后才能把观测到的交互当作普遍的设计规律。

另有两项扩展为这些结论划界并加以延伸。一个在任何特征被编码之前就已冻结预期的确认集**满足**该预期，因此 MPDD 结果的方向不是此前开发过程的假象；同一组对比在另外两个数据集上表现为 MVTec AD 与 VisA 明显为正、BTAD 点估计接近零且区间跨零（当前数据不足以确定交互方向），并在 C 支的**域内**数据集上最大。交互的**符号**对画布对应方式不敏感，**零排除判定**同样如此：在 MPDD 上，无论采用哪种对应变体或正则系数取值，全部十四个区间都排除零，包括会额外平滑 C 支的传输变体在内——其最弱的格下界仍为 +0.006 点；而在 BTAD 上没有任何变体排除零，故该处的判定不变。编码器迁移与支持 seed 两项扩展仍是探索性的：它们的条件口径与主要口径不同，且 seed 批次的回归门已在数据集宏平均层面通过。

## 附：阅读本文时的五个关键区分（便于快速把握）

1. **重新加权 ≠ 新增表征**：A1→DUP 只动权重（表 4 显示这本身就会降分），DUP→TRI 才是新表征的净效应。
2. **匹配规则有用 ≠ 新表征依赖匹配规则**：前者是匹配效应 $M$（表 5），后者是交互 $I$（表 7、表 9）。两者不能互相替代。
3. **正交互 ≠ 正收益**：$I>0$ 只说「L 让这次替换更有利」，$E$ 才能说「这次替换本身有没有用」（表 6、表 8）。
4. **区间跨零 ≠ 无差异**：只能说「方向证据不足」，不能说「等价」。论文在 BTAD 的 S 交互与 MPDD 的 S→D 差异上都严格用这个口径。
5. **可视化轮廓 ≠ 分割系统**：Otsu 轮廓只是展示选择，不是校准过的部署阈值，也没有用真值轮廓冒充预测。
