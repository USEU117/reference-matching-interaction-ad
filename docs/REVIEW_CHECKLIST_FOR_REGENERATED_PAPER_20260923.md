# 论文/PPT/图件重新生成后的完整核对清单 — 2026-09-23

> **一句话口径**：本文以「**外部评审**」指代指导方（含口头与书面修改意见的来源方）；文中所有「外部评审要求」均指指导方已提出的要求，**要求本身完整保留**。
> **用途**：论文/PPT/图件**重新生成后**交给 AI，按本清单**逐条核对**并输出「通过 / 部分通过 / 不通过 + 证据」。
> **性质**：本文件是**验收清单**，不是新要求；清单内条目全部可回溯到已登记的来源（见 §6），**未核实**的条目在表内明确标注。
> **边界**：本文件只新增这一份文档；未改任何实验数值、既有文档内容；未跑实验、未用 GPU；未提交、未推送。

## §0 使用说明（10 行内）

1. 把**新生成的 docx / PDF / PPT / 图件**交给 AI，连同本清单一起提供。
2. AI 从 **§1（可自动核查项）** 开始，逐条执行"检查命令/检查位置"，给出**通过 / 部分通过 / 不通过**与**证据**（页/表/图/文件:行/命令输出）。
3. **§2** 为需人工或语义判定的项：AI 给"判断标准 + 是否命中常见不合格表现"，无命令但须**引用原文片段**作为证据。
4. **§3** 判定方法覆盖与对照要求（含"3–4 个较先进方法"的判定模板）。
5. **§4** 是**保持性检查**（已满足、防回归）：只核对"是否被新版本破坏"，不要求重做。
6. 判定结果写入 **§5** 的表格（编号 / 状态 / 证据 / 备注），**一条一行，不留空**。
7. **清单外发现的新问题**单独列一节（标题：`§7 清单外新发现`），不与本清单条目混排。
8. 状态取值只允许：`通过` / `部分通过` / `不通过` / `未核实`（无法核实时必须写"未核实"并说明原因，**不得**写成"通过"）。
9. 涉及**冻结值**（§1 A-21、§4 K-13）时，"不通过"= 立即停手并回退，不做其它判断。
10. 证据只引用**盘上实读**结果；不得把"推测"写成"要求"，不得把"要求"降级成"建议"。
