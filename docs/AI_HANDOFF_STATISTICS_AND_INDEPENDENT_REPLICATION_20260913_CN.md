### 2.2 方法含义

B=DINOv2-B，S=DINOv2-S，C=当前 AnomalyCLIP 的 **CLIP 视觉特征**。路径里的 `anomalyclip_text` 不代表本轮加入了文本评分分支。

| 方法 | 有效距离权重 | 用途 |
|---|---|---|
| A1_J | B=1/2，C=1/2 | 双视觉联合最近邻基线 |
| TRI_J | B=S=C=1/3 | 等权真实三视觉分支 |
| BAL_J | B=S=1/4，C=1/2 | 平衡 DINO 家族总权重 |
| DUP_J | B=Bcopy=C=1/3 | 不增加信息，仅使 B 总权重变为 2/3 |
| DUP_BAL_J | B=Bcopy=1/4，C=1/2 | 应与 A1_J 等价的控制 |
| DUP_EXPECTED_J | B=2/3，C=1/3 | 应与 DUP_J 等价的控制 |

令 `d_b(q,r)=1-cos(q_b,r_b)`，权重和为 1：

```text
J(q) = min_r Σ_b w_b d_b(q,r)          # 所有分支共同选择一个参考行
L(q) = Σ_b w_b min_r d_b(q,r)          # 每支可独立选择参考行
G(q) = J(q) - L(q) >= 0               # 同一距离构造下的约束代价
Sλ(q) = L(q) + λG(q), λ∈{0,.25,.50,.75,1}
```

G 非负不意味着加入 G 必然改善异常排序。不得把这个数学恒等式本身当成新发现。

### 4.2 方法、对比和抽样口径

完整方法集合为 21 个：原九个主要方法，加 A1/TRI/BAL 各自的 L、λ=.25/.50/.75，共十二个附加方法；λ=1 复用原 J。

每个 K 固定 1000 次图像级配对 bootstrap。为了复核原结果，保持原随机生成方式：

```python
rng = np.random.default_rng([20260912, shot, replicate_index])
# 严格按第 2.1 节类别顺序逐类抽样；每类所有方法共用同一 idx
idx = rng.integers(0, n_images, size=n_images)
```

一张被抽中的图像携带其全部 stride-8 像素、mask、图像标签及分数；同一图像可重复抽中。每个类别先计算 pooled pixel AP/AUROC 和 image AP/AUROC，再对六类取宏平均。**不允许像素独立抽样、不允许平均逐图 AP 代替 pooled AP、不允许各方法各抽一套图像。**

区间来自同一次复制的指标差值，报告差值分布的 2.5%/97.5% 分位数；不能用两个方法各自区间的上下界相减代替配对区间。遇到单类别标签等不可定义情况，明确记录有效复制数与处理口径，不用零静默填充，不隐式改变宏均值类别集合。

这些是固定参考 seed 条件下的探索性区间；不包含支持样本抽取的不确定性。多个 λ/方法对比必须注明点位区间是否做了多重比较校正；未校正时不得写成经过全族错误率控制的显著性结论。`fraction_below_zero` 是 bootstrap 复制比例，不是无需解释就可称为 p 值的数。

### 4.3 可采用的加速与独立复核

原实现每次复制重新排序像素分数，耗时较高。可以先按分数排序并构建并列分数组，再把每张图像的抽样次数作为其全部像素的权重计算 AP/AUROC。这只是精确计算的优化，不能改成近似排序、分箱 AP 或不同的统计量。

加速实现必须先验证：

- 随机分数、并列分数、零权重图像、重复图像抽样、极端不平衡与不可定义情形。
- 对照 sklearn 显式重采样或加权指标；定义一致时绝对误差 ≤`1e-12`。
- 在真实类别上，用若干预先固定的复制编号对照原显式重采样路径，不按结果选择样本。
- 所有 21 个方法点估计对照现有 `metrics.csv`/分析点估计，采用原点估计复核容限 `5e-6`；若采用相同数组和数学指标，预期误差应远小于该值。
- 原九个方法的 1000 个复制在相同 RNG、类别顺序和方法口径下，对照旧 checkpoint；建议绝对容限 `1e-10`。失败时先检查方法轴、指标轴、随机流和无效值政策，不直接扩大容限。

如直接复用旧九个方法的复制序列，只能在源身份及随机流兼容验证后配对新增方法；不能将不同抽样序列的两个数组按下标硬配对。

新数据集选择需按缓存可用性、研究问题及数据角色预先登记，不能看指标后选择最有利的数据集。至少保留 B/C 单支、A1_J/L、DUP；若要声称三分支机制可迁移，则必须包含 S、TRI/BAL 的匹配对照。

### 6.3 全像素与其他暂不扩展项

当前像素结论基于 stride-8。最终论文关键的 A1_J/L、DUP 以及选定的三支控制，需要在相同测试范围用完整 448×448 像素复核，特别关注小缺陷方向是否改变。预先固定比较对象，不只选择改善最大的类别；完整指标与 stride-8 分开命名，不混表比较。

文本评分分支、前景增强、学习型动态融合、新骨干、K8/16 和部署阈值均不是本次统计补齐的默认范围。先完成现有问题的验证，不因用户之前讨论过这些方向而自动扩展。

## 8. 最终如何验收、如何写论文结论

- **A完成**：可以说固定 seed0 下的统计缺口已补齐，说明 L/J、固定 λ 的效应量和区间。不能说已跨 seed 验证。
- **B1完成**：可以说 B/C 权重与匹配约束在第二个预定支持抽样上得到复核或未复现。不能说真实三支已复核。
- **C完成**：可以对实际测试过的三视觉组合讨论跨支持抽样表现。不能说所有分支组合存在已找到的最优解。
- **D完成**：只能在实际覆盖的数据集、K、骨干及指标范围内讨论迁移性；仍不能仅凭有限实验宣称普适准确率上限或无人做过的创新。

效应参考尺度沿用宏像素 AP 的 `0.005`，即 **0.5 个百分点**。超过尺度且区间不含零、区间跨零、效应很小是不同情形；小效应或跨零不等于等价。不要把补实验后的结果反过来包装成事前未见结果的预注册假说。

最后的中文交付应让用户一眼看清：实际做了什么、结果支持/反驳什么、哪些只是实现检查、哪些独立验证仍缺失。若额度或运行条件不足，保存可恢复状态并列明下一条需要实施的动作，不用“全部完成”掩盖阶段性结束。
