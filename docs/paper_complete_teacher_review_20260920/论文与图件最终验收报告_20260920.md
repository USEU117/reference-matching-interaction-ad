## 仍需如实保留的研究边界

当前同机完整证据包含 6 个配置，来自本文 A1 的两种匹配方式以及 AnomalyDINO、PatchCore 两个外部方法家族的四个配置。它能够支持资源对比和同样本定性比较，但尚未达到导师曾建议的约 10 个公开方法规模。补齐更多方法需要实际安装、运行和按同一协议记录，不能用文献数值或推测结果替代。

本文方法使用冻结编码器，没有目标域训练和可报告的训练 loss。Figure S4 因而只检验已存 bootstrap 估计的数值稳定性。Figure S5 统计预处理、编码和评分阶段的和，并包含支持库工作；它不是独立测得的完整进程端到端延迟，也不是 query-only 延迟。显存是 PyTorch 进程内 allocated peak，不能与设备级占用混写。

资源基准限于 MPDD 的 3 个类别、seed 0、K=1 和 4，每个单元 1 次预热和 3 次计时重复。当前 bootstrap 区间是图像级配对区间；像素级全量 bootstrap 区间仍不可用。项目尚未建立公开的永久归档链接，因此 Data and Code Availability 只描述本地可复现材料，没有写入未经验证的公开 URL。
