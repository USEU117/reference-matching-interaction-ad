## 1. 推荐收敛为一个问题

> 在严格正常 K-shot 条件下，增加冻结视觉分支后出现的负增益，究竟来自表征家族被重复加权，还是共同最近邻要求引入了正常参考匹配冲突？这些效应如何随 K 和分支身份变化？

研究对象是工业异常检测及像素定位，不是有缺陷类别标签的少样本分类。推荐把“有限正常参考下的融合失效机制”作为候选主贡献，把单/双/三支比较作为发现和验证这个机制的实验载体。

其中最值得争取的新发现是：**在排除隐式权重改变后，是否仍存在对正常区域特别不利、随参考预算变化的共同匹配冲突？** 当前尚不能说这种机制已被项目证实。

建议工作题目：**《少样本工业异常检测中固定多分支融合的负增益来源与参考预算依赖》**。若最终没有发现预算依赖，则题目与结论必须相应收窄，不强行保留预期故事。

## 2. 为什么这比继续增加分支表更有研究价值

现有 MPDD、seed 0、K2/K4 结果：B+C 的宏 P-AP 均值为 0.366017，B+S+C 为 0.353675，下降约 1.23 个百分点。B 为 DINOv2-B，S 为 DINOv2-S，C 为当前 AnomalyCLIP 的 CLIP 视觉分支。数字与适用范围见配套规划第 3 节。

这只能证明已测组合中的一个现象，还不能区分以下解释：

1. 新增 S 没有足够的条件增量信息。
2. B/S 属于同一模型家族，等权增加 S 实际改变了两类表征的总权重。
3. 多分支必须共同接受同一个正常参考 patch；每支各自能找到正常近邻，但可能找不到共同接受的近邻。
4. 网格、距离尺度、维度、后处理或近邻实现改变带来混淆。

一个有解释力的论文需要通过受控干预区分这些解释。不要根据两张分数图的相关系数直接认定“冗余”，也不要把三支平均下降直接认定为“分支上限”。

## 3. 必须先做的控制：增加分支也可能是在重复计票

各支特征先单位化、等权拼接后单位化时，当前共同最近邻距离等价于在同一参考 patch 上平均各支余弦距离，再取最小值。

- A1 的 B+C 对两个家族各给 1/2 权重。
- B+S+C 等权时，DINO 家族总权重为 2/3，CLIP 为 1/3。
- 因而“分支数变化”和“表征家族总权重变化”在当前比较中同时发生。

应追加以下预先固定的控制，不使用测试标签挑权重：

| 控制 | 分支距离权重 | 作用 |
|---|---|---|
| A1 | B=1/2，C=1/2 | 冻结参照 |
| 精确复制 B+B+C | 各 1/3 | 不增加表征信息，只改变计票；数学上等价于 B=2/3、C=1/3 |
| 实际 B+S+C | 各 1/3 | 当前三支结果 |
| 家族平衡 B+S+C | B=1/4，S=1/4，C=1/2 | 保持两个已知家族总权重各半，检查结论是否改变 |
| 家族平衡 B+B+C | B 两份各 1/4，C=1/2 | 应与 A1 数值一致，作为实现检查 |

实现权重时：若采用加权拼接，单位特征乘以权重的平方根；不是直接乘权重。完全复制应复用同一特征数组，不重新运行随机增强。

解释边界：

- 复制控制的等价性是基本代数，**不是新定理或新方法**。
- 家族平衡只是预先声明的控制，不代表最优权重；B 与 S 也并非完全相同，真实信息变化仍存在。
- 若家族平衡恢复性能，可说此前的结论依赖权重设定；不能直接说已证明全部退化由冗余造成。
- 如果只有这个控制有效，成果更接近评测改进或有价值的纠偏，单独支撑强方法创新仍不足。

## 4. 主机制实验：保持每支信息不变，只干预跨支参考配对

### 4.1 直观解释

假设一个正常查询 patch 与两张参考图的 patch 有如下距离，越小越相似：

| 参考 patch | 分支 B 距离 | 分支 C 距离 |
|---|---:|---:|
| r1 | 0.1 | 0.9 |
| r2 | 0.9 | 0.1 |

各支独立找最近邻后平均得 0.1；要求同一个参考 patch 同时匹配两支，则最小平均距离为 0.5。这个例子只说明一种可能性，**不是实际实验数据，也不证明该 patch 应被判为正常**。

记同一参考行上的各支距离为 d_j(q,r)，固定非负权重 w_j 之和为 1：

```text
J(q) = min_r sum_j w_j d_j(q,r)       # 共同参考近邻
L(q) = sum_j w_j min_r d_j(q,r)       # 各支独立近邻
G(q) = J(q) - L(q) >= 0
```

这条不等式是基础事实，项目正文已有两种几何的解释，R1 已有独立 NN 的 MAP_mean。**G、近邻重合率或再跑一遍 MAP_mean 本身都不能算新创新。** 见[原创新审计](D:/STUDY/My_github/sci_project/docs/project_review_20260910/innovation_audit.md:95)和[已有实现](D:/STUDY/My_github/sci_project/scripts/innovation_breadth_20260908/probe_breadth.py:142)。

### 4.2 真正新增的干预

冻结查询特征、各支参考特征集合、支持图像 ID、K、参考行数、维度、权重、归一化和后处理。只改变某一支参考特征与其他分支参考行之间的配对关系。

| 条件 | 操作 | 应当验证什么 |
|---|---|---|
| 原始配对 | 相同图像、相同对齐位置的各支特征拼接 | 原始联合表示 |
| 共同置换 | 所有分支一起按同一个置换重排参考行 | 联合库只是换行序，J、L、单支图应不变 |
| 单支图内置换 | 仅一支在每张参考图内按预定局部块或位置置换 | 保持图像身份，扰动空间配对 |
| 单支跨图置换 | K>1 时，仅一支在参考图之间置换，尽量保持位置；或另设全局行置换 | 区分图像身份配对与空间配对；K1 的跨图条件记 N/A |

置换必须是双射；不能删除、复制或重新选 coreset。若原库已选子集，在固定子集之后置换。每支单独的完整最近邻分数与 L 应保持数值一致，只有依赖跨支对应关系的 J 允许变化。使用精确 NN，不让近似检索的行序敏感性混入结论。

建议 fp32 重放预注册最大分数误差容限 1e-6；若现有实现可稳定达到 1e-7，则采用更严容限。先检查原始距离，再检查后处理图。不能根据结果临时放宽容限。共同置换造成最近邻索引编号变化不代表分数改变，存在并列近邻时尤其如此。

### 4.3 要发现什么，而不是只看置换是否掉分

核心假设：少量正常参考下，共同匹配要求可能给正常区域增加过大的距离惩罚；更多分支未必增加有效异常证据，而可能增加正常误报。这个假设需同时考察：

1. 原始配对的 G 在正常区域与真实缺陷区域的分布是否不同；三支相对两支增加的部分集中在哪里。
2. 保持各支单独评分完全不变时，配对干预对上述分布和检测结果的影响，是否依赖 K、分支身份与权重控制。
3. 在嵌套正常参考集合 K=1/2/4/8/16 下，这种差异是否系统变化；第三支的增量是否随之改变。
4. 相同分析在共同 NN 和独立 NN 的固定融合中是否给出一致解释。

**仅发现“打乱对应关系会掉分”不足以成为强创新。** 置换也可能意外降低正常或异常距离，方向必须允许双侧结果。配对干预改变的是经验联合分布，同时包含空间对应、共现与联合密度，不能把所有变化归因于抽象的“语义互补”，更不能视为真实生产场景的因果证明。

增加 K 会同时增加参考数量、行数与覆盖机会；G 不保证随 K 单调下降，AP 也不保证单调改善。因此先使用“参考预算依赖”的表述；没有额外控制时不宣称“覆盖不足是唯一原因”。

## 5. 少量但关键的执行与验收

### 5.1 先利用现有缓存做可行性检查

建议新建独立实验名称 `fixed_fusion_mechanism_v1`。本轮没有创建实验运行目录。复用[受控组合脚本](D:/STUDY/My_github/sci_project/scripts/validation_handoff_20260911/run_controlled_matrix.py)和[共同评分模块](D:/STUDY/My_github/sci_project/scripts/validation_handoff_20260911/common.py)，通过新脚本调用，不覆盖旧结果。

第一阶段只用已有 MPDD 六类、seed 0、K2/K4 缓存：

- 完成第 3 节五组控制，并重放 A1。
- 对 B+C 与 B+S+C 做原始、共同、图内、跨图配对条件；正式运行前定义局部块大小、置换规则和随机种子。
- 先用 10 个固定置换种子估算时间和效应稳定性；明确这是探索阶段，不把 10 次置换当成 10 个独立数据集。
- 记录单支/L/J 的数值不变量，G 的区域分布、P-AP、I-AUROC、AUPRO 与逐图预测。仅在数据集提供有效像素标签时计算对应定位指标。

不变量失败先修实现，不解释机制。如果干预只产生全局分数尺度变化、没有稳定排名或区域效应，则记录“当前证据不足”，不要仅凭均值变动宣布发现。

### 5.2 确认性研究

在看确认集结果前冻结方案。至少在 MPDD 和另一个完整数据集（建议 MVTec AD）覆盖全部类别、seed 0/1/2、K1/2/4。若论文核心包含 K 依赖，须增加 K8/16；数据不足的类别明确报告实际 K，不能复制图片充数。

确认阶段的置换次数根据第一阶段实测成本预先固定，例如 30 次；不根据显著性反复增加次数。置换随机性、参考集合随机性和查询样本随机性分开报告。

新增 K 应采用可审计的嵌套支持集合。先核查现有 K1/2/4 是否已嵌套；若不是，保留旧结果并建立新支持协议，不假装旧表具有配对的 K 增长关系。

在能力允许时扩至原规划的四数据集。若要声称普遍的“分支数量规律”，还需增加一个异质视觉编码器，并检查足够的两支/三支子集；只有 B/S/C 时应限定为这几个模型组合。

### 5.3 机制结论的验收

- 所有数值不变量通过；同一比较的支持 ID、查询、权重、几何与后处理完全可追溯。
- 同时给出正常图像、异常图像内正常区域、缺陷区域分析，避免像素数量比例制造表面规律。
- 报告按图像成簇的配对不确定性与类别/seed 的分布；不能把数百万像素当作独立重复样本。
- 区分统计不确定与实际效应。建议把宏 P-AP 的 0.005 作为待预注册的实用效应参考值，而非必须超过 A1 的准入门槛；正式值须在确认集打开前固定并说明理由。置信区间跨零表示证据不确定，不自动等于无效；等价结论需预设等价界并有足够精度。
- 若报告正常误报率，阈值必须来自声明过的正常校准协议。额外正常校准图属于额外数据预算；没有有效阈值协议时报告无阈值的区域分布与排序指标，不用测试标签挑阈值后冒充部署结果。
- 至少提供跨数据集重复出现的实质效应和失败条件；只在 MPDD s0 出现的趋势保持为探索结果。
- 没有证明所有机制均独立可加，就不要把几个 AP 差值当成严格的“总收益分解”等式。

负结果也完成研究任务。若只有恒等式或打乱掉分，主机制创新尚不成立；若控制后先前的三支劣势消失，也应如实报告，转为“分支比较受隐式权重混淆”的较窄结论。

## 7. 两个可作为补充的方向

### A. 增加一个编码器，还是增加正常参考更划算？

比较单支 K1/2/4/8/16、双支与三支不同 K 的精度、参考采集量、参考库内存及完整推理延迟。回答“现有双支 K2 的效果，单支需要多少个已测 K 才达到”。只报告观测范围与置信区间；曲线可能不单调，不能外推一个普适的等效 shot 数。

其价值在于部署决策，作为主机制研究的应用结论较合适；一般的成本 Pareto、加模型/加数据比较已有广泛研究，新颖性风险比主机制方向更高。正常参考采集成本与推理成本不能凭任意系数合为一个所谓公平总预算。

### B. 文本增加的是图像排序能力，还是新的缺陷定位信息？

在 B、C、B+C 的固定分数融合上增加 T，比较：真实文本空间图、将每图文本分数广播到整图、保持每图数值集合但置换空间位置。配合全局像素 P-AP、逐异常图像内像素 AP、I-AUROC，区分图像间分数偏移和图像内空间排序变化。

如果广播项提高 pooled P-AP，不能据此声称定位更准；常数平移不改变同图像内部排名。真实空间文本还需显示超出广播控制的贡献。已有 v7/v8 与评价拆分可作基础，但其结果并非这一完整固定控制矩阵。

这适合作为视觉+文本章节的补充问题；当前未对其全部最近似文献完成独立穷尽审查，不将其列为已确认新颖点。

## 8. 建议给论文保留的贡献措辞

在证据成立后，可按实际结果写成：

1. 建立控制表征家族权重和参考配对关系的实验协议，避免将简单的分支增多直接等同于信息增多。
2. 识别并验证某种固定多分支融合失效机制，明确其正常区域影响、参考预算依赖和跨域限制。
3. 给出增加表征与增加正常参考的经验选择依据，报告适用条件与负结果。

**当前建议先做复制/家族权重控制与配对干预的小规模检查，再决定是否将主机制扩为完整论文。不要为了追求“没有人做过”而承诺一个尚未观察到的结论。**
