# 固定多分支融合的少样本贡献：相关工作、现状核查与实验规划

日期：2026-09-12。状态：**已完成文献检索与本地证据审阅；以下新增实验尚未执行。**

本文件落实用户的新方向：从“不断寻找超过 A1 的新模块”转为研究**冻结编码器、固定融合条件下，视觉分支数量与文本证据如何影响少样本工业异常检测和定位，以及性能、稳定性与成本的经验边界**。它作为后续 AI 的规划入口，保留既有实验与冻结协议，不重写历史结论。

## 1. 结论与论文定位

可以开展，而且已有项目成果提供了可复用基础。但检索已经找到多篇明确相关的研究，**不能以“没人做过多分支/视觉文本融合”为论点，也不能只多做一张三分支表就认定有新创新。**

更合理的研究问题是：

> 在仅有 K 张正常参考图、编码器冻结、融合规则固定且评测条件一致的情况下，增加视觉编码器或文本引导证据，何时改善工业异常检测，何时因冗余、错误匹配或尺度失衡而退化？这种边际贡献如何随正常参考预算、缺陷类型和计算成本变化？

推荐定位为**有机制分析的受控实证研究**。新颖性需要来自可复核的新发现、对混淆因素的拆分、跨数据集验证与可复用协议，而不是常规拼接本身。是否达到具体期刊的贡献要求仍取决于最终结果和目标期刊，不能承诺录用。

建议暂用研究题目：**《固定多编码器融合在少样本工业异常检测中的收益、冗余与性能—成本权衡》**。英文可为 *When Does Fixed Multi-Encoder Fusion Help Few-Shot Industrial Anomaly Detection?*。这些是建议题目，不修改当前 DCFnet 稿件名称。

“边界”须指明是**给定候选、K、数据集、指标和成本约束下的经验表现**；不能写成全局最优、准确率理论上限或“双分支普遍最佳”。本项目任务是正常/异常判别及像素定位，不是一般工业多类别识别，主指标也不能笼统称 accuracy。

## 4. 新研究必须改变的规则

旧任务书的目标是“找能超过 A1 的候选”，因此 G1 失败后停止扩测是合理的。**新研究要描述收益和失败的边界，就不能只把胜者送去跨域确认。**

另立 `fixed_fusion_study_v1`：预先冻结有限矩阵、支持样本、评分/融合、指标、预算；所有核心组合按同样范围完成。资源不足可在看结果前缩小范围，并相应收窄论文题目；不能因某组合输了就从主表删掉。旧实验继续保留原来的 gate_fail，新研究不改判历史门。

主目标由“过 +0.01 门”改为“回答预先列明的效应问题、完整报告效应大小与不确定性”。新的强机制、前景或动态模型暂不作为这篇主研究的依赖；它们单独保留后续路线。

## 5. 分支与模态先定义清楚

- **视觉编码器数**：真正参与查询图前向的不同视觉编码器个数。多层、多尺度、多次增强不自动算新编码器。
- **评分证据路径数**：独立产生异常分数的规则数。例如同一个 CLIP 图像特征既可做正常库匹配，也可做图文相似度。
- **输入模态数**：RGB 图像与文本提示。DINO+CLIP-image 仍是同一 RGB 输入的两个视觉表征，不能称 RGB+文本已经参与推理。
- **T**：冻结 CLIP 文本原型与查询图像/patch 的相似度证据。T 必须读取图像特征；“纯文本不看图判断这张图异常”不是合法检测对照。

因此 B+C+T 是“两视觉编码器 + 一条文本引导证据”，不等于三个独立视觉模型。T 复用 C 时计算与错误有依赖，需要显式画共享节点。若 B+T 仍要调用 CLIP 图像塔，成本表应记录两个视觉编码器，不可隐去它。

冻结 T 本身消耗 **0 张正常参考图**，不随 reference seed/K 改变。注册表增加 `support_consumed_by_path` 与 `K_effective`：T-only 标为 `K-invariant`，每数据集/类别只保存一份主结果；对照表可引用到各 K 列，但不得重复计算为独立运行或声称 T 获得了 K-shot 学习收益。B+T 等组合中的 K 只作用于视觉正常库。若文本原型后来依支持图更新，那已是另一种 T，须单独登记。

不能将一个对所有同类图都相同的文本向量直接复制到每个正常/查询 patch 后拼接，便声称增加了异常证据。文本必须参与图像条件的相似度或预测；若使用新的投影、prompt 训练或额外视觉层，必须在文本关闭对照中保留同样视觉处理，隔离文本语义贡献。

## 6. 实验矩阵：两种固定融合分开研究

### 6.1 第一组：视觉特征融合，承接现有 A1

固定三视觉 B/S/C，比较所有七个非空子集：

| 分支数 | 配置 |
|---|---|
| 1 | B、S、C |
| 2 | B+S、B+C、S+C |
| 3 | B+S+C |

逐支 L2、等权拼接与联合 L2，参考 patch 身份和几何一致，精确 1-NN；C-only 主对照使用相同对齐网格。旧 A1 后处理与评价保持一致。匹配式写为：

`s_feature(q) = min_r mean_j d_j(q, r)`。

### 6.2 第二组：统一的固定分数融合，容纳文本

各视觉分支独立从相同正常支持库产生分数，再平均：

`s_score(q) = mean_j min_r d_j(q, r)`。

先按这一算子也跑七个视觉子集，再引入 T。四个证据源 B/S/C/T 的全部非空子集共 **15 组**：

| 路径数 | 配置 |
|---|---|
| 1 | B、S、C、T |
| 2 | B+S、B+C、S+C、B+T、S+T、C+T |
| 3 | B+S+C、B+S+T、B+C+T、S+C+T |
| 4 | B+S+C+T |

最后的四路径配置增量评分成本较低，可帮助检查文本贡献是否依赖已有视觉组合；它仍只有三个视觉编码器，不是四视觉实验。七组 feature 与十五组 score 是两个实验臂，单支结果可在数值身份一致时共用，不能当 22 个独立算法或独立样本。

**必须额外保留 A1_joint + T：** 将冻结 A1 共同近邻图与 T 融合，而不是仅运行独立 B-score+C-score+T 后称“给 A1 加文本”。预登记主式为 `(2·A1_joint + T)/3`，与视觉证据共占 2/3 的 B+C+T 相对应；另以 `(A1_joint+T)/2` 作为将 A1 视作一个专家的固定敏感性对照。二者完整记录，不能看结果挑定义。先核查公共缩放和网格一致。

这里“相对应”只表示视觉与文本的总权重一致，**不表示数值等价**：`A1_joint+T` 的两视觉共同选近邻，score-B+C+T 的两视觉各自选近邻；两者必须保存独立 configuration ID、预测和指标，不能合并为一次运行或把一个当作另一个的复现。分别估计“文本加入 A1”和“文本加入独立视觉分数集成”的效应。

上述两个 min/mean 次序一般不等价；在同一组非负距离和同一候选支持集合下，`s_feature >= s_score`。这是简单代数性质，**不是新定理，也不意味着 P-AP 更高**。可以测其差值在缺陷和正常区域的分布，以及两分支独立最近邻身份是否一致，用作机制解释。

### 6.3 T 的最小合法实现与公平性

1. 选定一个官方支持图文对齐的冻结特征 tap、文本编码器和 checkpoint，保存 prompt 列表与哈希。不要把缓存目录 `anomalyclip_text` 当成真实文本输出。
2. T-image 与 T-pixel 分开：全局语义分数用于 I-AP / I-AUROC；空间文本分数才能用于像素定位。将一个图像标量广播到整图可以改变跨图像排序，但不提供图内定位细节，应独立标识。
3. 主文本规则可固定正常/异常原型余弦差：`T=(cos(z,t_abn)-cos(z,t_norm)+2)/4`，值域 [0,1]；视觉余弦距离统一映射为 `(1-cos)/2`。这只是无拟合的尺度约定，不代表已经概率校准。A1 原始距离按同样正比例缩放，旧指标应数值一致。
4. 为排除固定融合受数值尺度主导，至少加一项预登记敏感性：官方温度的二类 softmax 文本分数，保持同样提示和视觉特征。若结论随转换翻转，应写“尺度敏感”，不能写“文本本质有害”。禁止逐图 min-max、测试集分位数拟合或用测试 AP 选温度。
5. 文本语义控制：一组通用正常/异常提示为主，已知产品名提示为预定补充；用正常/异常原型置换作实现/语义检查。类别置换仅对含类别名提示有意义。不得根据测试缺陷名称人工补专属 prompt 后仍称无额外信息。
6. 所有含 T 的组合共享同一 T 缓存和尺度规则；新增可学习投影/区域解码器则另立方法，不混在“仅固定融合”主矩阵里。

像素主矩阵使用 T-pixel，各方法从融合后的同一完整异常图取 max 作为图像主指标。若增加 T-image 全局语义评分，则另开 image-only 表：视觉图像分数先按统一 max 生成，再与 T-image 固定融合。不能在一个表里对 T 使用全局语义、对视觉另择 top1%，然后将差值全部归因为模态贡献。

## 7. 数据、参考预算与执行规模

核心矩阵覆盖现有四数据集：MPDD 6 类、BTAD 3 类、MVTec AD 15 类、VisA 12 类，共 36 类；K=1/2/4，reference seed=0/1/2，共九配置。各类别先聚合测试像素计算 AP，再作类别宏平均；不可混成跨类别 micro AP。

主结果先分别报告四个数据集。如报告总体效应，主汇总固定为**等数据集权重**：每数据集先平均类别，再均匀平均九参考配置，最后四数据集等权平均。36 类直接等权平均只作为明确标注的补充，不能与主汇总互换。bootstrap 每次重采样后执行同一聚合顺序，不把三个类别的 BTAD 自动降为十五类别 MVTec 的 1/5 权重。

- 七组视觉 feature：7×36×9=**2268** 个方法–类别–配置单元。
- 十五组 score：15×36×9=**4860** 个任务单元，含可共用的单支；A1_joint+T 两种预定权重另列。
- 上述 score 数量为完整表格的配置槽位，不等于实际独立运行数；T-only 的 36×9 个槽位引用 36 份 K-invariant 结果，预算和覆盖表需显式去重。
- 单元不是独立数据集；同一测试图重复不同支持配置，bootstrap 必须配对。

无需为每个融合重新跑所有编码器。查询特征如果确实不依赖支持集、seed 和 K，可按图像/模型/预处理哈希提取一次；正常参考特征只导出实际需要的图像。复用前核验几何、权重、feature tap、test IDs、ref IDs，不通过则局部重导。6 GiB GPU 上可顺序导出，不能把多模型同时驻留作为唯一实现。

若论文声称“融合的帮助随正常样本增多而饱和”，**需要补 K=8/16**；只有 K1/2/4 就限定结论在这个小范围。新增 K 尽量使用嵌套参考集，但不能改写旧 manifest；旧 K 若非嵌套，保留旧协议并另建嵌套敏感性组。参考 seed 至少三组承接历史，关键效应建议另加两组；它们仍不构成新的测试域。

MPDD 已被大量探索，BTAD/MVTec 也看过，均不得称新盲测。先锁定全部新分析，再跑冻结迁移。现有 AnomalyCLIP 权重对 VisA 的来源关系保持 in-domain 标记；不同新增模型各自披露训练数据。若主张广泛跨域规律，优先增加一个未参与开发、且预训练/源训练关系可核查的新工业数据集，而不是继续重复旧测试集调参。

## 8. 怎样把分支数与身份、容量、模态分开

**第一层，必须完成：** 七视觉子集和十五评分子集内，报告每一条“添加一个证据源”的边际差值。例如 S 加到 B 与 S 加到 B+C 是不同干预，不用两个表的整体排名替代。

固定等权添加新支会同时重新分配旧支的权重。因此边际差值是**在这一固定融合规则下的增量效果**，不能声称测出了新支独立的信息量。对主要正/负例做少量冻结权重敏感性，保留零权重回到原组合的实现检查；不得由此开展无限调参。

**第二层，机制控制：**

- 单支与自身复制的 B+B：正确归一化下应等价于 B，用于排除“只是多了一个框或维度就提升”的解释。
- B+C+B 等权并不等价于 B+C，它把 B 总权重变成 2/3。若复制只用于无新增信息控制，拆分复制项权重、保持每个原证据总权重不变；若研究重加权，明确列为重加权对照。
- 记录原始维度、支持 patch 数和内存。增加固定总维度的预登记投影敏感性，如总 384 维、三个固定投影 seed，保留未压缩主表；投影不允许用测试标签拟合，不以挑最优投影代替报告重复结果。
- 分别报告单支质量、排名/错误相关性、近邻冲突与融合增益。低相关不等于互补，相关分析不等于因果；需要结合上面控制和跨域重复。

**第三层，如果希望标题概括“多编码器规律”，建议必须增加一个异质视觉家族：** 例如先核查已有 PatchCore 所用 CNN 能否导出固定特征并接入共同匹配器。只有一个 B+S+C 三支组合，无法区分“所有第三支都无用”和“新增 DINO-S 冗余”。新增第四视觉 D 后，可比较四个 single、六个 pair、四个 triple，共十四个不超过三视觉的组合；与原七组重合者直接复用。D 的选择在看性能前依可用权重、成本与表征差异确定，不从十个骨干里挑最好者。

D 不需要立刻与全部文本子集交叉。先检查三视觉结论是否随第三视觉家族改变，再决定是否扩文本稳健性。若资源只允许 B/S/C，应把论文范围写成“DINOv2 与 CLIP 的受控研究”，避免泛化成所有多分支系统。

## 9. 指标、统计与“边界”的验收

主要像素指标 P-AP；同时报告 P-AUROC、AUPRO@0.3，图像级 I-AP/I-AUROC。图像 max 与 top1% 的敏感性应明确分列；不得为不同候选选择各自最佳图像聚合然后声称同条件。

主表延续 448 网格、stride=8 以复用历史；新文本/小缺陷结论必须补全 448 像素敏感性，因为 stride=8 可能漏掉细小缺陷。测试标签只用于指标与事后诊断，不给预测器或融合参数。F1-max 不是可部署阈值。

建议提前锁定三个主要效应：

1. B+C 相对预定的组成单支 B：是否有增益，哪些类别例外？同时报告相对 C 与完整单支分布。
2. B+S+C 相对 B+C：增加 S 在各 K、数据域的增量。
3. A1_joint+T 相对 A1：文本证据的增量，图像与像素分别检验。

其他子集用于完整描述，不以事后最优单支/最优双支当作未选择的确认对照。可额外展示“候选集合中事后最佳”的包络，但注明使用测试结果选择、存在乐观偏差，不能当可部署路由或普遍上限。需要部署选择时，在开发集锁定一次再外测。

统计沿用配对整图 bootstrap，类别内按正常/异常分层、全部模型及参考配置共享抽样索引，B=2000、固定 RNG；参考集变化另外报告。主要三个效应若作显著性结论，应处理多重比较（如预登记 Holm 校正），完整探索矩阵的 CI 标为描述性。跨类别相关与测试像素不能被当成海量独立样本。

主要检验家族明确为上述三个效应在主 **P-AP、K1/2/4、三 seed、四数据集等权总体**上的三项配对比较，使用预登记的双侧配对检验及 Holm 家族错误率 0.05。图像指标、逐域/逐 K 和其余组合为次要或探索分析；若要对它们作确认性显著主张，运行前另登记比较家族，不能事后扩家族而沿用未校正的 p 值。bootstrap CI、检验 p 值与参考 seed 变异分开报告。

区分三种结论：

- **有增益：** 报告点估计、配对区间、逐类/seed/shot 稳定性和成本；不能仅凭宏平均为正。
- **退化：** 同样保留完整证据，说明在哪个固定规则与域发生；不因负结果删除实验。
- **近似无差异：** CI 跨零只表示证据不足，不证明等价。若要写“饱和/无实用增益”，需预定实用等价界（建议 P-AP ±0.005）并做等价判断；区间太宽则结论为不确定。这个界是工程判断，需在看新结果前冻结。

性能—成本边界使用完整可部署管线的 P-AP / I-AP 与延迟、显存、正常库字节绘制 Pareto 图。只在给定预算和已测候选中描述支配关系，报告 bootstrap 不确定性；单个指标最好不等于全方位最好。
