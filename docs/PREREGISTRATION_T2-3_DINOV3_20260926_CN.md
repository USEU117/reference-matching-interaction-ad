## 二、条目要素

### 1. 要回答的问题（可证伪）

在同一冻结协议（单层特征、0.5/0.5 concat、faiss top-1、支持集身份与槽位权重不变、0 目标域可训练参数）下，把**冻结基座由 DINOv2-B/14 替换为 DINOv3（同量级档）**后：

- **Q1**：MPDD 六类宏 Pixel-AP 的净变化 Δ 有多大？
- **Q2**：该 Δ 是否随**匹配模式**（J 共同参考 vs L 各自最近）改变？
- **Q3**：该 Δ 是否随 **shot 水平**（k2 / k4）改变？

**反证条件**：若任一 cell 出现"宏 Δ ≥ 门槛但 worst 类 < −0.03"，或"ΔAUROC 退化超过 −0.005"，则本条目的正向假说被否。

### 2. 因子与水平

| 因子 | 水平 | 说明 |
|---|---|---|
| 表征（主因子） | 控制 = DINOv2-B/14（= 论文 A1 的视觉塔）；候选 = DINOv3 同量级档（档位待定，见 §三） | 只换这一项，其余全部固定 |
| 匹配模式 | J（共同参考）/ L（各自最近） | 与论文主表同定义，用于 Q2 |
| shot | k2 / k4 | 与论文主表同定义，用于 Q3 |

### 3. 固定不变量（不得随基座改动）

- 特征**层选择**：单一固定层（不做多层扫描，多层属 T2-1，另行处理）。
- 融合：0.5 / 0.5 concat；匹配：faiss top-1；距离：1−cos；输出分辨率：与论文一致的 448 map。
- 支持集身份、槽位权重、查询集、六类宏口径、seed0。
- **token 网格对齐（关键）**：DINOv3 的 patch 尺寸 / 推荐分辨率与 DINOv2-B/14 不同，必须先把候选编码器的特征**重采样/插值到与 A1 相同的网格行 unit**，再进入 concat 与记忆库。**不得**同时改动输入分辨率（ANoCo 的 768 输入 / 增强 / 显存与本项目协议冲突，禁止引入）——否则基座效应与几何/分辨率混杂，结论不可引用。

### 4. 指标与区间

- 主指标：六类宏 Pixel-AP（与论文主表同口径）。
- 副指标：Image-AUROC（不得退化超过 −0.005）。
- **必须报告**：逐类 Δ 方向 与 **worst 类 Δ**（禁止只报宏）。
- 区间：图像级配对自助（沿用主表同一抽样流 `default_rng([20260913, dataset_id, category_id, replicate])`）；**不**把区间跨零写成零效应，写"区间跨零，方向未定"。

### 5. 成功判据（真实门，逐 cell 判定）

在 **k2 与 k4 两个 cell 均**满足：

- lead 宏 ΔAP **≥ +0.01**；且
- worst 类 Δ **≥ −0.03**；且
- ΔAUROC **≥ −0.005**。

### 6. Control parity（先决，未通过则本条无效）

新 harness 必须**精确复现**冻结控制值：k2 = `0.343706`、k4 = `0.388328`。任何偏离 > 1e-6 即判定 harness 不一致，候选数字一律不可信。

### 7. 预注册变体全集（含预期失败者，全部报告）

- 候选基座 × {J, L} × {k2, k4}：**四格全报**；
- 附加诊断（**不设门**，仅用于归因）：候选基座的"仅视觉分支"单支读数、以及池化/归一化差异的敏感性探针。

> lead 由**预注册规则**（宏最优且过门约束）选定，**不**由"看起来最好的那个变体"事后选定。

### 8. 泄漏审计

执行前检索候选 harness 代码，确认：ground-truth 字段不进入参考统计构造、类别选择、路由或超参选择路径；仅使用支持集与（推理时）无标签量。审计结果写入产物 payload。

### 9. 杀 criterion（不通过即关轴或改轴）

- parity 不通过 → harness 作废，重写；
- 任一 cell 宏 Δ < +0.01 且 worst 类受损 → 该 cell 判负；
- 两 cell 均判负 → **本条目标记为负结果并归档**（负结果同样是结果，作为 limitation / future work 证据），**不**改口径、**不**缩小数据集、**不**把跨零写成零效应。

### 10. 成本估算

需对候选基座**重新提特征**（MPDD 六类 support + query），估 **≈ 4–10 GPU 卡时（单卡 6 GB 串行；含重采样与 parity 复跑）**。**> 2 h 阈值 → 只预注册，不当场跑。**

### 11. 产物落盘（执行时）

- 目录：`experiments/dynamic_fusion/innovation_t2-3_backbone_20260926/`（新目录，前缀待作者确认）；
- 内容：预注册 payload（含 `preregistered` 字段）、逐 cell JSON、逐类 CSV、控制 parity 断言日志、泄漏审计记录、单一可复现命令说明。

### 12. 不可主张的红线（四条）

1. 不得宣称"首次把 DINOv3 用于少样本工业异常检测"（HyperFSAD 已落 MPDD/BTAD）；
2. 不得把"换基座"本身写成**方法创新**（`22_..._CN_20260903.md` 禁止清单第 6 条明令）；
3. 不得为对齐 ANoCo 而引入 768 输入 / 25+5 增强 / 大显存配置（破坏本项目口径）；
4. 不得在此条目内**顺手**改多层特征或注意力重加权（那属 T2-1 / DuoAD 轴，须另立预注册）。
