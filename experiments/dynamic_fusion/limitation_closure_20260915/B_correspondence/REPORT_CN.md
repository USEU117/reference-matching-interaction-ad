**判定（如实）**

2. **"在该口径下显著排除零"这一判定不稳健**：在主规则 ε=0.1·IQR 的 OT（Sinkhorn 软对应）下，
   I_TRI 与 I_BAL 的 98.75% 族式区间**都跨零**，即"排除零"从"是"翻成"否"。这是本次补充实验
   **改变**了既有结论的唯一一处，必须照实写进论文（不能只挑 identity/procrustes/shuffled 三条写）。

   （I_TRI +0.008345 [+0.002420, +0.014560]、I_BAL +0.009096 [+0.004384, +0.014729]，均排除零），
   翻转只发生在 ε∈{0.05, 0.1} 这段"软混合"区间、且 ε=0.5 又回到排除零。
   即：翻转的成因是**软混合把 C 支平滑了**，而不是"选了另一种画布对应"。
3. 翻转的机制不是点估计崩掉，而是**条件间离散度变大**：4 个条件里 `s1K1` 的交互由正转负（I_TRI −0.00216 vs identity +0.00441；I_BAL −0.00074 vs +0.00458），同时 `s1K4` 变得更大（+0.01674 / +0.01466）。逐条件对照见 §4.2。
4. **OT 计划本身几乎不携带"画布位置对应"信息**：OT 计划的**对角质量中位数 0.000949，而随机基线是 1/P = 0.000977**，即与画布对角的一致度处于偶然水平。这与 B1 审计（MPDD `match_exact` 均值 5.93%、`positional_information` 5.87%）互相印证：跨分支描述子的余弦代价太"平"，OT 解出的软对应基本不是画布对应。
5. **必须同时说明 OT 变体的性质**：在主规则 ε=0.1·IQR 下，每行最大权重中位数 0.0441（≈20–40 个画布位置的加权平均）。所以 OT 不是"重标号（relabel）"，而是**软混合（会同时平滑 C 支）**。它与 identity / procrustes / shuffled 有一个不可回避的不对称：后三者保持 C 支描述子的多重集不变，OT 软混合会改变它。因此 §6 另报了 **ε→0 硬对应（LAP 精确分配）** 这一"保持多重集"的极限作为对照——结果正是这一对照把翻转归因于软混合而非对应选择。

6. **BTAD（§7）**：BTAD 上的**四变体**（identity / procrustes / shuffled / ot_sinkhorn）与 **ε∈{0, 0.05, 0.5} 扫描**
   已在**同一次运行**中一次性补齐（全 3 类，115 min，见 §7.1）。
   BTAD 上 **identity 本身就不排除零**（I_TRI +0.000013 ✗ / I_BAL −0.000801 ✗），
   其余变体**也全部不排除零**（procrustes 与 identity 逐值相同；shuffled +0.002338 ✗ / +0.002172 ✗；
   OT(ε=0.1) +0.001151 ✗ / +0.001035 ✗；OT 硬指派 ε→0 +0.002197 ✗ / +0.001483 ✗）。
   即：**对应方式的替换没有改变 BTAD 上的判定**——只不过 BTAD 上的判定本来就是"不显著"，
   所以这是一条一致性证据，**不是**对 MPDD 那个翻转的复现（见 §7.5）。
   口径核对：本 harness 的 identity 在 MPDD 与 BTAD 上都复现了论文 **S（DINOv2-S）分支**的符号与零排除判定
   （BTAD 对照值 +0.00029 ✗ / −0.00052 ✗），因此这里的 BTAD 结论只适用于 S 分支那一档配置。

## 2. OT（Sinkhorn）变体的实现

### 2.1 代价矩阵（只读 support 参考描述子）

`support_cost_matrix`（L132-153）：

```
cost[p, q] = mean_i ( 1 − <b_ref[i, p], c_ref[i, q]> )      i = 1..shot
```

- `b_ref` / `c_ref` 是**参考（support）描述子**，取该条件实际使用的前 `shot` 张参考图；
  **不使用任何 query 行、不读取任何 GT**（GT 只在 `evaluate_variant` 里、打分之后用于评价，见 §3.3）。
- 行已单位化，故内积即余弦；实测 `cost` 中位数 ≈ 0.99–1.02，全矩阵跨度仅 ≈ 0.14–0.21。
- B/C 描述子宽度同为 768，可直接做跨分支余弦（函数内断言两者等宽）。

### 2.2 正则系数的先验规则（**在看到任何交互量之前定下**）

```
eps = OT_IQR_FACTOR × IQR(cost),    OT_IQR_FACTOR = 0.1（固定常数，脚本 L85）
```

- **为什么不用中位数**：跨分支余弦带一个很大的常数偏置（中位 cost≈0.99），其**水平**不携带信息；
  只有 cost 的**离散程度**才决定对应是否可解。所以规则锚在**成本的稳健离散度（四分位距 IQR）**上。
- IQR 由该单元的 support cost 矩阵算出（`np.percentile(cost,[25,75])`，L212-214），
  `OT_IQR_FACTOR=0.1` 是**对所有单元、所有条件同一个常数**，不做逐单元调参、不做逐数据集调参、不看结果调。
- 实测：`eps` 落在 0.002267–0.004374（中位 0.003032），`IQR` 落在 0.022667–0.043740（中位 0.030319）。
- 为了便于复核，§6 把 `OT_IQR_FACTOR ∈ {0, 0.05, 0.5}` 的整张扫描表也一并给出（0 表示 ε→0 硬对应）。
  扫描与主规则用同一份代码、同一批自助、同一批条件，只改这一个常数。

### 2.3 求解器与收敛判据（不新增依赖）

`sinkhorn_plan`（L155-192），**log-domain Sinkhorn**，只用 numpy + `scipy.special.logsumexp`（scipy 是本项目既有依赖）：

- 均匀边缘分布 `a = b = 1/P`；核 `K = exp(−cost/eps)` 在 log 域中隐式使用，
  因为 `cost/eps` 在尖锐设置下可达 1e3，普通 exp 核会下溢。
- 迭代：`f ← log a − logsumexp(g ⊘ K)`、`g ← log a − logsumexp(f ⊘ K)`（L182-183）。
- 收敛判据：每 25 次迭代检查一次**边缘相对违反量**
  `max( max|expm1(log rowsum − log a)|, max|expm1(log colsum − log a)| ) < 1e-10`（L184-189）。
- 上限 `max_iter = 5000`（L87）。**无论是否收敛，都把实际迭代数与实际边缘误差写进 `ot_info.csv`**。
- 实测：迭代 50–100 次，边缘误差 3.3e-14 – 8.9e-11，全部收敛。
- 计划 `Γ = exp(f ⊕ g − K)`（L191），随后**按行归一化**得到软对应矩阵 `M[p,q] = Γ[p,q] / Σ_q Γ[p,q]`（L219）。
  即"B 的画布位置 p 有多少份额落到 C 的画布位置 q"。

### 2.4 怎么作用到描述子上

`apply_variant` 的 OT 分支（L271-281）+ `mix_positions`（L256-264）：

- 只改写 **C 支**：`C'_p = Σ_q M[p,q]·C_q`，query 与 reference 行**都**改写，然后逐行重新单位化。
- 按图分块（`MIX_CHUNK = 16`）做，因为 BTAD-03 的 query 块是 441×1344×768 float32（≈1.8 GB），
  整块 einsum 连同其转置布局中间量放不下；每个输出行只对画布位置求和，分块不改变算术。
- B / S 支不与 `data` 复制、直接共享（L274-277），只为降低峰值内存；不改变任何数值。

### 2.5 ε→0 的硬对应极限（`factor = 0`，L215-235）

`eps = 0` 时熵正则退化为精确指派，用 `scipy.optimize.linear_sum_assignment` 求同一 cost 的最优置换，
`M` 成为置换矩阵。**这一支保持 C 支描述子的多重集不变**，因此与 `shuffled` 是同一类对象、可以直接比较；
它也是计划里 VB.2 提到的"温度趋于 0 的硬对应"。它作为扫描点单列，不参与主规则。

## 5. 判定：结论是否随对应方式改变

**分两层回答，不用一句话糊过去。**

**第一层，"交互为正"（方向与量级）**：**不随对应方式改变**。
四个变体（画布 / Procrustes / 空间置换 / OT 软对应）的 I_TRI、I_BAL 点估计全部为正，
OT 下为 +0.0059 / +0.0057，与 identity 的 +0.0077 / +0.0055 同量级。
对"几何对齐只是画布约定"这一疑虑，**这一层是支持的**：换掉对应方式，交互的符号与量级都没翻。

**第二层，"在该口径下 98.75% 区间排除零"（统计判定）**：**会随对应方式改变，必须如实写**。
- 画布 / Procrustes / 空间置换：八条（2 交互 × 4 变体中的 3 个）全部排除零。
- OT（Sinkhorn 软对应）：两条**都跨零**（I_TRI [−0.002049, +0.016528]；I_BAL [−0.000649, +0.014472]）。
- 驱动因素是逐条件方差：`s1K1` 由正转负，`s1K4` 幅度变大。

**为什么这一层要谨慎解读、以及对照的结果**

OT 只改写 C 支的**软混合**，每行最大权重中位 0.044（≈20–40 个位置加权平均），
它同时平滑了 C 支；而 identity / procrustes / shuffled 都保持 C 支描述子多重集不变。
因此 §6 用 **ε→0 硬对应（LAP，保持多重集、共享同一成本矩阵）** 做对照来分离两种成因：

- **对照结果（§6.1）：硬对应下 I_TRI +0.008345 [+0.002420, +0.014560]、I_BAL +0.009096 [+0.004384, +0.014729]，
  两条都排除零**（I_BAL 约为 identity 的 1.7 倍）。翻转没有出现。
- 而 ε=0.5（更糊）也排除零，翻转只出现在 ε∈{0.05, 0.1} 这段中等软混合区间。

⇒ **判定**：第二层的翻转归因于"OT 软混合同时平滑了 C 支"这一附加效应，
**而不是**"换了画布对应"。因此对论文而言更准确的表述是：
结论**不依赖画布对应这一选择**（identity / Procrustes / 置换 / OT 硬对应 四类替换下方向与零排除判定都不变），
但当"替换"同时改变了 C 支的信息内容（软混合式 OT）时，零排除判定会失效。

**论文措辞建议（必须遵守 AD-9 边界）**

- 可写："交互为正不依赖于画布对应这一具体选择（画布 / 正交线性对齐 / 位置置换 / 基于同一描述子代价的 OT 硬指派 下，
  方向与 98.75% 零排除判定都一致；OT 硬指派下 I_TRI +0.0083、I_BAL +0.0091）。"
- 可写（并给出机制）："当把对应替换改为**熵正则 OT 软对应**（ε=0.05–0.1·IQR）时，
  该替换除改变对应外还对 C 支描述子做了 15–40 个位置的加权平均，此时两个交互的族式区间不再排除零
  （I_TRI [−0.0020, +0.0165]、I_BAL [−0.0006, +0.0145]）；ε→0 与 ε=0.5 下零排除判定恢复。
  因此这一失效应归因于软混合带来的额外平滑，而非对应选择本身。"
- **不可写**："已证明画布对齐正确"、"画布位置描述同一物体部位"。工作流 B 只能量化风险 + 证明不依赖对应选择。

### 10.1 疑点

有人指出：`interaction_rows()` 可能是对**四个条件的点值取分位数**得到 98.75% 区间，
而不是用**逐副本（image-level bootstrap）序列**。若属实，则表 17 / §4.2.12 的区间与主研究口径不一致。
本节核实该疑点。

### 10.2 代码实读（关键行号与片段）

`scripts/limitation_closure_20260915/b2_learned_correspondence.py`：

| 位置 | 代码 | 作用 |
|---|---|---|
| **L375-381** | `def interval(values, level): ... return (float(v.mean()), float(np.percentile(v, (1-level)/2*100)), float(np.percentile(v, (1+level)/2*100)))` | 区间 = **对传入数组取分位数** |
| **L426-453** | `def interaction_rows(rows, variants, args, dataset="mpdd")` | 数据集级宏交互 |

| **L444-445** | `stats95 = interval(per_condition, CI_EXPLORATORY)`；`stats9875 = interval(per_condition, CI_FAMILY)` | **对 4 个点值取分位数** |

**判定：疑点属实。** 95% 与 98.75% 区间都是对 **4 个条件级点值** 取分位数得到的，
`CI_FAMILY = 1 - 0.05/4 = 0.9875`（L73）只用于分位水平，与自助副本数无关。
以 4 个点时 `np.percentile` 在 0.625%/99.375% 处插值，区间实质上≈这 4 个条件点值的 `[min, max]`
（可复核：identity I_TRI 的 4 个条件值 `+0.00401/+0.00949/+0.00441/+0.01277` → 区间 `[0.004014, 0.012712]`，
与 `interaction_by_variant.csv` 逐位一致；I_BAL 同理 → `[0.003237, 0.010488]`）。

### 10.3 与 §1.3 / §4.1 的表述是否矛盾

**不构成逻辑矛盾，但口径确实与主研究不同。**

- §1.3 写"1000 次自助、`replicate_weights` 确定性、四变体逐条件共用同一批权重"——**这句话本身为真**：
  `evaluate_variant` 里确实按单元跑 `replicate_weights` + `pooled_ap_auroc`，四变体逐条件共用同一批权重。
- §1.3 / §4.1 写"区间 = 条件级 95% 探索性 + 4 成员族式 98.75%"——**"条件级"三字是准确的**：
  区间是对 4 个条件取分位，不是对自助副本取分位。
- **真正的问题**是：自助序列只在单条件 AP 内部被使用，**从未进入交互量的区间**。
  因此"用了 1000 次自助"与"区间来自自助序列"是两件事；论文表 17 的注释
  （`1000 paired replicates, the same bootstrap stream for every row`）会被读成后者。

对照主研究口径（`scripts/limitation_closure_20260915/e1_fullpixel_ci.py`）：
`_interaction_series`（L475-488）先在**每个副本内**算 `a-b-c+d` 再跨条件取均值，得到长度 1000 的序列；
`_interval`（L465-472）对该序列取分位数。`E1_fullpixel_ci/V1_3_END_TO_END.json` 显示
这条链复现已发布的 `interaction_aggregate.csv` 的 ci9875，`max|Δ| ≤ 4.14e-11`。
⇒ **主研究口径 = 逐副本自助序列分位；B2 口径 = 4 个条件点值分位。两者不是同一个量。**

### 10.5 影响与最小修正方案（**未执行，留作者决定**）

**影响面**

### 10.8.4 核心结论：主口径下"软混合跨零"**不再成立**

**结论（实测）：不成立。** 在 MPDD 上，主口径下**全部 14 个区间都排除零**，包括此前唯一跨零的
OT 软混合两条（ε=0.05 与 ε=0.1），以及 ε→0 硬指派与 ε=0.5。要点：

1. **"软混合跨零"是旧口径的产物**。旧区间 ≈ 4 个条件点值的 `[min, max]`，而 4 个条件里 `s1K1` 在软混合下
   由正转负（I_TRI −0.00216、I_BAL −0.00074）→ 于是"区间跨零"。换到主口径后，区间不再包含条件间极差，
   该格下界回到 **+0.043 点**（I_BAL）/ **+0.191 点**（I_TRI），排除零。
2. **§6 的"非单调 ε 形态（0→是、0.05→否、0.1→否、0.5→是）"同样不成立**：新口径下四个 ε 全部排除零。
   因此"翻转归因于软混合平滑了 C 支"这一机制叙述**失去观测依据**，应当删除。
3. **§5 的第二层判定（区间分离会随对应方式改变）不成立**：14/14 排除零，两个层面（符号、区间分离）都稳健。
4. 仍然成立、可以照写的部分：交互的**符号/量级**不随对应方式改变（含 ε→0 硬指派）；软混合**同时改变
   C 支描述子多重集**（行最大权重中位 0.044 ≈ 15–40 个位置的加权平均）——但现在这只是一条"操作性质不同"
   的说明，**不是**"结论失效"的证据。ε=0.05 的 I_BAL 下界仅 +0.006 点，是唯一需要提醒的"勉强"格。
