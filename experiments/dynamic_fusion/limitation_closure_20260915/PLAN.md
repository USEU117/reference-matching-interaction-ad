## 一、七条局限的可行性判定

| # | 局限原文要点 | 判定 | 依据 |
|---|---|---|---|
| ① | 主要交互是事后形式化的；数据集不是未碰过的确认集 | ❌ **不可解决** | MVTec/VisA 原始数据虽在本地（`data/mvtec`、`data/visa_raw`），且 `v3_direction_a` 有这两个数据集的 DINOv2-B 与 CLIP 特征，但**缺 DINOv2-S 特征**；补齐需 GPU 重编码。且这两套数据同样参与过旧项目探索，即便补上也仍不构成"未碰过"的确认集 |

| ④b | 完整部署资源测量不可用 | ✅ **部分可解决** | 96 个 `DONE.json` **全部含 timing**（`load_s/score_s/metric_s/total_s`），48 个新编码器单元另有 `resource_usage.json`（含 `peak_gpu_mb=417.7`）→ 可聚合出分阶段成本分布，执行 **E3** |

## 二、E1：全像素 bootstrap 区间（解决局限 ④a）

### 为什么这是最大缺口
论文目前的说法是"全像素点估计保持了方向一致"，但同时声明"**不能**支持全像素显著性的断言"。若补出全像素区间且与 stride-8 结论一致，这条声明可以升级为"两个网格下结论一致"；若不一致，则必须降级表述——**无论哪种结果都有科学价值**。

### 输入
| 来源 | 内容 |
|---|---|
| `R/p1_matrix/units/<dataset>_s<seed>_k<K>/<cat>/patch_scores.npz` | MPDD 72 单元，patch 级分数 (N,32,32)，13 方法 |
| `R/p3_external/units/.../patch_scores.npz` | BTAD 24 单元 (N,32,42) |
| `R/../representation_matching_interaction_20260914/04_new_encoder/units/*/{patch_scores.npz}` | D 扩展 48 单元（`__study` 与 `__corrected` 两版） |
| `canonical/B/<dataset>_s<seed>_k8/<cat>.npz` | 掩码 `imgs_masks`、标签 `gt_sp`、`grid_size` |

### 方法（三步，全部确定性）
1. **全像素分数图**：完全复用 `common.dists_to_maps`（`cv2.resize` INTER_LINEAR 到 `grid×14`，再 `gaussian_filter(sigma=4)`）。不加任何新参数，确保与 `p4_fullpixel` 同源。
2. **配对重采样**：复用 `stats_v2.py` 的随机流构造 `default_rng([20260913, DATASET_ID[dataset], CATEGORY_ID[dataset][cat], replicate])`，含 `replicate` 且**不含** method/seed/K。这样每张测试图在某个副本中被抽中的次数，与已发布的 stride-8 分析**逐副本完全相同** → 全像素区间与 stride-8 区间构成配对比较。
3. **精确加权池化 AP**：不把池化像素真正拼起来（内存爆炸），改用等价分解——
   - 每张图预先算好"按分数排序的负像素数组"和"该图出现过的正像素取值及其计数"；
   - 对每个副本，池化后的 `neg_ge(v)` 与 `pos_ge(v)` 都是跨图计数的**加权和**，用一个 `(1000, N) @ (N, M)` 矩阵乘法一次算出全部 1000 个副本；
   - 再按 AP 的阶梯定义闭式求和。**不量化分数、不丢弃并列像素**。

### 验收标准（必须逐条通过）
| 编号 | 检查项 | 通过判据 |
|---|---|---|
| V1.1 | 全像素点估计复现 | 与 `p4_fullpixel/fullpixel_metrics.csv` 逐行比对，`max|Δ| < 1e-9`（BTAD-03 因 448×588 单独核） |
| V1.2 | AP 口径对齐 | 用同一实现对 stride-8 地图重算，结果必须等于 `p1_statistics/point_by_condition.csv` 的点估计 |
| V1.3 | 重采样下标一致 | 抽样权重与 `bootstrap_samples.npz` 隐含的逐副本下标一致（逐副本校验） |
| V1.4 | 区间嵌套 | 每个 98.75% 区间必须包含对应的 95% 区间 |
| V1.5 | 方向一致性 | 全像素与 stride-8 的 8 个交互（S 四条 + D 四条）符号逐条比对，报告一致/翻转清单 |
| V1.6 | 覆盖率 | 96（S）+ 48（D）单元全部产出，无缺单元 |

### 产物
`experiments/dynamic_fusion/limitation_closure_20260915/E1_fullpixel_ci/`
- `fullpixel_bootstrap.npz`（1000 副本 × 条件 × 方法）
- `interaction_fullpixel_ci.csv`（点估计、95%、98.75%、是否排除零）

## 三、E2：共享操作消融（解决局限 ⑥）

论文原文承认"空间映射、分支归一化、从拼接描述子打分"这三步是**固定的、未消融的**，因此不量化它们各自贡献多少。补三组消融。

| 编号 | 消融 | 实现要点 | 破坏的前提 |
|---|---|---|---|
| **ABL-N** | 去分支 L2 归一化 | `_unit_rows` 置恒等；距离由 `1 - q·r` 改为平方欧氏 `‖q‖²+‖r‖²-2q·r`，**必须去掉 `clamp(min=0)`** | unit descriptor 前提（权重不再等价于描述子几何权重） |
| **ABL-S** | 去后处理高斯平滑 | `dists_to_maps` 的 `sigma` 由 4 改为 0（**只加参数，不改默认值**） | 输出图的局部平滑；同时影响 pixel 与 image 指标（图像分数 = map 的 max） |
| **ABL-C** | 朴素拼接检索 | 拼接时用 `w`（而非 `sqrt(w)`）缩放后联合 L2 归一化再检索 | 与分数层加权融合的等价性 |

### 关键事实（必须在报告中写明，否则会被误读）
- **ABL-C 对等权构造（A1、TRI、DUP）在数学上是零效应**：已有的 `legacy_A1_faiss_real_patch_parity` 不变量已证明"`sqrt(w)` 缩放 + 拼接 + 联合 L2"与分数层加权融合**严格等价**（差 ~1e-6）。改用 `w` 缩放后，等效权重变成 `w²/Σw²`，**只有 BAL（1/4,1/4,1/2）会不同**。因此 ABL-C 的结论只能是"拼接式实现在不等权分配下与分数融合不同"，**不能**写成"拼接检索更差"。
- **ABL-S 与 ABL-N 需要重打分**（ABL-S 只需重算地图，ABL-N 需要重算距离）。

### 验收标准
| 编号 | 检查项 | 通过判据 |
|---|---|---|
| V2.1 | 不污染冻结产物 | 冻结目录的文件 mtime 与哈希在跑前跑后**完全不变**（脚本自动比对） |
| V2.2 | 基线复现 | 消融脚本在 baseline 配置（归一化开、sigma=4、sqrt(w)）下必须**逐位复现** `patch_scores.npz`（`max|Δ| < 1e-12`） |
| V2.3 | ABL-C 等价性验证 | 等权构造下 ABL-C 与 baseline 的差异 < 1e-5（证明等价性成立，而非实现错误） |
| V2.4 | ABL-N 有效性 | 单分支 B/S/C 的像素 AP 在 ABL-N 下必须发生变化（否则说明改动没生效） |
| V2.5 | 方向与量级报告 | 每个消融给出 4 个构造 × 2 规则的像素 AP，并与 baseline 求差 |

### 产物

## 五、明确不做的项与理由

| 项 | 为什么不做 |
|---|---|
| 在 MVTec AD / VisA 上跑新设计（局限①） | 缺 DINOv2-S 特征，需 GPU 小时级重编码；且两套数据同样参与过旧项目，补上也不构成"未碰过"的确认集 → **需你决策是否投入** |
