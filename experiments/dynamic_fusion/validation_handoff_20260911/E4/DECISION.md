# E4 DECISION — 第三视觉分支是否必要

协议：`handoff_gate_v1`　数据集：MPDD / development　seed 0　K=2、4　6 类
依赖：E0（parity）、E2（B/S/C 缓存与锁定对照）。三支缓存已就绪，故本工作包**已执行一次低增量成本初筛**（非阻塞）。

## 1. 假设
三支一起可能优于任意一对，也可能只增加噪声和成本。两个 pair 失败并不从逻辑上排除 triple 有效，故固定等权 B+S+C 做一次初筛，**不额外搜索三维权重**。

## 2. 实际做了哪些配置
复用 E2 的三支同 test/ref ID、几何与预处理，新增三支融合（逐支 L2 → 等贡献拼接 → 联合 L2，维度 768+384+768 = 1920），走同一 pipeline M 与同一 evaluator。对照：`best_pair_M` = B+C（A1）、`best_single_M` = M_B、三种去掉一支的 pair（E2 已有）、以及 `best_observed_single`（M_B/M_S/N_B_pcv/N_S_pcv 的实际可比范围）。

## 4. 相对锁定对照的增量
- **vs best_pair_M（B+C）**：k2 ΔP-AP = **−0.009500**、worst 类别 **−0.051237**、ΔP-AUROC −0.000357；k4 ΔP-AP = **−0.015185**、worst 类别 −0.064752、ΔP-AUROC +0.000425。两 shot 均**未达 +0.005**，worst 保护亦不通过 → **G1-B 不成立**。
- **vs best_single_M（M_B，补充参照，非 G1-A 对照）**：k2 宏 ΔP-AP +0.018595、worst 类别 −0.023793、ΔP-AUROC +0.011184（三项均过）；k4 宏 ΔP-AP +0.011159、**worst 类别 −0.035634（< −0.03 不通过）**、ΔP-AUROC +0.009390。triple 相对 best single 的均值 +0.014878。该对照只说明 triple 优于 M 内最强单支，**不改变 G1-A 的判定**（G1-A 的对照是冻结 A1）。
- **vs best_observed_single**：本轮实际完成的原生单支只有 `N_S_pcv`（0.322206）与 `N_B_pcv`（0.313435），triple 高于二者；但**官方 N_S/N_B 缺失**，该参照范围不完整，不能据此宣称“胜过原生单支”。
- 与三种 pair 的关系：triple 高于 B+S 与 S+C，但**低于 B+C** → 「第三支不必要」。

## 5. 门槛逐项结果
- **G1-A vs frozen A1**：**不通过**。k2 ΔP-AP = −0.009500、k4 = −0.015185，两 shot 均未达 +0.01（详见 `../E1/gate1a.json`）。
- **G1-B vs best_pair_M（B+C）**：**不通过**（k2/k4 ΔP-AP 均 ≤0，worst 保护亦不通过）。
- 补充事实：triple 相对 **best_single_M（M_B）** 在 k2 达到 +0.0186 且 worst/AUROC 均过，但 k4 的 worst 类别 −0.0356 破裂；这不是 G1-A 的定义对照，只作为“第三支在什么条件下才有一点价值”的观察记录。
- 结论按协议落为「**第三支不必要**」：相对**最强对照（B+C）**为负且成本更高（+384 维、+0.46 s 建库、+8.3 ms/图）。

## 6. 能得出 / 不能得出的结论
- **能**：在这三种编码器与 M 协议内，**加入第三支 B+S+C 没有带来增益**，且相对锁定最强双支退化。这与 E2 的分支冗余分析一致：B 与 S 高度冗余（0.88–0.95），把 S 追加到 B+C 只是加入近似重复信息。
- **能**：工程上 triple 相对 B+C 增加 384 维特征、+33% 建库时间、+15% 每图延迟而无精度回报。
- **不能**：不能仅凭 pair 失败宣称“任意 triple 必失败”；本轮只否证**这一组等权三支**。
- **不能**：不能宣称 A1 整体最优；官方原生单支缺失使 `best_observed_single` 范围不完整。
- **限制**：峰值 RAM/GPU 未插桩（`psutil` 在该 venv 不可用），因此按协议记为缺失，不填 0；建库与评分时间为 CPU faiss 口径。

## 7. 是否扩展及唯一原因
不扩展。三支等权路线按协议在此结束，不继续随意扫三维权重；若要做新机制，须另立独立后续协议（对应 E6 的触发条件）。
