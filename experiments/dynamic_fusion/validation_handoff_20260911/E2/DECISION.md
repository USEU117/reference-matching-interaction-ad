# E2 DECISION — 三个视觉编码器的单支 / 双支矩阵

协议：`handoff_gate_v1`　数据集：MPDD / development　seed 0　K=2、4　6 类
候选集合：DINOv2 ViT-B/14（B）、DINOv2 ViT-S/14（S）、AnomalyCLIP ViT-L/14@336 图像塔（C）

## 1. 假设
当前 B+C 未必是这三个候选中的最佳双支；某个单支也可能已足够好。结论只支持这个候选集合。

## 2. 实际做了哪些配置（第一轮固定六组 + 两个额外参照）
全部走 matched 管线 M（同一原图坐标、canonical 32×32 patch 网格、逐支 L2、等权拼接、联合 L2、同一正常记忆库 1-NN）。CLIP 单支经网格对齐后评分记为 `C_aligned`；其原生 37×37 单支记为 `C_native37`（额外参照，不与 aligned 混用）。
B/S/C 复用 E1/E0 缓存，未重复导出。

## 5. 组成单支比较（`constituent_comparisons.csv`）
- B+S vs 组成单支：+0.0081（k2）/+0.0016（k4）vs M_B，+0.0210/+0.0349 vs M_S。锁定组成单支为 **M_B**（两者中更强）；B+S 相对 M_B 的 ΔP-AP 两 shot 均 <+0.005，**G1-B 的融合必要性不成立**。
- S+C vs 组成单支：+0.0142/+0.0207 vs M_S，+0.0443/+0.0651 vs C_aligned。锁定组成单支为 **M_S**；S+C 相对 M_S 的 ΔP-AP 达标，但 k2 最差类别 Δ=−0.0362 < −0.03，**worst 保护不通过，G1-B 仍不成立**。
- B+C vs 组成单支：+0.0281/+0.0263 vs M_B，+0.0710/+0.1040 vs C_aligned（A1 为参照，不作为待晋级候选）。

## 6. 锁定（`selected_pair_lock.json` / `../selected_controls_lock.json`）
- `best_single_M` = **M_B**（s0 K2/K4 均值 0.338797；候选 M_B/M_S/C_aligned）
- `best_pair_M` = **B+C / A1**（0.366017；候选 B+S/B+C/S+C）
- `constituent_single`：B+S → M_B；B+C → M_B；S+C → M_S
- 规则：按 s0 K2/K4 宏 P-AP 均值一次选定，不按测试类别/shot/后续数据集重选；相差 ≤0.001 时依次取分支更少、配置 ID 字典序更前。

## 7. 门槛逐项结果
- **G1-A**：六个（含 triple）**全部不通过**。最接近的是 B+S（Δ 均值 −0.0224）。逐单元明细见 `../E1/gate1a.json`。
- **G1-B**：B+S、S+C 相对各自锁定组成单支**均不通过**。详见 `gate1b.json`。
- **paired bootstrap**（B=2000、seed=20260911、类别内按正常/异常图分层、整图重采样、共享抽样索引；`bootstrap_primary.json`）：B+S vs A1 = −0.020215 [−0.037026, −0.001521]（k2）/ −0.025576 [−0.041473, −0.007876]（k4），两 shot CI 全在 0 以下；B+S+C vs A1 = −0.009900 [−0.021350, +0.002974]（k2）/ −0.013816 [−0.028573, +0.004424]（k4），上界最高仅 +0.0044、>0 比例约 6%。**区间不支持任何“候选优于 A1”的主张。**

## 8. 能得出 / 不能得出的结论
- **能**：在这次明确列出的候选集合 {B, S, C} 内，**当前 B+C 就是最佳双支，也是最佳组合**。更换任一支或去掉任一支都降低宏 P-AP（−0.022～−0.088）。答案落在协议预列的“当前 B+C 最好”分支。
- **能**：收益**不来自 backbone 替换**（S 更差，E1），**也不来自融合机制的新设计**（B+C 就是冻结的等权拼接）；C 与 B 的互补性（低相关）是 B+C 有效的直接机制证据。
- **不能**：不能外推到“B+C 在所有视觉编码器组合中全局最优”；未比较其他预训练范式。协议规定：若需新编码器 N，须另立 v2 协议、最多引入一个预先选定的 N。
- **不能**：C_aligned/C_native37 的差距（−0.088/−0.076）说明网格对齐对 C 单支并非增益来源，但**这不能用于否定 C 在融合中的贡献**——融合增益来自互补性而非单支强度。
- 单支路线：最好单支 M_B 相对 A1 为负，**不满足 G1-A**，单支不晋级。

## 9. 质量检查（本轮实际发现并修正的问题）
- **适配器功能自检**（`E2/adapter_selftest.json`，全部 pass）：
  - ID 排序置乱后按 `sample_ids` 重新对齐 → 逐指标差 0.0；
  - 参考/样本身份错配被 `require_same_ids` 拒绝（抛错）；
  - 权重 [1,0] 精确恢复单支距离（最大差 7.2e-07）；
  - 同一分支重复拼接保持单支距离（最大差 6.0e-07，Pearson 0.999999999996）。
- **bootstrap 口径修正**：首版 `bootstrap_primary.py` 把**逐图标签**重复成像素标签，导致 bootstrap 均值与点估计不符（例如 k2 的 B+S 点估计 −0.0200，错误实现给出 −0.0010）。已改为从**重采样后的 GT 掩码**生成像素标签；修正后用恒等重采样复算，四个比较全部逐位复现点估计（k2 B+S −0.019989、k2 B+S+C −0.009500、k4 B+S −0.024768、k4 B+S+C −0.015185）。**修正前的中间结果已作废，未进入本报告任何结论。**
- 为控制计算量，paired bootstrap 只承载两个决策相关候选（`B+S`、`B+S+C`）对 A1 的区间；`M_B/M_S/S+C` 的差异仅以点估计报告。B=2000、seed=20260911 与协议一致。

## 10. 是否扩展及唯一原因
不扩展。六组均已完整且无候选过 G1-A/G1-B，按协议不进入 G2/G3，不追加 backbone 或层选择。唯一可考虑的扩展是另立 v2 协议引入一个新视觉编码器，但这需要新信息依据而非试跑排名。
