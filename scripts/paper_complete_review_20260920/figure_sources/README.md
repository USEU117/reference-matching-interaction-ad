# Figure source archive

This directory preserves the scripts used for the 20 September 2026 manuscript and figure-deck build.

- `plot_primary.py` builds the primary effect and sensitivity plots.
- `plot_extra.py` builds the resource and geometry panels.
- `plot_supplementary_figures.py` builds Figures S2–S5 and the multipart S3 evidence panels.
- `build_methods.mjs` builds the editable method slides used for Figures 2, 3 and S1.
- `build_deck.mjs` assembles the 58-slide figure deck and its slide index.

The editable framework source is retained separately at `docs/main_figure_revision_20260920/Main_Figure_Editable_Final_20260920.pptx`. The numerical scripts resolve evidence from the project result directories; they do not contain copied or invented measurements.
